# 기Log 로고·색 적용 지침 (2026-10-16 사용자 확정)

**언제**: 캘린더 세션이 지금 만드는 버전(0.8.1) **바로 다음에 나가는 버전**에 넣어요. 다음 버전이 캘린더 수정이든 9단계든, 그 버전에 이 지침을 함께 적용해요. 적용하면 이 파일 맨 아래 "적용 기록"에 버전을 적고 CLAUDE.md 진행 상태 표의 "브랜드" 줄을 고쳐요.

**우선순위**: 색과 로고는 이 파일이 디자인 시스템 아티팩트·화면 시안보다 우선해요(시안은 아직 남색으로 그려져 있어요). 배치·칸 순서·문구는 그대로 시안을 따라요.

로고 시안 캔버스: https://claude.ai/artifact/KcmnSaXffoTWrdBDREnCDN ("확정 로고", "상황별 시안" 보드)

## 1. 이름

- 화면에 보이는 이름은 모두 **기Log** (사이드바, 창 제목, 트레이 메뉴 "기Log 열기", 알림 문구, 설정·정보 문구, 백업 저장 창 제목 등).
- 바꾸지 않는 것: `productName`·`identifier`(kr.gilog.app)·자료 폴더(문서\giLog)·백업 확장자(.gilogbak)·설치 파일 이름(giLog_<버전>_x64-setup.exe). 기존 설치·자료와 이어지게 하고, 한글 파일 이름 문제를 피하려고요.
- 윈도우 알림 앱 이름(AppUserModelId 표시 이름)은 **기Log**로 보이게 해요(등록 키 이름 `kr.gilog.app`은 그대로).

## 2. 로고

파일은 `brand/`에 있어요(모두 윤곽선이라 글꼴이 필요 없어요).

| 파일 | 쓰는 곳 |
| --- | --- |
| `logo.svg` | 밝은 바탕 기본형 (심볼·ㄱ·L = accent, ㅣ·O·G = ink) |
| `logo-dark.svg` | 어두운 바탕 기본형 |
| `logo-black.svg` | 흑백 인쇄·PDF 머리글 |
| `logo-white.svg` | 보라 바탕 위 반전 |
| `symbol.svg` | 심볼만 |
| `app-icon.svg`, `app-icon-1024.png` | 앱 아이콘 원본 (두 테마 같은 그림) |

- **앱 안에서는 SVG 파일을 붙이지 말고 `src/Logo.tsx` 부품을 만들어 그려요.** `logo.svg`의 path를 그대로 옮기고, 색은 `fill="var(--accent)"`(심볼, 글자 ㄱ·L), `fill="var(--ink)"`(ㅣ·O·G, `fill-rule="evenodd"`)로 써서 테마를 따라가게 해요. 크기는 `height` 하나로 정하고 비율(3536:822)을 지켜요.
- **사이드바**: 지금 `App.tsx`의 `<div className="brand">giLog</div>` 자리에 로고 높이 32px(심볼 기준). 메뉴 위 여백은 지금과 같게.
- **잠금 화면**: 앱 아이콘 64px + 그 아래 글자 로고만(심볼 빼고 ㄱㅣLOG, 높이 약 23px).
- **정보(설정의 "정보")**: 앱 아이콘 56px + 글자 로고 + 버전.
- **앱 아이콘 교체**: 저장소 맨 위 `app-icon.png`를 `brand/app-icon-1024.png`로 바꾸고 `npx tauri icon app-icon.png`로 `src-tauri/icons/`를 다시 만들어요(ico·png 모든 크기). 트레이 아이콘도 같은 그림이에요.
- 규칙: 로고 둘레에 심볼 높이의 절반 이상 비워요. 로고 최소 높이 16px, 심볼 단독 12px. 늘이기·눕히기·색 바꾸기·그림자·간격 바꾸기 금지.

## 3. 색 — 남색 계열을 모두 없애요

`src/tokens.css`의 값만 바꾸면 돼요(화면 코드에는 색 값이 없어요 — 확인함). **밝게**(`:root`)와 **어둡게**(`@media (prefers-color-scheme: dark)` 안과 `:root[data-theme="dark"]` 두 곳)를 모두 같은 값으로 고쳐요. 표에 없는 토큰(상태 처리중·완료, danger, urgent, 형광, 프로젝트 8색, 구글 24색)은 그대로예요.

| 토큰 | 밝게 (지금 → 새) | 어둡게 (지금 → 새) | 쓰임 |
| --- | --- | --- | --- |
| `--accent` | #0C447C → **#4B37C4** | #8DB8EA → **#B6AAFF** | 현재 화면, 등록·저장, 체크, 로고 |
| `--on-accent` | #FFFFFF (그대로) | #0B1E33 → **#1A1240** | accent 위 글자 |
| `--accent-tint` | #E3EEFB → **#EEEAFF** | #1B3350 → **#2B2552** | 선택됨, "접수" 배지 |
| `--accent-wash` | #F5F9FE → **#F8F6FF** | #172230 → **#1E1B30** | 입력 중인 줄·카드 바탕, 오늘 칸 |
| `--accent-line` | #9DB7D6 → **#B9AEF0** | #3F5F85 → **#5A4FA8** | 신규 입력 점선 |
| `--ink` | #1B2430 → **#1C1B22** | #E6EBF1 → **#ECEAF2** | 본문 글자 |
| `--ink-2` | #3A4553 → **#3B3A45** | #C3CCD6 → **#C9C6D3** | 보조 글자, 메뉴 |
| `--muted` | #56616F → **#5E5C6A** | #9AA6B4 → **#A09DAD** | 안내·개수 |
| `--surface` | #FFFFFF (그대로) | #151A21 → **#17161C** | 화면·카드 바탕 |
| `--surface-side` | #F4F6F8 → **#F5F5F8** | #10141A → **#121116** | 사이드바 |
| `--surface-band` | #F1F4F7 → **#F1F0F5** | #1D242D → **#1F1E26** | 카드 머리띠, 시간 기둥 |
| `--line` | #C9D3DE → **#CFCDD9** | #3A4553 → **#3D3B47** | 카드·입력칸 테두리 |
| `--line-soft` | #E3E8EE → **#E5E4EC** | #2A323D → **#2C2B34** | 구획선 |
| `--line-row` | #EEF1F4 → **#EFEEF3** | #232A33 → **#25242C** | 목록 줄 구분선 |
| `--row-alt` | #FAFBFC → **#FAFAFC** | #181E26 → **#1B1A21** | 표 줄무늬 |
| `--st-hold-bg` / `-fg` | #ECEEF1 / #4A5563 → **#EEEDF2 / #4E4C5A** | #2A313B / #B4BECA → **#2C2B34 / #BAB7C6** | "보류" 배지 |
| `--st-new-bg` / `-fg` | #EEEAF7 / #4A3B8C → **#EEEAFF / #4B37C4** | #2E2A45 / #C4B8F0 → **#2B2552 / #C9C0FF** | "접수" 배지 (accent-tint와 같은 결) |
| `--saturday` | #1D4E9E → **#2F55C8** | #8AB4F8 (그대로) | 토요일 날짜 |

- 대비 확인함(본문 4.5:1 이상): 밝게 accent/바탕 7.9, 흰 글자/accent 7.9, ink 17.1, muted 6.5 · 어둡게 accent/바탕 8.7, on-accent/accent 8.5, ink 15.1, muted 6.8.
- 어둡게 테마에서 `--st-new-*`가 두 번 적힌 줄(시스템 블록)은 하나로 정리해요.
- 그림자: `src/app.css`의 `rgba(20, 28, 38, …)`(남색 기운) 5곳을 `rgba(28, 27, 34, …)`로 바꿔요(같은 투명도). 할 수 있으면 `--shadow-rgb` 토큰 하나로 묶어요.
- 바꾼 뒤 `grep -rnE "#[0-9A-Fa-f]{6}" src | grep -v tokens.css`가 비어 있어야 해요.

## 4. 테마 세 가지 (밝게 · 어둡게 · 시스템)

- 이미 있어요: 설정의 테마(시스템·밝게·어둡게) → `App.tsx`가 `data-theme`을 붙이거나 빼요(시스템이면 윈도우 설정을 따라가요). 이 구조를 유지해요.
- 할 일: 위 표의 값이 **세 곳 모두**(밝게, 시스템-어둡게, 직접 어둡게)에 같은 값으로 들어가 있는지 확인. 시스템 모드에서 윈도우 테마를 바꾸면 앱을 다시 켜지 않아도 바로 바뀌는지 확인(`prefers-color-scheme` 변경을 따라가요).
- 로고·아이콘: 사이드바·잠금·정보의 로고는 토큰 색이라 저절로 바뀌어요. 앱 아이콘은 두 테마 같은 그림이에요.
- 프로젝트 8색과 구글 24색은 두 테마 같은 색 그대로예요.

## 5. 확인 (올리기 전)

1. 1920×1080 스크린샷을 **밝게·어둡게** 두 벌로 찍어 모든 화면(업무일지·민원대장·업무연락처·캘린더·할 일·설정·잠금)에 남색이 남아 있지 않은지 봐요.
2. 사이드바 로고 32px이 또렷한지(심볼 맞물림, ㄱ·L 보라).
3. 설치 뒤 작업표시줄·트레이·알림·창 제목에 새 아이콘과 "기Log"가 보이는지 — 윈도우에서만 확인돼서 사용자에게 시험 항목으로 적어요.
4. 기존 자료가 그대로 열리는지(이름을 바꾸지 않은 폴더·식별자 덕분에 그대로여야 해요).

## 6. 아직 정하지 않은 것 (사용자에게 물어요)

- 프로젝트 배지 4번(보라, #7A2FD0)이 새 강조색과 가까워 "선택됨"과 헷갈릴 수 있어요. 1안 자주색 쪽으로 옮기기, 2안 그대로.
- 디자인 시스템 아티팩트와 화면 시안 캔버스의 색을 이 표대로 고칠지(이 대화에서는 아직 안 고침).
