# 엑셀 양식 (사용자 양식, 2026-10-17)

사용자가 준 양식(시트 "민원대장"·"업무연락처")을 가져오기·내보내기에 그대로 써요. **양식 파일은 아직 저장소에 넣지 않았어요.** 업무연락처 4행은 사용자가 넣은 예시예요 — 앱에 넣을 때는 이 줄을 비운 양식을 넣어요(2026-10-17 사용자 1안). 내보내기는 양식 파일을 열어 4행부터 자료만 채우고 나머지 설정은 건드리지 않는 방식(서식·인쇄 설정을 코드로 다시 만들지 않음)을 권해요.

## 두 시트 공통
- 1행: 제목(시트 이름과 같음), 전체 열 병합, **HY헤드라인M 20pt**, 가운데, 행 높이 30.
- 2행: 빈 줄, 높이 18.
- 3행: 열 제목, **맑은 고딕 10pt 굵게, 글자색 #002060**, 바탕 연회색(테마 흰색 −5% ≈ #F2F2F2), 가는 테두리(테마 검정 50% ≈ #808080), 가운데·세로 가운데, 높이 18.
- 4행부터 자료: **맑은 고딕 10pt**, 셀 서식 텍스트(@), 가는 테두리(같은 회색), 가운데·세로 가운데·자동 줄 바꿈. 긴 글 열만 왼쪽 맞춤. 기본 행 높이 18(고정).
- 틀 고정 3행 아래, 페이지 나누기 미리 보기, 확대 100%.
- 인쇄: A4 **가로**, 여백 **위·아래·왼쪽·오른쪽 1.5cm**, 머리글·바닥글 없음(쪽 번호 없음), **가로 가운데 맞춤**, **너비 1쪽에 맞춤**(높이 자동, 배율 민원대장 57%·업무연락처 71%), **인쇄 제목 1~3행**(쪽마다 반복), 인쇄 영역 A1:M195 / A1:I195 → 내보낼 때 마지막 자료 행까지로 맞춰요.

- **테두리와 인쇄 영역(2026-10-17 사용자)**: 자료가 들어간 행에만 양식과 같은 회색 가는 테두리를 둘러요(빈 행에는 없음). 인쇄 영역은 1행부터 마지막 자료 행까지로 맞춰, 테두리 범위가 인쇄 영역 안에 꼭 맞게 해요. 목록 칸(접수유형·상태)도 자료 행까지만.
