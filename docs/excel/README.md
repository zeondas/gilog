# 엑셀 양식 (사용자 양식, 2026-10-17)

사용자가 준 양식(시트 "민원대장"·"업무연락처")을 가져오기·내보내기에 그대로 써요. **양식 파일은 아직 저장소에 넣지 않았어요.** 업무연락처 4행은 사용자가 넣은 예시예요 — 앱에 넣을 때는 이 줄을 비운 양식을 넣어요(2026-10-17 사용자 1안). 내보내기는 양식 파일을 열어 4행부터 자료만 채우고 나머지 설정은 건드리지 않는 방식(서식·인쇄 설정을 코드로 다시 만들지 않음)을 권해요.

## 두 시트 공통
- 1행: 제목(시트 이름과 같음), 전체 열 병합, **HY헤드라인M 20pt**, 가운데, 행 높이 30.
- 2행: 빈 줄, 높이 18.
- 3행: 열 제목, **맑은 고딕 10pt 굵게, 글자색 #002060**, 바탕 연회색(테마 흰색 −5% ≈ #F2F2F2), 가는 테두리(테마 검정 50% ≈ #808080), 가운데·세로 가운데, 높이 18.
- 4행부터 자료: **맑은 고딕 10pt**, 셀 서식 텍스트(@), 가는 테두리(같은 회색), 가운데·세로 가운데·자동 줄 바꿈. 긴 글 열만 왼쪽 맞춤. 기본 행 높이 18(고정).
- 틀 고정 3행 아래, 페이지 나누기 미리 보기, 확대 100%.
- 인쇄: A4 **가로**, 여백 **위·아래·왼쪽·오른쪽 1.5cm**, 머리글·바닥글 없음(쪽 번호 없음), **가로 가운데 맞춤**, **너비 1쪽에 맞춤**(높이 자동, 배율 민원대장 57%·업무연락처 71%), **인쇄 제목 1~3행**(쪽마다 반복), 인쇄 영역 A1:M195 / A1:I195 → 내보낼 때 마지막 자료 행까지로 맞춰요.

### 업무연락처 양식 바뀜 (2026-10-19 사용자 파일 — 축약 공사명이 백업에서 빠졌어요)
- 시트는 "업무연락처" 하나, **A~L**: 연번·이름·소속·직위·무선·유선·이메일·프로젝트·메모 + **숨긴 열 J 그룹(21.7, 왼쪽)·K 축약 공사명(30, 가운데)·L 색(1~8, 비우면 자동)**. 제목 병합·인쇄 영역은 A~L(숨긴 열은 인쇄되지 않아요). 프로젝트 열 폭 37.2.
- 행 높이: 1행 30, 2행·3행·자료 행 18(사용자 파일대로 — 업무연락처만, 기본 행 높이는 30 그대로). 민원대장·업무일지는 예전 그대로(1행 50·나머지 30).
- **한 사람 = 한 줄**(2026-10-19 사용자 — 사람이 중심이라 같은 사람이 프로젝트 수만큼 있으면 안 돼요). 프로젝트가 여러 개면 프로젝트 칸에 **쉼표 + 줄바꿈**(`가,⏎나`)으로 한 줄에 하나씩, 숨긴 그룹·축약 공사명·색도 같은 줄 순서로(값이 모두 비면 칸을 비워요). 순서는 그 사람에게 붙인 순서 그대로(첫 프로젝트가 업무일지에 저절로 붙어서). 행 높이는 프로젝트 줄 수만큼(1줄 18, 줄마다 +13.5).
- 연락처가 없는 프로젝트는 **맨 아래에 이름~메모가 빈 "프로젝트만 있는 줄"**(사용자 1안).
- 가져오기: **연번과 이름이 같은 줄은 떨어져 있어도 한 사람**(엑셀에서 프로젝트로 정렬해도 돼요), 연번이 비면 이름~메모가 모두 같은 줄을 묶어요. 묶인 사람의 소속·번호·메모는 처음 나온 줄 것(비어 있으면 다음 줄 것). 프로젝트 순서는 줄 순서. 이름~메모가 모두 빈 줄은 프로젝트만 만들어요. 숨긴 열은 프로젝트가 한 개인 줄에서 읽고, 같은 프로젝트가 이미 있으면 **비어 있는 것만** 채워요(축약 공사명·그룹·색). 숨긴 열이 없는 예전 파일(A~I, 프로젝트 칸 쉼표)도 예전처럼 읽어요. 묻는 창에 "프로젝트 N개의 축약 공사명·그룹·색도 맞춰요" 한 줄. 프로젝트 칸은 줄바꿈으로 나누고 줄 끝 쉼표를 떼요(쉼표만인 예전 칸은 쉼표로 나눔 — 이때 숨긴 칸은 프로젝트가 한 개일 때만 읽어요). 사람마다 여러 줄로 적은 파일도 한 사람으로 묶어 읽어요. **앱에 이미 있는 사람**(이름·소속이 같고 무선 번호 숫자가 같음)은 새로 만들지 않고 없는 프로젝트만 뒤에 붙여요(2026-10-19 사용자 1안 — 백업을 다시 가져와도 사람이 늘지 않게, 묻는 창에 "이미 있는 사람 N명은 …프로젝트만 붙여요").

## 가져오기 규칙 (2026-10-17 사용자)
- 앱이 판단하지 않아요: 중복 검사·미리 보기·값 고치기 없이 4행부터 모든 줄을 그대로 넣어요(모든 칸이 빈 줄만 건너뜀). 열은 3행 제목 이름으로 찾아요. 민원 연번은 앱 규칙대로 이어 매기고, 연락처 연번은 읽지 않아요.
- 파일을 고르면 "○○ N건을 가져올까요?" 한 번 묻고, 끝나면 "N건을 가져왔어요".
- 경로는 사용자가 정해요(2026-10-17): 가져오기는 윈도우 "열기" 창에서 파일을 고르고, 내보내기는 윈도우 "다른 이름으로 저장" 창에서 폴더·이름을 정해요. 기본 이름은 "민원대장_YYYY-MM-DD.xlsx"·"업무연락처_YYYY-MM-DD.xlsx", 창은 마지막에 쓴 폴더에서 열려요(처음엔 문서). 다 되면 저장한 경로를 알려 줘요.
- 내보내기는 늘 전체예요.

## 정해야 할 것
- **행 높이(2026-10-17 사용자)**: 모든 행 기본 30(2행·3행·자료 행 — 받은 파일의 18은 쓰지 않아요). 1행 제목("민원대장"·"업무연락처")만 예외로 **50**(받은 파일은 30이었지만 사용자가 50으로 기억 — 다른 행이 30이 되니 50으로 정함). **여러 줄인 자료 행도 30 그대로예요**(2026-10-17 사용자 바로잡음 — 50은 1행만, 나머지는 모두 30. 처음엔 줄 수만큼 늘렸어요). 빈 행 기본 높이도 30.
