## 봤는데 괜찮았던 것

- 되살리기 바꿔치기 1~4단계 어디서 끊겨도 온전한 짝 하나(`recover_swap`) – 기존 시험 그대로 통과, 2단계 이름 바꾸기 실패도 다음 `exists()`에서 맞춰져요.
- 형식 버전이 앱보다 높으면 파일을 안 건드리고 `too_new`, 음수·0은 옛 파일로 올려요.
- 같은 파일을 두 곳이 쓰는 일: 앱 두 번 켜기는 한 번 켜기 플러그인이 막고, 시험용 두 번째 기록은 `giLog-B` 폴더 · 앱 안 명령은 한 자물쇠(`Mutex`)라 백업 도중 저장이 끼지 않아요.
- 한글·공백 경로(`보관`, `gilog_손상_…`) 문제 없음 · 자료 폴더 안으로 옮기기·내보내기는 `guard::export_to`가 막아요.
- 비밀번호 바꾸기 도중 꺼짐(`key.new.json` 남음)은 열 때 두 열쇠를 다 해 봐서 새 비밀번호로 열려요(4번은 "안 꺼졌는데 실패로 알린" 경우예요).
