# 회사 문서보안(DRM) 해제 — 검토 결과

2026-10-19 탐색기 아이콘·보안 세션. 사용자 회사 PC에서 확인한 사실만 적어요.

## 사실

1. **보안 프로그램**: SoftCamp Document Security Client 5.0 (설치 프로그램 목록). MarkAny EPSBroker·mdmviewer도 있지만 파일 잠금은 소프트캠프예요.
2. **우클릭 메뉴 등록**: 정적 명령(`HKCR\*\shell`)에는 없어요. 셸 확장으로만 등록돼 있어요.
   - `HKCR\*\shellex\ContextMenuHandlers\1SoftcampDS` = `{AAEFDE7B-B9F4-4F23-9AD7-05FA7ECB8267}`
   - DLL `C:\WINDOWS\Softcamp\SDS\x64\DSShell64.dll` (64비트, Apartment)
3. **해제 명령줄 도구 없음**: `C:\WINDOWS\Softcamp` 안 exe는 암호화(`SDSEnc`·`ScanEnc`), 관리·로그인(`SDSMan`·`SDSLogin`), 보기(`SCViewer`), 외부 반출 파일 만들기(`MkSom`·`SOM`·`OffSend`), 서버 통신 서비스(`ComAgent`·`SCIPDSService`·`DSCNTSrv`), 진단 도구뿐이에요. 해제는 셸 DLL이 서비스를 거쳐(정책·승인·기록) 해요.
4. **기록 앱에는 메뉴가 안 나와요**: 기록 탐색기 우클릭(`files_win.rs` `context_menu` — `GetUIObjectOf` → `QueryContextMenu`, 64비트)에 소프트캠프 항목이 없어요(사용자 확인). 같은 파일을 윈도우 탐색기에서 우클릭하면 바로 나와요 — 회사 PC는 윈도우 11이지만 새 우클릭 메뉴가 꺼져 있어 "더 많은 옵션 표시"를 거치지 않아요. 잠기지 않은 파일에는 "○○ 일반 문서 암호화"·"○○ 외부전송 보안파일 생성"이 보여요.
   → 소프트캠프 DLL이 호출 프로그램(윈도우 탐색기인지)을 보고 메뉴를 가리는 것으로 봐요.

## 결론

- **1안(기록이 직접 해제) — 없음.** 기록이 메뉴를 받을 수 없고 해제 도구도 없어요. 윈도우 탐색기인 척하는 우회는 회사 보안 우회라 하지 않아요.
- **2안(윈도우 탐색기로 넘기기) — 유지.** 지금 만든 그대로(`reveal()`: 탐색기에서 파일을 골라 두고 3초 안에 앞에 오면 메뉴 키). 해제는 사용자가 누른 그 파일 하나만, 소프트캠프 승인·기록을 그대로 거쳐요.

## 남은 확인 (사용자 윈도우 시험)

- 기록에서 잠긴 파일 우클릭 → "윈도우 탐색기에서 열기 · 보안 해제" → 탐색기가 열리며 보안 메뉴가 저절로 뜨는지.
- 안 뜨면 어디서 멈추는지(창이 앞에 안 옴·메뉴 안 뜸·다른 파일이 골라짐) — 그 부분만 다듬어요.
