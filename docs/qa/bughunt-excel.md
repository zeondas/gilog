## 봤는데 괜찮았던 것

- 민원대장·업무연락처 가져오기, 집행현황(해마다), 예산현황 시트 가져오기(`bstatus_set_many`)는 한 트랜잭션이에요. 중간 값이 틀리면(집행현황 1원 금액·구분·단계) 아무것도 안 바뀌어요.
- 머리 줄만 있는 파일·빈 줄만 있는 파일은 "가져올 줄이 없어요"로 끝나요. 대체하기로 0건을 넣어 다 지우는 일은 없어요.
- 열 순서가 바뀌거나 열이 빠지거나 더 있어도 열 이름으로 찾아요. 빠진 열은 빈 값이에요. 다른 화면 양식 파일은 "○○ 양식이 아니에요"로 막혀요(열 제목 둘이 있어야 함).
- 연번: 대체하기는 1부터, 덮어쓰기는 지금 가장 큰 연번 다음부터 겹치지 않게 매겨요. 파일의 연번은 읽지 않아요.
- 집행현황 같은 이름 세부사업·공사가 파일에 둘이면 하나씩 짝짓고 남는 것은 새로 더해요(덮어 사라지지 않음).
- 집행현황 메모 왕복(`textToMemo`↔`memoToText`)은 한 글자도 안 바뀌어요. 천원 단위 내보내기는 나눈 값을 그대로 써서 다시 가져와도 원 단위 값이 같아요.
- 대체하기 10만 건(민원대장)은 7초예요.
