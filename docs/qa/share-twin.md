# 집행현황 팀 공유 – 한 PC에서 두 계정으로 시험하기 (2026-10-25)

사용자 요청: 구글 계정 둘로 한 PC에서 팀 공유가 서로 맞춰지는지 확인. 가지 `wip/share-twin`(다음 빌드).

## 시험용 두 번째 기록
- 설정 → 모듈별 → 집행현황 카드 맨 아래 **[시험용 두 번째 기록 – 열기]** 를 누르면 기록이 하나 더 떠요(창 제목 "기록 · 시험 B").
  - 직접 켜려면 바로가기 대상 끝에 `--profile B`를 붙여요(예 `"C:\Program Files\giLog\giLog.exe" --profile B`).
- 따로인 것: 자료 `문서\giLog-B` · 앱 설정 `AppData\Roaming\kr.gilog.app\profiles\B` · 화면 저장소 `AppData\Local\kr.gilog.app\profiles\B` · 자격 증명 이름 `giLog-B` · 구글 연결(자료 안에 저장).
- 하지 않는 것: 한 번 더 켜기 막기(원래 기록과 함께 떠요) · 자동 실행 · 바로가기 아이콘 색.
- 구글 로그인 창은 늘 **계정 고르기**를 띄워요(`prompt=select_account consent`) – B 창에서는 두 번째 계정을 고르면 돼요.
- 다 쓰면 B 창을 끝내고 `문서\giLog-B`·`profiles\B` 폴더를 지우면 흔적이 없어요.

## 시험 순서
1. 원래 기록(A, 첫 계정): 집행현황 카드 → 팀 공유 켜기 → [새로 만들기] → "함께 쓰는 사람"에 B 이름 + 두 번째 계정 메일 더하기 → 집행현황 화면 [새로고침](권한 주기) → [주소 복사].
2. [시험용 두 번째 기록 – 열기] → B 창에서 비밀번호 새로 정하기 → 설정 → 집행현황 카드 → 팀 공유 켜기 → 주소 붙여 넣고 [연결] → 브라우저 로그인에서 **두 번째 계정** 고르기.
3. A에서 세부사업·공사 하나 더하기 → A [새로고침] → B [새로고침] → B에 보이는지.
4. B에서 금액 하나 고치기 → B [새로고침] → A [새로고침] → A에 보이는지(받은 줄 왼쪽 초록 선).
5. 같은 칸을 A·B가 각각 다르게 고친 뒤 차례로 새로고침 → 늦게 올린 쪽에 주황 칸·고르기 상자.
6. 담당 배지: A에서 세부사업 담당을 B로 → B에서 보이는지.
7. 명단에서 B를 빼기 → A [새로고침] → B [새로고침]이 "권한 없음"으로 멈추는지.

## 알아 둘 것
- 구글 앱이 "테스트" 상태면 두 번째 계정을 Google Cloud 콘솔 → OAuth 동의 화면 → 테스트 사용자에 더해야 로그인돼요("확인되지 않은 앱" 경고만 뜨면 그대로 진행).
- 두 창 모두 5분마다 저절로 새로고침해요 – 빨리 보려면 [새로고침]을 눌러요.
