## 2. 같은 것끼리 비교

- **토글 부품 세 가지**: `.cal-views`(흰 고름·글자 13), `.bd-unit`(채운 보라·12.5·칸 사이 2), `.seg`(흰 고름·보라 글자·12.5·500). 탐색기는 토글 대신 켜고 끄는 단추를 채운 보라로.
- **검색창**: 폭 232·260·282 세 가지, 높이 34(설정만 30). 자리는 맨 왼쪽(탐색기)·제목 옆(설정)·가운데쯤(업무일지)·오른쪽 묶음(나머지). 자리글 길이 2~16자. **끝 × 단추는 집행현황·설정만** — 공통 결정(2026-10-18 13:40)대로라면 민원대장·민원처리·할 일·업무일지·업무연락처·탐색기·캘린더·예산현황 8곳에 없어요.
- **배치최적화 자리**: 민원대장은 검색 오른쪽, 집행·예산현황은 검색 왼쪽.
- **엑셀 ▾ 자리**: 늘 맨 오른쪽(업무일지만 뒤에 "인쇄"). 관리 단추(분류·공사·프로젝트)는 엑셀 앞, 캘린더 "관리"만 왼쪽 열의 28 작은 단추.
- **추가 단추**: 집행현황 "세부사업 추가" 하나(다른 화면은 신규 입력 줄이 늘 켜져 있어 없음).
- **제목 → 첫 요소**: 16(민원처리·캘린더)·18(집행·예산)·43(설정). 요소 사이는 8이 대부분, 탐색기 묶음 사이 20·민원대장 칩 6·캘린더 이동 단추 4·설정 12.
- **제목 없음**: 탐색기·민원대장. 업무일지 제목은 날짜, 캘린더 제목은 달.
- 머리 줄에만 있는 글자: 할 일 "남은 일 6건"(다른 화면의 건수 글줄은 지웠어요), 민원대장 "상태".
