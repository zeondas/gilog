@상세
#가. 머리 줄
○ 날짜마다 하나 있는 줄, 그날의 출근 시각·교통·날씨·비고를 남겨 근무 기록으로 활용
1) 일지 맨 위 머리 줄의 출근·교통·날씨·비고 칸에 입력
2) enter 또는 tab으로 다음 칸 이동, 바꾸는 즉시 저장
- 인쇄할 때 쪽 머리에 날짜와 함께 이 한 줄이 그대로 인쇄
#나. 검색
○ 모든 날짜의 일지를 한 번에 검색, 예전에 누가 무슨 말을 했는지 바로 확인할 수 있도록 구현
1) 오른쪽 위 검색 칸에 사람 이름이나 내용을 입력
2) 글자를 입력하는 대로 맞는 기록이 날짜별로 묶여 표시, 맞는 글자는 형광 표시
3) "해당하는 말만 보기"를 켜면 대화 중 맞는 줄만 남김
4) 날짜 제목을 누르면 그날 일지로 이동
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
#다. 엑셀·인쇄
○ 업무일지를 엑셀로 주고받고, 필요한 기간을 종이나 pdf로 남길 수 있도록 지원
1) 검색 칸 옆 "인쇄" 단추를 누르면 기간 창 표시
2) 빠른 선택(오늘·이번 주·이번 달·지난달·연초·올해)이나 두 달 달력에서 시작일 → 끝일을 눌러 기간 지정
3) 아래에 "기록 있는 날 N일 · N쪽" 확인 후 인쇄를 누르면 인쇄 창 표시, pdf는 인쇄 창의 "PDF로 저장"으로 생성
- A4 가로, 하루마다 새 쪽에서 시작, 기록 없는 날은 제외
4) 엑셀 : "엑셀 ▾" 단추로 가져오기·내보내기, 기록 한 건이 한 줄
- 가져올 때 날짜·시각·구분·상대·내용이 같은 기록은 건너뜀
<그림>
#라. 달력
○ 왼쪽 위 월 달력에서 날짜를 눌러 그날 일지를 바로 열람
1) 날짜를 누르면 그날 일지가 열림, 기록 없는 날도 열리고 그 날로 등록
2) 오늘은 보라 테두리, 고른 날은 보라 바탕, 기록 있는 날은 날짜 아래 점
3) 달력 머리 "2026년 10월 ▾"를 누르면 12달 고르기 표시, ‹ ›로 해 이동
4) 다른 날을 보고 있으면 제목 옆 "오늘" 단추로 오늘 일지로 이동
5) 날짜 우클릭 : "이 날 열기", "이 날 일지 지우기"(한 번 더 확인)
- 일요일·공휴일은 빨강, 토요일은 파랑
<그림>
#마. 시간·구분
○ 기록을 빠르게 남기도록 시간은 자동으로, 구분은 초성만으로 입력
1) 화면을 열면 커서가 구분 칸에 있고, 등록 뒤에도 구분 칸으로 돌아옴
2) 시간은 지금 시각으로 채워지고, 직접 고치지 않으면 지금 시각을 계속 따라감
3) 구분은 목록에서 고르거나 초성만 입력하고 칸을 떠나면 변환(ㅇㅅ → 유선수신)
- 구분과 초성은 설정 → 업무일지 카드에서 추가·삭제
- 첫 말을 한 사람은 구분이 정함, 수신이면 상대, 발신이면 나
#바. 상대
○ 엑셀 일지 때처럼 연락처를 찾을 필요 없이, 이름만 입력하면 업무연락처에서 연락처를 가져옴
1) 상대 칸에 이름을 입력하면 업무연락처에서 찾아 후보 표시, 초성도 가능(ㅂㅈㅎ, 박ㅈ)
2) 후보를 고르면 구분에 맞는 연락처가 자동 입력(유선 → 유선 번호, 무선 → 무선 번호, 메일 → 이메일)
3) 여러 명은 "/"로 구분해 입력(홍길동 / 김영수)
- 초성만 입력하고 떠나면 초성이 같은 사람이 한 명일 때 자동 입력
- 연락처에 없는 이름도 그대로 등록, 업무연락처에 자동 추가하지는 않음
#사. 말 입력 줄
○ 대화를 말한 사람별로 한 줄씩 기록, 누가 한 말인지 분명히 남김
1) 말 입력 줄에 내용 입력
2) enter는 다음 말(말한 사람 교대), shift+enter는 같은 사람이 이어서 말함
3) alt+enter는 한 말 안에서 줄 바꿈, tab은 등록, esc는 취소
4) 말 앞의 배지를 누르면 말한 사람을 변경
- 상대 배지는 이름마다 정해진 색, 내 말은 "나" 배지
#아. 메모 편집기
○ 회의 내용처럼 대화가 아닌 기록을 문서처럼 작성하도록 편집기 제공
1) 구분에 "메모"를 고르면 말 입력 줄 대신 편집기가 열림
2) 본문·제목·인용, 글머리·번호 목록, 굵게·기울임·밑줄·취소선, 정렬, 표(8×8까지) 사용 가능
3) enter는 다음 문단, shift+enter는 ● 목록 시작, tab은 저장
4) 표 : enter는 다음 칸(마지막 칸이면 줄 추가), alt+enter는 칸 안 줄 바꿈
- 구분 "메모"는 지울 수 없는 고정 구분
- 메모 카드는 상대·사업 없이 본문만 표시
<그림>
#자. 기록 카드
○ 등록한 기록을 시간 기둥형 카드로 쌓아, 하루 동안 오간 말을 순서대로 확인
1) 카드는 2열, 최근 기록이 맨 앞(왼쪽 단 위→아래, 다음 오른쪽 단)
2) 카드를 두 번 누르면 그 자리에서 수정, 바깥을 누르면 저장
3) 사업 배지를 누르면 고르기 목록 표시, 검색 칸에서 사업 이름(초성 가능)으로 찾아 지정
4) 지우기는 수정 중인 카드 아래 휴지통으로, "지울까요?" 확인 후 삭제
- 등록할 때 상대의 첫 사업이 자동으로 지정
- 고친 흔적은 남기지 않음
#차. 챙길 일
○ 일지를 쓰면서 마감이 다가온 일을 놓치지 않도록 왼쪽 아래에 모아서 표시
1) 마감이 7일 안(지난 것 포함)이고 완료되지 않은 민원과 할 일이 마감순으로 표시
2) 항목을 누르면 민원대장·할 일의 그 항목으로 이동
