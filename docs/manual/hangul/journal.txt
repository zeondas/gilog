@화면 업무일지
@부제목 통화·회의·메일 등 업무상 대화를 발언자별로 기록하는 일일 업무 기록 도구
@기획의도
가. 전화·회의·메일로 오간 내용을 발언자까지 기록, 지시 사항에 대한 사후 이견에 대비
나. 업무연락처에 등록된 사람은 연락처가 자동 입력되어 연락처 검색 수고 해소
다. 왼쪽 시간, 오른쪽 대화의 시간 기둥형 카드로 하루 기록을 한눈에 정리
라. 구분 "메모"는 문서 편집기로 작성, 회의 내용·표까지 일지 안에 보관
@기능별
가. 상단 : 날짜별 출근 시각·교통·날씨·비고를 한 행으로 기록
나. 검색 : 전체 일지에서 사람·내용을 검색하여 날짜별로 묶어 표시
다. 엑셀·인쇄 : 엑셀 가져오기·내보내기, 선택 기간 일지를 A4 가로로 인쇄
라. 달력 : 날짜 클릭 시 해당 일지로 이동, 기록 있는 날은 점으로 표시
마. 시간·구분 : 시간은 현재 시각 자동 반영, 구분은 초성 입력으로 변환
바. 상대 : 이름 입력 시 업무연락처에서 검색하여 연락처 자동 입력
사. 말 입력 행 : 발언 내용을 발언자 배지와 함께 기록
아. 메모 편집기 : 구분 "메모" 선택 시 제목·목록·표를 쓰는 편집기로 작성
자. 기록 카드 : 최근 기록 우선 표시, 더블클릭으로 수정, 사업 배지 지정
차. 챙길 일 : 마감 7일 이내 민원·할 일을 마감순으로 표시
@상세
#가. 상단
○ 날짜별 출근 시각·교통·날씨·비고를 기록하여 근무 기록으로 활용
1) 일지 상단의 출근·교통·날씨·비고 입력란에 입력
2) Enter 또는 Tab으로 다음 입력란 이동, 입력란을 벗어나면 자동 저장
- 인쇄 시 쪽 상단에 날짜와 함께 이 행이 인쇄됨
#나. 검색
○ 전체 일지를 한 번에 검색하여 과거 발언 내용을 즉시 확인하도록 구현
1) 날짜 제목 옆 검색란에 사람 이름이나 내용 입력
2) 입력과 동시에 해당 기록이 날짜별로 묶여 표시, 일치 글자는 형광 표시
3) [해당하는 말만 보기] 선택 시 대화 중 일치하는 행만 표시
4) 날짜 제목의 "이 날짜로 이동 →" 클릭 시 해당 일지로 이동
- 검색란 끝의 × 또는 Esc로 입력 내용 일괄 삭제, [검색 닫기]로 검색 종료
#다. 엑셀·인쇄
○ 업무일지를 엑셀로 주고받고, 필요한 기간을 종이나 PDF로 보관하도록 지원
1) 검색란 옆 [인쇄] 클릭 시 "업무일지 인쇄" 창 표시
2) 빠른 선택(오늘·이번 주·이번 달·지난달·연초·올해) 또는 두 달 달력에서 시작일 → 끝일 클릭으로 기간 지정
3) 하단 "기록 있는 날 N일 · N쪽" 확인 후 [인쇄] 클릭, PDF는 인쇄 창의 "PDF로 저장"으로 생성
- A4 가로, 날짜마다 새 쪽에서 시작, 기록 없는 날은 제외
4) 엑셀 : [엑셀 ▾]에서 가져오기·내보내기 선택, 기록 1건이 1행
- 가져오기는 덮어쓰기·대체하기 중 선택, 날짜·시각·상대가 같으면 같은 기록으로 처리
<그림>
#라. 달력
○ 오른쪽 위 월 달력에서 날짜를 클릭하여 해당 일지를 즉시 열람
1) 날짜 클릭 시 해당 일지 표시, 기록 없는 날도 열리며 그 날짜로 등록
2) 오늘은 보라 테두리, 선택한 날은 보라 바탕, 기록 있는 날은 날짜 아래 점 표시
3) 달력 상단 "2026년 10월 ▾" 클릭 시 12개월 선택 표시, ‹ ›로 연도 이동
4) 다른 날짜 열람 중에는 제목 옆 [오늘] 클릭으로 오늘 일지로 이동
5) 날짜 우클릭 : "이 날 열기", "이 날 일지 지우기"(재확인 후 삭제)
- 일요일·공휴일은 빨강, 토요일은 파랑으로 표시
<그림>
#마. 시간·구분
○ 신속한 기록을 위해 시간은 자동 입력, 구분은 초성으로 입력
1) 화면을 열면 구분 입력란에 커서 위치, 등록 후에도 구분 입력란으로 복귀
2) 시간은 현재 시각으로 자동 입력, 직접 수정하지 않으면 현재 시각을 계속 반영
3) 구분은 초성 입력 후 입력란을 벗어나면 변환(ㅇㅅ → 유선수신)
- 구분과 초성은 설정 → 업무일지 카드에서 추가·삭제
- 첫 발언자는 구분으로 결정, 수신이면 상대, 발신이면 나
#바. 상대
○ 이름만 입력하면 업무연락처에서 연락처를 가져오도록 구현
1) 상대 입력란에 이름 입력 시 업무연락처에서 후보 표시, 초성 검색 가능(ㅂㅈㅎ, 박ㅈ)
2) 후보 선택 시 구분에 맞는 연락처 자동 입력(유선 → 유선 번호, 무선 → 무선 번호, 메일 → 이메일)
3) 여러 명은 "/"로 구분하여 입력(홍길동 / 김영수)
- 초성만 입력하고 벗어나면 초성이 같은 사람이 1명일 때 자동 입력
- 연락처에 없는 이름도 그대로 등록, 업무연락처에 자동 추가하지 않음
- 전화번호는 숫자·하이픈만 입력 시 규칙에 맞게 하이픈 재배치(010-72805715 → 010-7280-5715)
#사. 말 입력 행
○ 대화를 발언자별로 한 행씩 기록하여 발언자를 명확히 남김
1) 말 입력 행에 내용 입력
2) Enter는 다음 발언(발언자 교대), Shift+Enter는 같은 발언자가 이어서 발언
3) Alt+Enter는 한 발언 안 줄 바꿈, Tab은 등록, Shift+Tab은 앞 입력란, Esc는 취소
4) 발언 앞 배지 클릭 시 발언자 변경
- 상대 배지는 이름별 고유 색, 본인 발언은 "나" 배지
#아. 메모 편집기
○ 회의 내용 등 대화가 아닌 기록을 문서 형태로 작성하도록 편집기 제공
1) 구분에 "메모" 선택 시 말 입력 행 대신 편집기 표시
2) 본문·제목·인용, 글머리·번호 목록, 굵게·기울임·밑줄·취소선, 정렬, 표(8×8까지) 지원
3) Enter는 다음 문단, Shift+Enter는 ● 목록 시작, Tab은 저장
4) 표 : Enter는 다음 칸(마지막 칸이면 행 추가), Alt+Enter는 칸 안 줄 바꿈
- 구분 "메모"는 삭제 불가한 고정 구분
- 메모 카드는 상대·사업 없이 본문만 표시
<그림>
#자. 기록 카드
○ 등록한 기록을 시간 기둥형 카드로 쌓아 하루 대화를 순서대로 확인
1) 카드는 2열, 최근 기록 우선(왼쪽 열 위→아래, 이어서 오른쪽 열)
2) 카드 더블클릭(또는 선택 후 Enter) 시 그 자리에서 수정, 바깥 클릭 시 저장
3) 사업 배지 클릭 시 선택 목록 표시, 검색란에서 사업 이름(초성 가능)으로 검색하여 지정
4) 삭제는 수정 중인 카드 왼쪽 아래 휴지통 클릭, "이 기록을 지울까요?" 확인 후 삭제
- 등록 시 상대의 첫 번째 사업이 자동 지정
- 수정 이력은 남기지 않음
#차. 챙길 일
○ 일지 작성 중 마감 임박 업무를 놓치지 않도록 오른쪽 아래에 모아 표시
1) 마감 7일 이내(경과 포함)이고 완료되지 않은 민원과 할 일을 마감순으로 표시
2) 항목 클릭 시 민원대장·할 일의 해당 항목으로 이동
