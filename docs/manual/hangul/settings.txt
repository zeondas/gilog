@화면 설정
@부제목 앱 전체와 모듈별 설정을 한 곳에서 바꾸는 도구
@기획의도
가. 비밀번호·잠금·테마·화면 크기·키 설정 등 앱 전체 설정과 모듈별 설정을 한 화면에 모음
나. 자동 잠금은 켜고 끌 수 있고, 잠기기까지 시간도 직접 지정
다. 바꾸는 즉시 저장, 언제든 "기본값으로 되돌리기"로 처음 값으로 복원
@기능별
가. 설정 찾기 : 설정 이름·설명으로 원하는 설정만 검색
나. 기본값으로 되돌리기 : 모든 설정을 처음 값으로 복원
다. 닫기 : 마지막으로 보던 화면으로 이동
라. 모듈 : 모듈마다 켜고 끄기, 끄면 사이드바에서 숨김
마. 일반 : 내 이름·테마·강조색·시작 화면·화면 크기·닫기 단추·자동 실행 지정
바. 보안·저장 : 앱을 열 때 암호 묻기, 자동 잠금, PIN 풀기, 암호 바꾸기, 백업
사. 키 설정 : enter·tab·esc 등 동작마다 키를 직접 지정
아. 모듈별 설정 : 탐색기·민원대장·민원처리·캘린더·업무일지·집행현황 설정
@상세
#가. 설정 찾기
○ 설정 항목이 많아, 찾을 글자만 입력하면 맞는 설정만 남도록 구현
1) 머리 줄 찾기 칸에 찾을 글자 입력, ctrl+f로도 찾기 칸으로 이동
2) 카드 이름·줄 이름·설명에 맞는 줄만 남고, 맞은 글자는 노랗게 표시
3) 옆에 "설정 N개"가 표시, 없으면 "맞는 설정이 없어요"
- 비슷한 말도 검색 가능("암호" → 비밀번호, "다크" → 테마)
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
#나. 기본값으로 되돌리기
○ 설정을 잘못 바꿨을 때 한 번에 처음 값으로 돌아가도록 제공
1) 머리 줄 "기본값으로 되돌리기" 단추를 누름
2) 한 번 더 확인 후 모든 설정을 처음 값으로 복원
- 암호, 저장 위치, 구글 연결, 저장한 자료는 그대로 유지
#다. 닫기
○ 설정을 마치고 하던 일로 바로 돌아가도록 제공
1) 머리 줄 오른쪽 x를 누르거나 사이드바 "설정"을 한 번 더 누름
2) 마지막으로 보던 화면으로 이동
- 아래로 내리면 오른쪽 아래 "맨 위로" 단추 표시
#라. 모듈
○ 쓰지 않는 화면은 사이드바에서 숨겨 필요한 메뉴만 남도록 구현
1) 공통 설정 맨 위 "모듈" 카드에서 모듈마다 스위치를 켜고 끔
2) 끄면 사이드바에서 그 메뉴가 사라지고, 아래 그 모듈의 설정 카드는 접힘
- 끄기는 메뉴 숨기기일 뿐, 자료는 그대로이고 다시 켜면 그대로 복원
- 적어도 모듈 하나는 켜 두어야 함
#마. 일반
○ 앱을 쓰는 사람과 화면 모양에 관한 기본 설정
1) 내 이름 : 일지 등에 쓰이는 내 이름
2) 테마 : 시스템·밝게·어둡게, 오른쪽 색 동그라미로 강조색(보라·녹투아 브라운·파랑·먹색) 선택
3) 시작 화면 : 앱을 켜면 처음 열리는 화면(처음 값 업무일지)
4) 화면 크기 : 12~17 가운데 선택(13 = 100%), 글자·칸·아이콘이 함께 커짐
5) 민원 마감 임박 표시 : 마감 며칠 전부터 임박으로 표시할지 지정(처음 값 2일 전)
6) 윈도우 시작할 때 자동 실행 : 켜면 컴퓨터를 켤 때 트레이에서 조용히 켜짐(처음 값 꺼짐)
7) 닫기(x) 단추 : 작업표시줄로 내림·트레이로 보냄·프로그램 종료 가운데 선택(처음 값 트레이로 보냄)
- 프로그램 종료를 고르면 앱이 꺼져 일정 알림이 오지 않음
#바. 보안·저장
○ 민원인 정보 등이 담긴 자료를 지키기 위한 잠금과 저장 설정
1) 앱을 열 때 암호 묻기 : 켜면 비밀번호를 넣어야 열림(처음 값 켬)
2) 자동 잠금 : 켜고 끄기, 입력이 없을 때 잠기기까지 시간을 5분·10분·30분·1시간 가운데 선택(처음 값 켬, 10분)
3) 윈도우 PIN으로 잠금 풀기 : 켜면 비밀번호 대신 윈도우 PIN으로 잠금 해제(처음 값 꺼짐, PC마다 따로)
4) 암호 바꾸기, 저장 위치 지정, 백업 내보내기·불러오기
- 암호를 잊으면 자료를 되찾을 방법이 없음
- 백업을 불러올 때는 그 파일의 암호를 입력
- 이 PC에서 PIN을 쓸 수 없으면 스위치가 흐리게 "이 PC에서는 쓸 수 없어요" 표시
#사. 키 설정
○ 손에 익은 키로 쓸 수 있도록 엔터규칙의 동작마다 키를 바꿀 수 있게 구현
1) 바꿀 동작의 칸을 누르고 쓰려는 키를 직접 누름
2) enter·tab·esc와 shift·ctrl·왼쪽 alt 조합 사용 가능
3) "기본값으로" 단추로 처음 키로 복원
- 같은 키가 겹치면 두 칸에 빨간 테두리가 생기고 저장하지 않음
- 오른쪽 alt는 한/영 키라 사용 불가
#아. 모듈별 설정
○ 화면마다 따로 필요한 설정을 사이드바 순서대로 카드로 정리
1) 탐색기 : 날짜 형식, 보이는 드라이브, 숨김 파일 보이기, 새 탭이 여는 폴더, 지울 때 묻기, 빠른 찾기
2) 민원대장 : 상태 목록, 접수유형 목록, 민원유형 목록
3) 민원처리 : 지시자, 폴더, 지시부 양식 등
4) 캘린더 : 쉬는 날 음영, 구글 연동(구글 로그인, 내 일정·민원 마감·할 일 마감 내보내기 켜고 끄기)
5) 업무일지 : 구분과 초성 단축키
6) 집행현황 : 팀 공유, 공유 시트, 함께 쓰는 사람
- 상태 "완료"는 마감 계산의 기준이라 지울 수 없음
- 목록에서 항목을 지워도 이미 적은 기록의 값은 그대로 남음
