@화면 설정
@부제목 앱 전체 및 모듈별 설정을 한 곳에서 변경하는 도구
@기획의도
가. 비밀번호·잠금·테마·화면 크기·키 설정 등 앱 전체 설정과 모듈별 설정을 한 화면에 통합
나. 자동 잠금 사용·해제 설정 및 잠금까지의 시간 직접 지정
다. 변경 즉시 저장, [기본값으로 되돌리기]로 언제든 초기값 복원
@기능별
가. 설정 찾기 : 설정 이름·설명으로 원하는 설정만 검색
나. 기본값으로 되돌리기 : 모든 설정을 초기값으로 복원
다. 닫기 : 직전에 보던 화면으로 이동
라. 모듈 : 모듈별 사용·해제 설정, 해제 시 사이드바에서 숨김
마. 일반 : 내 이름·테마·강조색·시작 화면·화면 크기·닫기 버튼·자동 실행 지정
바. 보안·저장 : 비밀번호 확인, 자동 잠금, PIN 잠금 해제, 비밀번호 변경, 백업
사. 키 설정 : Enter·Tab·Esc 등 동작별 키 직접 지정
아. 모듈별 설정 : 탐색기·민원대장·민원처리·집행현황·캘린더·업무일지 설정
@상세
#가. 설정 찾기
○ 설정 항목이 많아 검색어 입력 시 해당 설정만 표시되도록 구현
1) 상단 "설정 찾기" 입력란에 검색어 입력, Ctrl+F로도 입력란 이동
2) 카드 이름·항목 이름·설명이 일치하는 행만 표시, 일치 글자는 노란색 표시
3) 옆에 "설정 N개" 표시, 없으면 "맞는 설정이 없어요" 표시
- 유사어 검색 가능("암호" → 비밀번호, "다크" → 테마)
- 입력란 끝의 × 또는 Esc로 입력 내용 일괄 삭제
#나. 기본값으로 되돌리기
○ 설정을 잘못 변경한 경우 한 번에 초기값으로 복원하도록 제공
1) 상단 [기본값으로 되돌리기] 클릭
2) 재확인 후 [되돌리기] 클릭 시 모든 설정을 초기값으로 복원
- 비밀번호, 저장 위치, 구글 연결, 저장된 자료는 그대로 유지
#다. 닫기
○ 설정 완료 후 하던 업무로 바로 복귀하도록 제공
1) 상단 오른쪽 × 클릭 또는 사이드바 "설정" 재클릭
2) 직전에 보던 화면으로 이동
- 아래로 스크롤하면 오른쪽 아래 "맨 위로" 버튼 표시
#라. 모듈
○ 사용하지 않는 화면은 사이드바에서 숨겨 필요한 메뉴만 남도록 구현
1) 공통 설정 맨 위 "모듈" 카드에서 모듈별 스위치로 사용·해제 설정
2) 해제 시 사이드바에서 해당 메뉴가 숨겨지고, 아래 해당 모듈의 설정 카드는 접힘
- 해제는 메뉴 숨김일 뿐 자료는 유지, 다시 사용 설정 시 그대로 복원
- 최소 1개 모듈은 사용 설정 필요
#마. 일반
○ 사용자와 화면 표시에 관한 기본 설정
1) 내 이름 : 업무일지 대화 기록에서 본인 발언에 표시되는 이름
2) 테마 : 시스템·밝게·어둡게, 오른쪽 색 동그라미로 강조색(보라·녹투아 브라운·파랑·먹색) 선택
3) 시작 화면 : 앱 실행 시 처음 표시되는 화면(초기값 업무일지)
4) 화면 크기 : 12~17 중 선택(13 = 100%), 글자·입력란·아이콘이 함께 확대
5) 민원 마감 임박 표시 : 마감 며칠 전부터 임박으로 표시할지 지정(초기값 2일 전)
6) 윈도우 시작할 때 자동 실행 : 사용 설정 시 컴퓨터 부팅 때 트레이에서 자동 실행(초기값 해제)
7) 닫기(X) 단추 : 작업표시줄로 내림·트레이로 보냄·프로그램 종료 중 선택(초기값 트레이로 보냄)
- 프로그램 종료 선택 시 앱이 종료되어 일정 알림이 오지 않음
#바. 보안·저장
○ 민원인 정보 등이 담긴 자료 보호를 위한 잠금 및 저장 설정
1) 앱을 열 때 비밀번호 묻기 : 사용 설정 시 비밀번호 입력 후 실행(초기값 사용)
2) 자동 잠금 : 사용·해제 설정, 미입력 시 잠금까지 시간을 5분·10분·30분·1시간 중 선택(초기값 사용, 10분)
3) 윈도우 PIN으로 잠금 풀기 : 사용 설정 시 비밀번호 대신 윈도우 PIN으로 잠금 해제(초기값 해제, PC별 설정)
4) [비밀번호 바꾸기], 저장 위치 [폴더 바꾸기], [백업 내보내기]·[불러오기]
- 비밀번호 분실 시 자료 복구 불가
- 백업 불러오기 시 해당 백업 파일의 비밀번호 입력
- 이 PC에서 PIN 사용이 불가하면 "이 PC에서는 쓸 수 없어요" 표시
#사. 키 설정
○ 손에 익은 키로 사용하도록 엔터규칙의 동작별 키를 변경할 수 있게 구현
1) 변경할 동작의 입력란 클릭 후 사용할 키를 직접 누름
2) Enter·Tab·Esc와 Shift·Ctrl·왼쪽 Alt 조합 지정 가능, "잠그기"는 Ctrl·왼쪽 Alt + 글자 키(초기값 Ctrl+L)
3) [기본값으로] 클릭 시 초기 키로 복원
- 같은 키가 겹치면 해당 입력란에 빨간 테두리가 표시되고 저장되지 않음
- 오른쪽 Alt는 한/영 키라 사용 불가
#아. 모듈별 설정
○ 화면별로 필요한 설정을 사이드바 순서대로 카드로 정리
1) 탐색기 : 날짜 형식(8종, 초기값 Windows), 드라이브 단추, 폴더 트리, 빠른 찾기, 보이는 열, 숨김 파일 보이기 등
2) 민원대장 : 접수유형, 민원유형, 위치 표기(법정동·행정동), 웹에서 주소 찾기, 주소 자료
3) 민원처리 : 민원 폴더 등 폴더 4종, 지시부 양식, 메일 제목·본문, Claude 모델, AI 지침 등
4) 집행현황 : 팀 공유, 공유 시트, 함께 쓰는 사람
5) 캘린더 : 쉬는 날 음영, 구글 연동(구글 로그인, 내 일정·민원 마감·할 일 마감 내보내기 사용·해제)
6) 업무일지 : 구분과 초성 단축키
- 민원 상태(접수·진행·답변·완료·불가·보류·장기)는 고정값으로 변경 불가
- 접수유형·민원유형 삭제 시 사용 중인 민원이 있으면 "합칠 값" 선택 후 [합치고 지우기]
