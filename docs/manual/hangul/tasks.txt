@기획의도

나. "민원" 목록에는 민원대장의 기한 있는 민원이 자동으로 들어와 답변 기한을 놓치지 않도록 구현
다. 마감 배지로 급한 일을 먼저 보고, 끝낸 일은 아래로 접어 남은 일만 집중
@기능별
가. 검색 : 할 일을 글자로 검색, 남은 일 건수 표시
나. 목록 칸 : 새 목록 만들기, 목록 카드 보이기·숨기기
다. 새 할 일 : 카드 맨 위 칸에서 제목·세부정보·날짜를 바로 등록
라. 할 일 항목 : 제목을 눌러 펼친 뒤 그 자리에서 수정·삭제
마. 체크 : 할 일 완료 표시, 위 항목과 하위 항목 함께 완료
바. 민원 목록 : 민원대장의 기한 있는 민원을 자동으로 표시, 체크하면 답변으로 변경
사. 마감 배지 : 오늘·임박·지남을 색으로 구분
아. 하위 항목 : 항목 아래 한 단계 들여 쓴 세부 할 일
자. 완료됨·목록 메뉴 : 끝낸 일을 카드 아래로 접기, 우클릭으로 목록 이름 바꾸기·옮기기·지우기
@상세
#가. 검색
○ 목록이 많아져도 원하는 할 일을 바로 찾도록 제목 줄에 검색 제공
1) 제목 줄 오른쪽 검색 칸에 글자 입력, 치는 대로 바로 걸러 표시
2) 맞는 글자는 형광 표시
3) 제목 옆 숫자는 남은 일 건수
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
#나. 목록 칸
○ 업무 성격별로 목록을 나누고, 지금 필요한 목록만 골라 보도록 구현
1) 왼쪽 맨 위 "새 목록 만들기"로 목록 생성
2) 목록 앞 체크로 그 목록 카드를 보이거나 숨김
3) 목록을 우클릭하면 이름 바꾸기·위로/아래로 옮기기·목록 지우기
- "민원" 목록은 지울 수 없고 순서만 옮김
- 목록을 지우면 딸린 할 일도 삭제, 지우기 전에 할 일 수를 알려 주고 확인
<그림>
#다. 새 할 일
○ 카드마다 입력 칸이 늘 열려 있어 생각나는 즉시 적도록 구현
1) 카드 맨 위 제목 칸을 누르면 세부정보와 날짜 칸이 펼쳐짐
2) 제목 → tab 세부정보 → tab 날짜 순서로 입력
3) 아무 칸에서 enter, 또는 날짜 칸에서 tab으로 등록, esc는 닫기
4) 날짜는 칸에 직접 적거나 달력 단추를 눌러 작은 달력에서 고름
  - 세부정보는 머릿기호 규칙(● 기본) 적용
  - 바깥을 누르면 적던 것을 저장하고 접힘, 제목이 비어 있으면 접기만
  - 날짜를 읽을 수 없으면 등록하지 않고 빨간 테두리 표시

#라. 할 일 항목
○ 항목을 누르는 그 자리에서 내용을 보고 고치도록 구현
1) 항목 제목을 누르면 세부정보가 펼쳐짐
2) 펼친 상태에서 제목·세부정보·날짜 수정, 바깥을 누르면 저장
3) 펼친 항목의 ×로 삭제, "지울까요?"를 한 번 더 확인
- 정렬은 마감일이 빠른 것이 위, 마감일 없는 것이 아래
#마. 체크
○ 끝낸 일을 체크 한 번으로 정리하고, 체크하는 손맛까지 구글 할 일처럼 구현
1) 항목 왼쪽 동그라미를 누르거나 space로 체크
2) 마우스를 올리면 연한 체크가 미리 보이고, 누르면 원이 차오르며 체크가 그려진 뒤 "완료됨"으로 내려감
3) 위 항목을 완료하면 하위 항목도 함께 완료, 되돌리면 하위도 함께 되돌아감
4) 하위 항목을 되돌리면 위 항목도 되돌아감
- 윈도우 "애니메이션 효과"를 끄면 움직임 없이 바로 내려감
#바. 민원 목록
○ 민원대장에서 마감일(법정 답변기한)이 있는 민원을 자동으로 모아 할 일처럼 챙기도록 구현
1) 민원 항목 제목은 "접수유형(지역 위치)", "민원대장 연동" 표시가 붙음
2) 체크하면 민원대장 상태가 "답변"으로 바뀌고, 체크를 풀면 그 전 상태로 복귀
3) 항목을 두 번 누르면 민원대장의 그 줄로 이동
4) "민원" 목록에 직접 할 일을 더할 수도 있음
  - 제목과 마감일은 민원대장에서만 수정
  - 답변이 끝난 민원(답변·완료·불가·보류·장기)은 체크된 채 "완료됨"에 들어감
  - 답변이 끝난 민원은 마감이 30일 안쪽인 것만 "완료됨"에 남음
#사. 마감 배지
○ 마감이 가까운 일을 색으로 먼저 알아보도록 항목마다 마감 배지 표시
1) 오늘이 마감이면 파랑
2) 임박 기준 안이거나 지났으면 빨강
3) 임박 기준보다 하루 더 남았으면 주황
- 임박 기준은 설정 → 일반 카드 → 민원 마감 임박 표시(기본 2일 전부터)
#아. 하위 항목
○ 큰 일을 작은 단계로 나눠 챙기도록 한 단계 아래 항목 제공
1) 항목을 펼친 뒤 "하위 항목 추가"를 누르면 한 단계 들여 쓴 항목 생성
2) 입력 방법은 새 할 일과 같음
- 하위 항목은 한 단계까지만 가능
#자. 완료됨·목록 메뉴
○ 끝낸 일은 접어 두고, 카드에서 바로 목록을 정리하도록 구현
1) 완료한 항목은 카드 아래 "완료됨 (N개)"에 접혀 들어감
2) 카드 제목 줄을 우클릭하면 "목록 지우기", 들어 있는 할 일 수를 알려 주고 "지울까요?"를 한 번 더 확인
- "민원" 목록은 지울 수 없음
