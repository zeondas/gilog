@기획의도
가. 구글 할 일처럼 목록별 카드로 나누어 할 일 관리, 기본으로 "민원"과 "행정업무" 목록 제공
나. "민원" 목록에는 민원대장의 기한 있는 민원이 자동 표시되어 답변기한 누락 방지
다. 마감 배지로 급한 일을 우선 확인하고, 완료한 일은 아래로 접어 남은 일에 집중
@기능별
가. 검색 : 할 일을 입력한 글자로 검색, 남은 일 건수 표시
나. 목록 영역 : 새 목록 만들기, 목록 카드 표시·숨김
다. 새 할 일 : 카드 맨 위 입력란에서 제목·세부정보·날짜를 즉시 등록
라. 할 일 항목 : 클릭하여 펼친 뒤 해당 위치에서 수정·삭제
마. 체크 : 할 일 완료 표시, 상위 항목과 하위 항목 함께 완료
바. 민원 목록 : 민원대장의 기한 있는 민원을 자동 표시, 체크 시 답변으로 변경
사. 마감 배지 : 오늘·임박·경과를 색으로 구분
아. 하위 항목 : 항목 아래 한 단계 들여 쓴 세부 할 일
자. 완료됨·목록 메뉴 : 완료한 일을 카드 아래로 접기, 우클릭으로 목록 이름 변경·이동·삭제
@상세
#가. 검색
○ 목록이 많아져도 원하는 할 일을 즉시 찾도록 상단에 검색 제공
1) 상단 오른쪽 검색란에 글자 입력, 입력하는 대로 즉시 필터
2) 일치하는 글자는 형광 표시
3) 제목 옆 "남은 일 N건"은 완료하지 않은 할 일 건수
- 입력란 끝 × 또는 Esc로 입력한 글자 일괄 삭제
#나. 목록 영역
○ 업무 성격별로 목록을 나누고, 필요한 목록만 선택하여 보도록 구현
1) 왼쪽 맨 위 "새 목록 만들기"에 이름 입력 후 Enter로 목록 생성
2) 목록 앞 체크로 해당 목록 카드 표시·숨김
3) 목록 우클릭 메뉴 : "이름 바꾸기"·"위로 옮기기"·"아래로 옮기기"·"목록 지우기"
- "민원" 목록은 삭제 불가, 순서만 이동 가능
- 목록 삭제 시 소속 할 일도 삭제, 삭제 전 할 일 수를 안내하고 확인

#다. 새 할 일
○ 카드마다 입력란이 항상 열려 있어 생각나는 즉시 기록하도록 구현
1) 카드 맨 위 "할 일 추가"를 클릭하면 세부정보와 날짜 입력란이 펼쳐짐
2) 제목 → 세부정보 → 날짜 순서로 입력, Tab으로 다음 입력란 이동
3) 날짜 입력란에서 Enter 또는 Tab으로 등록, Esc는 닫기
4) 날짜는 직접 입력하거나 달력 버튼을 클릭하여 작은 달력에서 선택
  - 세부정보는 머릿기호 규칙(● 기본) 적용, Enter는 같은 위계 다음 줄
  - 바깥 클릭 시 입력 중인 내용을 저장하고 접힘, 제목이 비어 있으면 접기만
  - 날짜를 인식할 수 없으면 등록하지 않고 빨간 테두리 표시

#라. 할 일 항목
○ 항목을 클릭한 위치에서 내용을 확인하고 수정하도록 구현
1) 항목을 클릭하면 세부정보와 [하위 항목 추가]·[고치기] 버튼 표시
2) 더블클릭 또는 [고치기]로 제목·세부정보·날짜 수정, 바깥 클릭 시 저장, Esc는 취소
3) 펼친 항목의 휴지통 버튼으로 삭제, "이 할 일을 지울까요?"를 한 번 더 확인
- 정렬은 마감일이 빠른 항목이 위, 마감일 없는 항목이 아래
#마. 체크
○ 완료한 일을 체크 한 번으로 정리하고, 체크하는 조작감까지 구글 할 일처럼 구현
1) 항목 왼쪽 원을 클릭하거나 Space로 체크
2) 마우스를 올리면 연한 체크 미리 표시, 클릭하면 원이 차오르며 체크된 뒤 "완료됨"으로 이동
3) 상위 항목 완료 시 하위 항목도 함께 완료, 되돌리면 하위 항목도 함께 복원
4) 하위 항목을 되돌리면 상위 항목도 복원
- 윈도우 "애니메이션 효과"를 해제하면 움직임 없이 즉시 이동
#바. 민원 목록
○ 민원대장에서 마감일(법정 답변기한)이 있는 민원을 자동으로 모아 할 일처럼 관리하도록 구현
1) 민원 항목 제목은 "접수유형(지역 위치)", 카드 제목에 "민원대장 연동" 표시
2) 체크하면 민원대장 상태가 "답변"으로 변경, 체크 해제 시 이전 상태로 복원
3) 항목을 더블클릭하거나 [민원대장에서 보기]를 클릭하면 민원대장의 해당 행으로 이동
4) "민원" 목록에 할 일 직접 추가 가능
  - 제목과 마감일은 민원대장에서만 수정
  - 답변이 끝난 민원(진행·답변·완료·불가·보류·장기)은 체크된 상태로 "완료됨"에 표시
  - 답변이 끝난 민원은 마감일이 30일 이내인 것만 "완료됨"에 유지
#사. 마감 배지
○ 마감이 가까운 일을 색으로 우선 확인하도록 항목별 마감 배지 표시
1) 오늘이 마감이면 파란색("오늘")
2) 임박 기준 이내이거나 경과했으면 빨간색
3) 임박 기준보다 하루 더 남았으면 주황색
- 임박 기준은 설정 → 일반 카드 → 민원 마감 임박 표시(기본 2일 전부터)
#아. 하위 항목
○ 큰 일을 작은 단계로 나누어 관리하도록 한 단계 아래 항목 제공
1) 항목을 펼친 뒤 [하위 항목 추가]를 클릭하면 한 단계 들여 쓴 항목 생성
2) 입력 방법은 새 할 일과 동일
- 하위 항목은 한 단계까지만 가능
- 하위 항목이 있는 항목을 삭제하면 하위 항목도 함께 삭제
#자. 완료됨·목록 메뉴
○ 완료한 일은 접어 두고, 카드에서 즉시 목록을 정리하도록 구현
1) 완료한 항목은 카드 아래 "완료됨 (N개)"에 접혀 들어감
2) 카드 제목 행을 우클릭하면 "목록 지우기", 소속 할 일 수를 안내하고 "지울까요?"를 한 번 더 확인
- "민원" 목록은 삭제 불가
