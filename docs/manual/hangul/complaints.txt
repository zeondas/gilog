@화면 민원대장
@부제목 모든 민원을 하나의 플랫폼에 정리하여, 민원 처리에 빈틈이 없도록 활용하는 도구
@기획의도
가. 국민신문고·진정민원·정보공개청구·유선·메신저 등 여러 창구로 접수된 민원을 하나의 양식으로 정리
나. 시공사 업무지시 여부와 완료 여부를 한눈에 확인하는 처리 현황판으로 활용
다. 답변기한이 있는 민원은 캘린더·할 일과 연계하여 기한 누락 방지
라. 지역·위치·접수유형·처리 소요 기간 등 처리 민원을 업무 통계 기초자료로 축적
@기능별
가. 상태 칩 : 선택한 상태의 민원만 표시, 열 제목 필터와 함께 작동
나. 열 폭 조정 : 열 경계 드래그·더블클릭으로 열 폭 조정, 열마다 저장
다. 분류 관리 : 접수유형·민원유형 목록의 추가·삭제
라. 검색 : 표 안의 민원을 입력한 글자로 즉시 검색
마. 엑셀 : 엑셀 민원대장 가져오기·내보내기
바. 신규 행 : 표 맨 윗행에서 즉시 등록, 더블클릭으로 해당 행 수정
사. 위치 : 법정리·법정동과 지번을 초성으로 입력, 지역은 자동 입력
아. 마감일 : 법정 답변기한과 남은 일수 표시
자. 상태 : 배지 클릭으로 처리 상태 즉시 변경, 조치완료일 자동 입력
차. 메모 : 민원별로 별도 기재하는 메모
@상세
#가. 상태 칩
○ 접수·진행·답변·보류·장기·완료·불가 7개 상태로 민원을 필터하는 기능, 처리 중인 민원만 선택하여 현황판으로 활용
1) 표 위 상태 칩을 클릭하면 해당 상태의 민원만 표시
2) 여러 칩 동시 선택 가능, 칩 옆 숫자는 건수
3) "전체" 클릭 시 상태 필터 해제
4) 열 제목 필터 : 접수유형·민원유형·위치·상태 열 제목 클릭 시 엑셀 필터처럼 값 목록 표시, 체크한 값만 표시
- 필터가 적용된 열 제목은 강조 표시, 칩 행 오른쪽에 적용 조건 표시(×로 해제, 둘 이상이면 "모두 풀기")
- 상태 칩과 상태 열 필터는 같은 필터, 검색과도 함께 작동
- 앱 재실행 시 상태 필터만 유지, 나머지는 해제
<그림>
#나. 열 폭 조정
○ 열마다 폭을 직접 조정하는 기능, 조정한 폭은 열마다 저장되어 다음 실행 시에도 유지
1) 열 제목 오른쪽 경계를 드래그하면 해당 열 폭만 변경
2) 열 합계가 창보다 넓어지면 표 안에서 가로 스크롤
3) 경계를 더블클릭하면 해당 열을 내용에 맞춤
4) 열 제목 행 우클릭 : "내용에 맞춤(모든 열)", "처음 폭으로"
- 조정하지 않은 열은 글 길이와 창 폭에 맞춘 기본 폭으로 표시
- 창이 좁으면 마감일은 D-day만, 접수일은 짧은 날짜로 줄여 표시, 창을 넓히면 복원
#다. 분류 관리
○ 접수유형·민원유형 목록을 정리하는 창, 설정의 민원대장 항목과 같은 목록이라 어느 쪽에서 수정해도 함께 변경
1) 상단 [분류 관리]를 클릭
2) 묶음 아래 입력란에 새 이름을 입력하고 [추가] 클릭 또는 Enter
3) 항목별 × 버튼으로 삭제, "지울까요?" 확인 후 삭제
4) 해당 값을 쓰는 민원이 있으면 합칠 값을 선택하고 [합치고 지우기]
- 사용 중인 민원이 0건이면 확인만 거쳐 즉시 삭제
- 상태 7개는 고정이므로 목록에서 제외
#라. 검색
○ 민원대장의 민원만 대상으로 입력할 때마다 즉시 필터하는 검색, 일치하는 글자는 형광 표시
1) 상단 검색란에 검색어 입력(위치·내용·민원인 등)
2) 입력하는 대로 표가 필터됨
- 상태 칩·열 제목 필터와 함께 작동
- 입력란 끝 × 또는 Esc로 입력한 글자 일괄 삭제
#마. 엑셀
○ 기존 엑셀 민원대장을 그대로 옮겨 오고, 전체 민원을 엑셀 민원대장 양식으로 내보내는 기능
1) 상단 [엑셀 ▾]를 클릭
2) 가져오기 : 파일 선택 후 "어떻게 가져올까요?" 창에서 방식 선택
3) "덮어쓰기" : 같은 민원은 파일 내용으로 갱신, 새 민원은 추가, 파일에 없는 민원은 유지
4) "대체하기" : 현재 민원을 모두 삭제하고 파일 내용만 등록(되돌릴 수 없음)
5) 내보내기 : 저장 위치 지정 시 전체 민원을 "민원대장_날짜" 파일로 저장, 마지막 폴더 기억
- 같은 민원 판단 기준은 접수일·접수유형·위치
- 위치가 도로명주소이면 가져올 때 리·동과 지번으로 자동 변환
- 내보낸 파일에는 민원인 이름·연락처도 포함, 취급에 주의
#바. 신규 행
○ 표 맨 윗행이 항상 열려 있는 입력 행, 접수 창구와 관계없이 같은 양식으로 즉시 기록
1) 맨 윗행 입력란에 차례로 입력, Tab 또는 Enter로 다음 입력란 이동
2) 마지막 입력란(상태)에서 Enter를 누르면 등록, 입력란 하나만 입력해도 등록 가능
3) 접수일은 오늘 날짜가 미리 입력됨, 1015·261015처럼 줄여 입력해도 입력란을 벗어나면 2026-10-15로 변환
4) 내용·조치내용은 여러 줄 입력란, Enter는 같은 위계 다음 줄, Shift+Enter는 한 위계 아래 줄, 왼쪽 Alt+Enter는 항목 안 줄 바꿈
5) 등록한 행을 더블클릭하면 해당 행 전체 수정, 바깥 클릭 시 저장, Esc는 취소
6) 행 우클릭 메뉴 : "고치기"·"위치 복사"·"민원인 복사"·"지우기"
- 연번은 접수일 순서로 자동 부여, 삭제 시 아래 번호가 앞당겨짐
- 접수유형·민원유형은 분류 관리 목록에서 초성으로 선택하여 입력
- 접수유형·민원유형이 길면 한 줄에 "…"로 표시, 마우스를 올리면 전체 표시
- 민원인 입력란에는 이름·기관·연락처를 한 입력란에 입력, 클릭하면 복사
<그림>
#사. 위치
○ 담당자가 법정동 기준으로 지번을 검색하는 업무 방식에 맞춰, 위치는 법정리·법정동과 지번으로 기록하고 지역(읍면동)은 위치에서 자동 입력
1) 위치 입력란 맨 앞에 리·동 이름을 초성으로 입력(예: ㅂㅇㅊ)
2) 후보 목록에서 ↑·↓로 선택하고 Tab으로 확정, 지번을 이어서 입력
3) 리·동을 선택하면 앞에 읍면동 지역이 자동 입력
4) 도로명주소를 입력하면 리·동과 지번으로 변환하여 입력
- 여러 행정동에 걸친 법정동(동패동 등)은 행정동까지 선택하여 입력
- "대원리1234"처럼 붙여 입력해도 입력란을 벗어나면 "대원리 1234"로 정리
- 목록에 없는 타 시 주소도 그대로 입력 가능
- 표기 방식(행정동·법정동)은 설정 → 민원대장 카드 → 위치 표기에서 변경
- 위치를 클릭하면 복사되어 다른 문서에 즉시 붙여 넣기 가능
#아. 마감일
○ 법정 답변기한을 입력하고 남은 일수를 표시하는 입력란, 캘린더·할 일·업무일지 챙길 일과 연계하여 기한 누락 방지
1) 마감일 입력란에 답변기한 날짜 입력
2) 날짜 바로 뒤에 남은 일수(D-2) 표시
3) 답변이 끝난 상태(진행·답변·완료·불가·보류·장기)가 되면 마감일 자리에 흐린 체크 표시, 마우스를 올리면 마감일 확인
- 마감일이 있는 민원은 할 일 "민원" 목록과 캘린더에 자동 표시
- 할 일에서 민원을 체크하면 민원대장 상태가 "답변"으로 변경
- 남은 일수는 상태가 "접수"일 때만 표시
#자. 상태
○ 민원의 처리 단계를 배지로 표시, 확인할 순서대로 색을 달리하여 처리 현황을 한눈에 확인
1) 행의 상태 배지를 클릭하면 상태 목록 표시
2) 접수·진행·답변·보류·장기·완료·불가 중 선택하여 즉시 변경
3) 완료·불가로 변경 시 조치완료일에 오늘 날짜 자동 입력, 다른 상태로 되돌리면 삭제
4) 조치완료일 열은 기본으로 접혀 있으며, 열 제목 › 버튼으로 펼침
- 조치완료일 뒤에 접수부터 소요 기간을 흐린 글자로 표시(예: 4d, 3m), 처리 소요 기간 통계로 활용
- 조치완료일을 직접 입력하면 상태가 완료로 변경
- 완료·불가 민원은 행 글자가 흐리게 표시
#차. 메모
○ 표에 기재하지 않을 통화 내용·진행 경과 등을 민원별로 별도 기재하는 메모
1) 행의 메모 버튼을 클릭하면 메모 창 표시
2) 머릿기호 규칙대로 입력, Enter는 같은 위계 다음 줄, Shift+Enter는 한 위계 아래 줄
3) Tab, 창 바깥 클릭, 오른쪽 위 ×는 저장 후 닫기, Esc는 취소
- 굵게(Ctrl+B)·취소선, 줄 위·아래 이동 지원
- 민원 삭제 시 메모도 함께 삭제
