@화면 민원대장
@부제목 모든 민원을 하나의 플랫폼에 정리하여, 민원 처리에 빈틈이 없도록 활용하는 도구
@기획의도
가. 국민신문고·진정민원·정보공개청구·유선·메신저 등 여러 창구로 들어온 민원을 하나의 양식으로 정리
나. 시공사 업무지시 여부와 완료 여부를 한눈에 확인하는 처리 현황판으로 활용
다. 답변기한이 있는 민원은 캘린더·할 일과 연계하여 기한을 놓치지 않도록 관리
라. 지역·위치·접수유형·처리 소요 기간 등 처리한 민원을 업무 통계 기초자료로 축적
@기능별
가. 상태 칩 : 고른 상태의 민원만 표시, 열 제목 거르기와 함께 작동
나. 배치최적화 : 글 길이에 맞춰 열 폭을 한 번에 정리
다. 분류 관리 : 접수유형·민원유형 목록을 추가·수정·삭제
라. 검색 : 표 안의 민원을 글자로 바로 검색
마. 엑셀 : 엑셀 민원대장 가져오기·내보내기
바. 신규 줄 : 표 맨 윗줄에서 바로 등록, 두 번 눌러 그 자리에서 수정
사. 위치 : 법정리·법정동과 지번을 초성으로 입력, 지역은 자동 입력
아. 마감일 : 법정 답변기한과 남은 날 표시
자. 상태 : 배지를 눌러 처리 상태를 바로 변경, 조치완료일 자동 입력
차. 메모 : 민원마다 따로 적어 두는 메모
@상세
#가. 상태 칩
○ 접수·진행·답변·보류·장기·완료·불가 7개 상태로 민원을 걸러 보는 기능, 처리 중인 민원만 골라 보며 현황판으로 활용하도록 구현
1) 표 위 상태 칩을 누르면 그 상태의 민원만 표시
2) 여러 칩을 함께 골라 보기 가능, 칩 옆 숫자는 건수
3) "전체"를 누르면 거르기 해제
4) 열 제목 거르기 : 접수유형·민원유형·위치·상태 열 제목을 누르면 엑셀 필터처럼 값 목록이 열리고, 체크한 값만 표시
- 거르기가 걸린 열 제목은 보라 바탕으로 표시, 칩 줄 오른쪽에 걸린 조건과 "N건 중 M건" 표시
- 상태 칩과 상태 열 거르기는 같은 거르기, 검색과도 함께 작동
- 앱을 다시 켜면 상태 거르기만 남고 나머지는 해제
<그림>
#나. 배치최적화
○ 민원 전체의 글 길이를 재어 열마다 알맞은 폭으로 맞추는 기능, 1600×900 창에서 가로 스크롤 없이 한 화면에 보이도록 구현
1) 머리 줄 오른쪽 [배치최적화]를 누름
2) 내용·조치내용을 뺀 열이 가장 긴 글에 맞춰지고, 남는 폭은 내용·조치내용이 반씩 차지
3) 열 제목 끝선을 끌면 그 열 폭만 바꾸고 기억
- 끌어서 바꾼 폭도 [배치최적화]나 열 제목 줄 우클릭 "열 너비 초기화"로 처음 폭으로 복귀
- 창이 좁아지면 마감일은 D-day만, 접수일은 짧은 날짜로 차례로 줄여 표시, 창을 넓히면 다시 풀림
#다. 분류 관리
○ 접수유형·민원유형 목록을 정리하는 창, 설정의 민원대장 항목과 같은 목록이라 어느 쪽에서 고쳐도 함께 변경
1) 머리 줄 [분류 관리]를 누름
2) 묶음 아래 칸에 새 이름을 입력하고 "＋ 추가"
3) 줄마다 쓰는 곳 수가 보이고, 지우기 단추로 삭제
- 삭제 시 "지울까요? 이미 적은 민원은 그대로예요"를 한 번 확인
- 상태 7개는 고정이라 목록에서 제외
#라. 검색
○ 민원대장의 민원만 대상으로 글자를 칠 때마다 바로 거르는 검색, 맞는 글자는 형광 표시
1) 머리 줄 검색 칸에 찾을 글자를 입력
2) 입력하는 대로 표가 걸러짐
- 상태 칩·열 제목 거르기와 함께 작동
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
#마. 엑셀
○ 기존 엑셀 민원대장을 그대로 옮겨 오고, 전체 민원을 엑셀 민원대장 양식으로 내보내는 기능
1) 머리 줄 [엑셀 ▾]를 누름
2) 가져오기 : 파일을 고르면 "민원대장 N건을 가져올까요?"를 한 번 확인한 뒤 모든 줄을 그대로 등록
3) 내보내기 : 저장할 곳을 정하면 전체 민원을 "민원대장_날짜" 파일로 저장, 마지막 폴더 기억
- 가져오기는 빈 줄만 건너뛰고 중복 검사는 하지 않음, 겹친 민원은 골라 삭제
- 내보낸 파일에는 민원인 이름·연락처도 포함, 취급에 주의
#바. 신규 줄
○ 표 맨 윗줄이 늘 열려 있는 입력 줄, 창구와 상관없이 들어온 민원을 같은 양식으로 바로 기록
1) 맨 윗줄 칸에 차례로 입력, tab 또는 enter로 다음 칸 이동
2) 마지막 칸에서 enter를 누르면 등록, 칸 하나만 적어도 등록 가능
3) 접수일은 오늘 날짜가 미리 채워져 있음, 1015·261015처럼 줄여 써도 칸을 떠나면 2026-10-15로 변경
4) 내용·조치내용은 여러 줄 칸, enter는 같은 위계 다음 줄, shift+enter는 한 위계 아래 줄, 왼쪽 alt+enter는 항목 안 줄 바꿈
5) 등록한 줄을 두 번 누르면 그 자리에서 줄 전체 수정, 바깥을 누르면 저장, esc는 취소
6) 줄 우클릭 메뉴 : 고치기·위치 복사·민원인 복사·지우기
- 연번은 접수일 순서로 자동 부여, 삭제하면 아래 번호가 당겨짐
- 접수유형·민원유형은 분류 관리 목록에서 초성으로 골라 입력
- 민원인 칸에는 이름·기관·연락처를 한 칸에 적고, 한 번 누르면 복사
<그림>
#사. 위치
○ 담당자들이 법정동 기준으로 지번을 찾는 업무 방식에 맞춰, 위치는 법정리·법정동과 지번으로 기록하고 지역(읍면동)은 위치에서 자동으로 채우도록 구현
1) 위치 칸 맨 앞에 리·동 이름을 초성으로 입력(예: ㅂㅇㅊ)
2) 후보 목록에서 ↑↓로 고르고 tab으로 확정, 지번을 이어서 입력
3) 리·동을 고르면 앞에 읍면동 지역이 자동 입력
4) 도로명주소를 입력하면 리·동과 지번으로 바꿔 입력
- 여러 행정동에 걸친 법정동(동패동 등)은 행정동까지 골라 입력
- "대원리1234"처럼 붙여 써도 칸을 떠나면 "대원리 1234"로 정리
- 목록에 없는 다른 시 주소도 그대로 입력 가능
- 표기 방식(행정동·법정동)은 설정 → 민원대장 카드 → 위치 표기에서 변경
- 한 번 누르면 위치가 복사되어 다른 문서에 바로 붙여 넣기 가능
#아. 마감일
○ 법정 답변기한을 적어 두고 남은 날을 표시하는 칸, 캘린더·할 일·업무일지 챙길 일과 연계되어 기한을 놓치지 않도록 구현
1) 마감일 칸에 답변기한 날짜를 입력
2) 날짜 바로 뒤에 남은 날(D-2)이 표시
3) 답변이 끝난 상태(진행·답변·완료·불가·보류·장기)가 되면 마감일 자리에 흐린 체크로 표시, 마우스를 올리면 마감일 확인
- 마감일이 있는 민원은 할 일 "민원" 목록과 캘린더에 자동 표시
- 할 일에서 민원을 체크하면 민원대장 상태가 "답변"으로 변경
- 남은 날은 상태가 "접수"일 때만 표시
#자. 상태
○ 민원의 처리 단계를 배지로 표시, 신경 쓸 순서대로 색을 달리해 처리 현황을 한눈에 확인하도록 구현
1) 줄의 상태 배지를 누르면 상태 목록이 열림
2) 접수·진행·답변·보류·장기·완료·불가 중 골라 바로 변경
3) 완료·불가로 바꾸면 조치완료일에 오늘 날짜가 자동 입력, 다른 상태로 돌리면 비움
4) 조치완료일 열은 처음에 접혀 있고, 열 제목 › 단추로 펼침
- 조치완료일 뒤에는 접수부터 걸린 기간이 흐린 글자로 표시(예: 4d, 3m), 처리 소요 기간 통계로 활용
- 조치완료일을 직접 적으면 상태가 완료로 변경
- 완료·불가 민원은 줄 글자가 흐리게 표시
#차. 메모
○ 표에 올리지 않을 통화 내용·진행 경과 등을 민원마다 따로 적어 두는 메모
1) 줄의 메모 칸을 누르면 메모 창이 열림
2) 머릿기호 규칙대로 입력, enter는 같은 위계 다음 줄, shift+enter는 한 위계 아래 줄
3) tab, 창 바깥 누르기, 오른쪽 위 x는 저장하고 닫기, esc는 취소
- 굵게(ctrl+b)·취소선, 줄 위·아래 옮기기 지원
- 민원을 지우면 메모도 함께 삭제
