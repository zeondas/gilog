@기능별추가
자. 파일 목록 : 윈도우 탐색기와 같은 손버릇으로 파일 열기·복사·옮기기·지우기
차. 문서보안 해제 : 보안이 걸린 파일을 윈도우 탐색기로 넘겨 바로 해제
@상세
#나. 탐색기 탭
○ 탐색기 창마다 여러 폴더를 탭으로 열어 두고 오가도록 구현, 자주 쓰는 폴더는 탭 고정으로 늘 유지
1) 탭 줄 끝 + 를 누르면 새 탭 열림(새 탭이 여는 폴더는 설정 → 탐색기 카드 → 새 탭이 여는 폴더)
2) 탭 고정 : 늘 열어 둘 폴더의 탭을 우클릭 → 고정 선택, 탭에 핀이 표시되고 닫기 단추가 사라짐
3) 고정 탭에서 다른 폴더로 가면 새 탭에 열리고, 고정한 폴더는 그대로 남음
4) 고정 해제 : 고정 탭을 우클릭 → 고정 풀기
5) 탭 우클릭 메뉴의 복제는 같은 폴더 탭을 하나 더, 반대 창에 열기는 대상 창에 열기
- 탭 닫기는 ctrl+w, 탭 이동은 ctrl+tab·ctrl+shift+tab
- 폴더를 마우스 가운데 단추로 누르면 뒤에 새 탭으로 열림
- 설정 → 탐색기 카드 → 끌 때 열린 탭 비우기를 켜면 다시 켤 때 고정 탭만 남음
<그림>
#다. 빠른 필터
○ 지금 연 폴더 목록을 글자로 바로 걸러, 파일이 많은 폴더에서도 원하는 파일을 빠르게 찾도록 구현
1) 탐색기 창 윗줄 빠른 필터 칸에 찾을 글자를 입력
2) 입력하는 대로 지금 폴더 목록이 걸러짐
3) 목록에서 바로 글자 키를 쳐도 빠른 필터 칸에 입력됨
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
- 빠른 필터는 저장하지 않음(다시 켜면 비어 있음)
#라. 드라이브
○ 자주 쓰는 저장장치(C:, D:, USB 등)로 한 번에 이동하는 단추
1) 드라이브 단추를 누르면 그 드라이브 맨 위 폴더로 이동
2) USB를 꽂거나 빼면 3초 안에 단추에 반영
3) 드라이브 단추를 우클릭하면 윈도우 드라이브 메뉴(꺼내기·속성 등) 표시
4) 보기 ▾ 단추로 목록 보기 방식 선택 : 자세히·간단히·큰 아이콘·썸네일(ctrl+shift+1~4, ctrl+휠)
- 보일 드라이브는 설정 → 탐색기 카드 → 드라이브 단추에서 선택
- 보기 방식·정렬은 탐색기 창마다 따로 기억
<그림>
#마. 경로표시줄
○ 지금 폴더의 경로를 표시하고, 경로 복사·윈도우 탐색기로 열기·즐겨찾기 지정을 한 줄에 모아 구현
1) 경로의 폴더 이름을 누르면 그 폴더로 이동
2) 경로 줄 빈 곳을 누르면 경로를 직접 입력 가능(ctrl+l, alt+d, f4도 같음), enter로 이동
3) 경로를 입력하는 동안 아래 폴더가 후보로 표시, ↑·↓로 고르고 tab으로 채움
4) 폴더 이름 사이 › 를 누르면 그 폴더의 아래 폴더 목록 표시
5) 오른쪽 단추 : 경로 복사(파일을 골랐으면 파일 경로) · 윈도우 탐색기로 열기(ctrl+e) · ★ 즐겨찾기
- ★를 누르면 지금 폴더를 즐겨찾기에 추가, 별이 채워지면 등록된 것, 다시 누르면 해제
- 즐겨찾기 폴더는 폴더트리 맨 위 즐겨찾기 묶음과 드라이브 줄 끝 ★ 즐겨찾기에 표시
#바. 머리줄 단추
○ 탐색기 창 분할과 자주 쓰는 기능을 한 줄에 모아, 윈도우 탐색기 창을 여러 개 띄우지 않도록 구현, 켜진 단추는 채운 색으로 표시
1) 새로고침(ctrl+r) : 지금 폴더를 다시 읽음, 다른 프로그램에서 돌아오면 저절로 다시 읽음
2) 배치복구 : 폴더트리 폭과 창 사이 크기를 처음대로 되돌림
3) 트리보기 : 왼쪽 폴더트리를 켜고 끔
4) 두칸보기 : 두 창으로 분할, 한 번 더 누르면 좌우 ↔ 상하
5) 세칸보기 : 세 창으로 분할, 한 번 더 누르면 긴 칸이 왼쪽 ↔ 오른쪽
6) 네칸보기 : 2×2 네 창으로 분할
7) 펼쳐보기 : 하위 폴더의 파일까지 한 목록 탭으로 모아 보기
8) 미리보기 : 대상 창 자리에 고른 파일 미리 보기(alt+p)
9) 숨긴파일 : 숨김 파일을 흐리게 표시
10) 같은폴더 : 대상 창을 지금 창과 같은 폴더로 열기
11) 창바꾸기 : 지금 창과 대상 창을 서로 바꾸기
12) 이름변경 : 고른 파일들의 일괄 이름 바꾸기 창 열기
- 지금 창은 마지막으로 누른 창, 대상 창은 그 바로 전에 있던 창(세칸·네칸에서는 두 창에 테두리 표시)
- f5 복사·f6 옮기기는 늘 대상 창으로, tab은 다음 창, ctrl+1~4는 창 바로 고르기
- 창 사이 경계를 끌면 창 크기 조정
13) 일괄 이름 바꾸기 : 바꿀 파일들을 고르고 이름변경을 누른 뒤, 패턴 칸에 새 이름 규칙 입력
- [n] 기존 이름 · [c] 번호 · [ymd] 수정한 날 · [p] 상위 폴더 이름 · [e] 확장자, 예: [ymd]_[n]
- 찾기·바꾸기(대소문자·모든 발생·확장자 제외), 번호(시작·증가·자릿수) 지정 가능
- 위 목록의 새 이름에서 결과를 미리 확인, 겹치는 이름·쓸 수 없는 글자는 빨간 줄로 막힘
- 이름 바꾸기 또는 맨 아래 확인(바꾸고 닫기), 잘못 바꿨으면 되돌리기
<그림>
#사. 단축키 안내
○ 탐색기 창 아래 줄에 자주 쓰는 단축키를 늘 표시해, 키를 외우지 않아도 바로 쓰도록 구현
1) f2 이름 바꾸기 · f3 열기 · f5 복사 · f6 옮기기 · f7 새 폴더 · f8 지우기
2) ctrl+c·x·v 복사·잘라내기·붙이기 · space 고르기 · tab 다음 창 · ctrl+e 윈도우 탐색기로
- f5·f6은 대상 창으로 가며, 누르면 "복사할까요?"로 한 번 확인
- 윈도우 탐색기 키도 그대로 작동 : alt+↑ 위 폴더, alt+enter 속성, ctrl+shift+n 새 폴더, ctrl+z 되돌리기, ctrl+y 다시 하기
#아. 폴더트리
○ 폴더와 파일의 위계 구조를 한눈에 보여 주고, 누른 폴더를 지금 창에 바로 열도록 구현
1) 폴더를 누르면 지금 창에 열리고, 트리는 지금 창의 폴더를 따라 펼쳐짐
2) 맨 위 즐겨찾기 묶음에 ★로 지정한 폴더가 모임(등록은 경로표시줄의 ★)
3) 트리에 보일 드라이브·즐겨찾기 지정 : 설정 → 탐색기 카드 → 폴더 트리에서 내 PC·드라이브·즐겨찾기를 켜고 끔
4) 트리와 창 사이 경계를 끌면 폭 조정, 두 번 누르면 처음 폭으로
5) 트리의 폴더를 우클릭하면 이름 바꾸기·새 폴더·보안 해제 가능
<그림>
#자. 파일 목록
○ 윈도우 탐색기와 같은 손버릇으로 파일을 다루도록 구현, 우클릭은 윈도우 전체 메뉴를 바로 표시
1) 두 번 누르거나 enter로 열기, 파일은 윈도우 기본 프로그램으로 열림
2) 위 폴더로 : 맨 위 ".." 줄, backspace, alt+↑, 빈 곳 두 번 누르기
3) 여러 개 고르기 : ctrl·shift를 누른 채 누르기, space, 빈 곳에서 끌어 고무줄로 고르기
4) 열 제목을 누르면 정렬, 경계를 끌면 폭 조정(두 번 누르면 자동 폭), 열 제목 우클릭으로 보일 열 선택
5) 복사·옮기기 : f5·f6은 대상 창으로, ctrl+c·x·v는 윈도우 탐색기·바탕 화면·메일 첨부와도 오감
6) 끌어 놓기 : 같은 드라이브면 옮기기, 다른 드라이브면 복사(ctrl 복사·shift 옮기기)
- 같은 이름이 있으면 두 파일을 나란히 보여 주고 건너뛰기·덮어쓰기·둘 다 두기를 물음, "나머지도 같게"로 한 번에 지정
- f8·delete는 묻고 휴지통으로, shift+f8은 완전 삭제(묻지 않게 하려면 설정 → 탐색기 카드 → 지울 때 묻기 끄기)
- ctrl+z 되돌리기는 이 앱에서 한 옮기기·복사·이름 바꾸기·휴지통 지우기·새 폴더만 가능(앱을 끄면 기록 삭제)
- zip 파일은 두 번 누르면 폴더처럼 들어가 안을 보고 꺼내기 가능(읽기만)
<그림>
#차. 문서보안 해제
○ 회사 문서보안 메뉴는 윈도우 탐색기에서만 보여, 기록이 윈도우 탐색기로 넘겨 바로 해제하도록 구현
1) 목록에서 보안을 풀 파일을 고름(같은 폴더면 여러 개 가능)
2) 우클릭 → 맨 아래 "윈도우 탐색기에서 열기 · 보안 해제" 선택
3) 윈도우 탐색기가 열리면서 그 파일들이 골라지고, 우클릭 메뉴까지 저절로 표시
4) 메뉴에서 보안 해제 선택
5) 윈도우 탐색기 창은 직접 닫음, 기록 목록은 저절로 새로 고침
