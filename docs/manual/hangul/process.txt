@화면 민원처리
@부제목 국민신문고 민원을 불러와 시공사 공사 지시부를 신속하게 만들어 보내는 도구
@기획의도
가. 국민신문고 민원을 하나씩 열고 사진을 내려받던 번거로움을 [민원 불러오기] 한 번으로 해소
나. AI가 민원 내용과 사진을 보고 보수 내용과 맡을 공사(시공사)를 미리 판단
다. 위치·보수 내용·위치도·현장사진이 든 공사 지시부를 자동으로 만들어 시공사에 전송
라. 지시부를 만들면 민원대장 조치내용에 지시 내용이 자동 기입
@기능별
가. 신문고 열기 : 크롬으로 업무처리포털을 열어 로그인
나. 민원 불러오기 : 처리중 민원을 AI가 읽어 표에 한 줄씩 등록
다. 공사 관리 : 공사마다 시공사·현장대리인·처리 범위를 지정
라. 고르기 칸 : 같은 공사 민원을 골라 지시부 하나로 묶어 생성
마. 위치 : 리·동과 지번 표시, 두 번 눌러 수정
바. 판단 공사 : AI가 고른 공사 표시, 눌러서 변경
사. 고려사항 : 시공사에 전할 내용을 적으면 지시부에 함께 기입
아. 진행 : 접수부터 완료까지 처리 단계를 막대로 표시
자. 줄 메뉴 : 지시부 열기·보내기·완료로 이동·지우기 등 민원별 작업
@상세
#가. 신문고 열기
○ 크롬으로 국민신문고 업무처리포털을 여는 단추, AI가 민원을 읽으려면 크롬에 신문고 로그인이 되어 있어야 함
1) 머리 줄 제목 옆 [신문고 열기]를 누름
2) 크롬에 업무처리포털이 열리면 로그인
3) 로그인한 크롬 창은 그대로 두고 [민원 불러오기] 진행
- 처음 한 번 준비 : 컴퓨터에 Claude Code 설치·로그인, 크롬에 Claude 확장 설치
- 엣지에 Claude 확장이 있으면 꺼 둘 것
#나. 민원 불러오기
○ AI가 크롬에서 신문고 민원처리목록을 읽고, 민원마다 원문과 첨부 사진을 받아 보수 내용과 맡을 공사를 판단하여 표에 넣는 기능
1) 머리 줄 [민원 불러오기]를 누름
2) 표 위에 진행 띠가 뜨고, 민원이 읽히는 대로 한 줄씩 표에 등록
3) 불러오는 동안 다른 업무 가능, 그만둘 때는 띠의 [멈추기]
4) 끝나면 아래 줄에 새 민원·건너뜀 건수와 걸린 시간 표시
- 이미 표에 있는 접수번호는 다시 열지 않고 건너뜀
- 사진이 여러 장이면 보수할 곳이 가장 잘 보이는 1장을 AI가 골라 맨 앞에 둠
- 민원 요약에 마우스를 올리면 AI가 그 공사를 고른 이유 표시
- 번호를 누르면 전체 접수번호가 복사되어 신문고 검색 칸에 붙여 넣기 가능
- 신문고 로그인이 풀려 있으면 멈추고 "로그인해 주세요" 안내, 멈춘 까닭은 아래 줄 [로그 열기]로 확인
- AI 모델은 설정 → 민원처리 카드 → Claude 모델에서 변경
#다. 공사 관리
○ AI가 공사를 판단하는 기준이자 지시부 머리에 들어갈 공사 정보를 적어 두는 창
1) 머리 줄 오른쪽 [공사 관리]를 누름
2) 맨 아래 신규 줄 공사명 칸에 이름이나 초성을 입력하면 업무연락처 사업이 후보로 표시
3) 사업을 고르면 축약 공사명·현장대리인·시공사가 자동 입력
4) 처리 범위 칸에 그 공사가 맡는 보수 범위를 입력, AI의 판단 기준으로 사용
5) 다음 연번은 지시부 번호, 비우면 다음 번호가 자동
- 두 번 눌러 그 자리에서 수정, enter·바깥 누르기는 저장, esc는 취소
- 현장대리인은 업무연락처에서 고르고, 고르면 시공사가 그 사람 소속으로 자동 변경
- 업무연락처와 연결되어 어느 쪽에서 고쳐도 함께 변경

#라. 고르기 칸
○ 같은 공사 민원을 여러 건 골라 지시부 한 장으로 묶는 기능, 지시부는 표준 양식 한글 파일과 쪽마다 그림 파일로 자동 생성
1) 줄 앞 고르기 칸을 누름, 다른 공사 줄은 흐려져 고를 수 없음
2) 번호 머리 앞 전체 고르기 칸을 누르면 같은 공사의 지시부 전 민원을 모두 선택
3) 표 위 띠에서 묶을 건수와 지시부 번호를 확인하고 [지시부 만들기]
4) 지시부는 민원 폴더에 "지시일_축약 공사명-연번" 이름으로 저장
5) 지시부에 든 민원은 민원대장에 자동 등록, 조치내용에 "● 축약 공사명 지시(1지구-03 · 2)" 기입
- 항목은 접수일 순서로 들어가고, 항목마다 공사내용(위치)·고려사항·위치도·현장사진 1장 기입
- 지시부에 이미 든 민원과 끝난 민원은 고르기 칸이 막힘
- 민원 폴더는 설정 → 민원처리 카드 → 민원 폴더에서 지정
#마. 위치
○ AI가 원문·사진에서 읽은 주소를 리·동과 지번으로 표시, 주소가 분명하지 않으면 "주소불명"으로 표시
1) 위치를 두 번 누르면 입력 칸으로 변경
2) 리·동 초성을 입력하면 후보가 뜨고, 고르면 지역(읍면동)이 자동 입력
3) 칸을 떠나거나 enter를 누르면 저장, esc는 취소
- 민원대장에 들어간 민원은 대장의 지역·위치도 함께 수정
- 지시부에 든 민원은 고친 주소로 지시부를 다시 생성
#바. 판단 공사
○ AI가 공사 관리의 처리 범위를 보고 고른 공사를 배지로 표시, 애매하면 비워 두고 담당자가 확인하여 결정
1) 판단 공사 배지를 누르면 공사 목록이 열림
2) 맡길 공사를 골라 변경
3) 공사 대상이 아니면 목록 맨 아래 "해당 없음"을 고름, 민원대장 추가 여부를 한 번 확인
- 공사가 비어 있으면 주황 "공사 고르기"로 표시
- 지시부에 든 민원의 공사를 바꾸면 그 지시부에서 빠지고, 남은 건으로 지시부를 다시 생성
#사. 고려사항
○ 현장에서 주의할 점 등 시공사에 전할 내용을 적는 칸, 지시부에 "○" 줄로 기입
1) 고려사항 칸을 두 번 누르면 칸 아래로 펼쳐져 입력
2) 머릿기호 규칙대로 여러 줄 입력 가능
3) tab이나 바깥 누르기는 저장하고 접기, esc는 취소
- 줄에는 첫 줄만 보이고, 마우스를 올리면 전체 표시
- 지시부에 든 민원은 고친 뒤 지시부를 다시 생성
#아. 진행
○ 민원 처리 단계를 글자가 든 막대 하나로 표시, 막대가 찰수록 처리가 끝난 민원
1) 접수 → 지시부 → 보냄 → 답변 → 완료 순서로 막대가 참
2) 보냄 막대를 누르면 받는 사람·보낸 시각·첨부를 담은 보낸 증거 카드 표시
3) 지시부 막대를 누르면 지시부 열기, 답변·완료 막대를 누르면 민원대장의 그 줄로 이동
- 답변·완료는 민원대장 상태를 따름
- 메일을 보냈으나 보낸메일함에서 확인되지 않으면 주황 "확인 필요"로 표시
- 민원대장에서 완료·불가가 되면 표 아래 "완료 N건" 띠 아래로 이동, [보기]로 펼침
#자. 줄 메뉴
○ 줄 끝 ⋯ 단추나 줄 우클릭으로 여는 메뉴, 그 민원에 필요한 작업을 한곳에 모음
1) 줄 끝 ⋯를 누르거나 줄을 우클릭
2) 맨 위에서 사진·위치도 수 확인, 작은 사진을 눌러 지시부에 넣을 사진 변경
3) 보내기 : 메일로 보내기(현장대리인의 업무연락처 메일 주소로 지시부 첨부) 또는 폰으로 보내기 선택
4) 완료로 이동 : 민원대장의 그 줄을 완료로 변경, 대장에 없으면 등록 여부를 확인
5) 그 밖에 이 건만 지시부 만들기·지시부 열기·다시 만들기·저장 폴더 열기·민원대장에 추가·지우기
- 메일은 확인 창에서 받는 사람·제목·본문을 확인한 뒤 보내기, 민원인 이름·연락처는 넣지 않음
- 메일 제목·본문 틀은 설정 → 민원처리 카드에서 변경
- 지운 민원은 다음 불러오기 때 다시 들어옴
