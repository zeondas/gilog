@화면 민원처리
@부제목 국민신문고 민원을 불러와 시공사 공사 지시부를 신속하게 작성·전송하는 도구
@기획의도
가. 국민신문고 민원을 하나씩 열고 사진을 내려받던 번거로움을 [민원 불러오기] 한 번으로 해소
나. AI가 민원 내용과 사진을 검토하여 보수 내용과 담당 공사(시공사)를 사전 판단
다. 위치·보수 내용·위치도·현장사진이 포함된 공사 지시부를 자동 작성하여 시공사에 전송
라. 지시부 작성 시 민원대장 조치내용에 지시 내용 자동 기입
@기능별
가. 신문고 열기 : 크롬으로 업무처리포털을 열어 로그인
나. 민원 불러오기 : 처리중 민원을 AI가 읽어 표에 한 행씩 등록
다. 공사 관리 : 공사별 시공사·현장대리인·처리 범위 지정
라. 선택란 : 같은 공사 민원을 선택하여 지시부 하나로 묶어 작성
마. 위치 : 리·동과 지번 표시, 더블클릭으로 수정
바. 판단 공사 : AI가 선택한 공사 표시, 클릭하여 변경
사. 고려사항 : 시공사에 전달할 내용을 입력하면 지시부에 함께 기입
아. 진행 : 접수부터 완료까지 처리 단계를 막대로 표시
자. 행 메뉴 : 지시부 열기·보내기·완료로 이동·삭제 등 민원별 작업
@상세
#가. 신문고 열기
○ 크롬으로 국민신문고 업무처리포털을 여는 버튼, AI가 민원을 읽으려면 크롬에 신문고 로그인 필요
1) 상단 제목 옆 [신문고 열기]를 클릭
2) 크롬에 업무처리포털이 표시되면 로그인
3) 로그인한 크롬 창은 그대로 두고 [민원 불러오기] 진행
- 최초 1회 준비 : 컴퓨터에 Claude Code 설치·로그인, 크롬에 Claude 확장 설치
- 엣지에 Claude 확장이 있으면 사용 해제
#나. 민원 불러오기
○ AI가 크롬에서 신문고 민원처리목록을 읽고, 민원별 원문과 첨부 사진을 받아 보수 내용과 담당 공사를 판단하여 표에 등록하는 기능
1) 상단 [민원 불러오기]를 클릭
2) 표 위에 진행 표시줄이 나타나고, 읽은 민원부터 한 행씩 표에 등록
3) 불러오는 동안 다른 업무 가능, 중단 시 진행 표시줄의 [멈추기]
4) 완료 시 하단에 새 민원·건너뜀 건수와 소요 시간 표시
- 이미 표에 있는 접수번호는 다시 열지 않고 건너뜀
- 사진이 여러 장이면 보수 위치가 가장 잘 보이는 1장을 AI가 선택하여 맨 앞에 배치
- 민원 요약에 마우스를 올리면 AI의 공사 판단 이유 표시
- 번호를 클릭하면 전체 접수번호가 복사되어 신문고 검색란에 붙여 넣기 가능
- 신문고 로그인이 해제되어 있으면 중단 후 로그인 안내, 중단 사유는 하단 [로그 열기]로 확인
- AI 모델은 설정 → 민원처리 카드 → Claude 모델에서 변경
#다. 공사 관리
○ AI의 공사 판단 기준이자 지시부 상단에 들어갈 공사 정보를 기재하는 창
1) 상단 오른쪽 [공사 관리]를 클릭
2) 맨 아래 신규 행 공사명 입력란에 이름이나 초성을 입력하면 업무연락처 사업이 후보로 표시
3) 사업을 선택하면 축약 공사명·현장대리인·시공사 자동 입력
4) 처리 범위 입력란에 해당 공사의 보수 범위 입력, AI 판단 기준으로 사용
5) 다음 연번은 지시부 번호, 비우면 다음 번호 자동 부여
- 행을 더블클릭하여 해당 행 수정, Enter·바깥 클릭은 저장, Esc는 취소
- 현장대리인은 업무연락처에서 선택, 선택 시 시공사가 해당 소속으로 자동 변경
- 업무연락처와 연결되어 어느 쪽에서 수정해도 함께 변경

#라. 선택란
○ 같은 공사 민원 여러 건을 선택하여 지시부 한 건으로 묶는 기능, 지시부는 표준 양식 한글 파일과 쪽별 그림 파일로 자동 작성
1) 행 앞 선택란을 클릭, 다른 공사 행은 흐리게 표시되어 선택 불가
2) 번호 제목 앞 전체 선택란을 클릭하면 같은 공사의 지시부 작성 전 민원 모두 선택
3) 표 위 표시줄에서 묶을 건수와 지시부 번호를 확인하고 [지시부 만들기]
4) 지시부는 민원 폴더에 "지시일_축약 공사명-연번" 이름으로 저장
5) 지시부에 포함된 민원은 민원대장에 자동 등록, 조치내용에 "● 축약 공사명 지시(1지구-03 · 2)" 기입
- 항목은 접수일 순서로 기입, 항목별 공사내용(위치)·고려사항·위치도·현장사진 1장 기입
- 지시부에 이미 포함된 민원과 완료된 민원은 선택 불가
- 선택 취소는 표시줄의 [선택 해제]
- 민원 폴더는 설정 → 민원처리 카드 → 민원 폴더에서 지정
#마. 위치
○ AI가 원문·사진에서 읽은 주소를 리·동과 지번으로 표시, 주소가 불분명하면 "주소불명"으로 표시
1) 위치를 더블클릭하면 입력란으로 변경
2) 리·동 초성을 입력하면 후보가 표시되고, 선택 시 지역(읍면동) 자동 입력
3) 입력란을 벗어나거나 Enter를 누르면 저장, Esc는 취소
- 민원대장에 등록된 민원은 대장의 지역·위치도 함께 수정
- 지시부에 포함된 민원은 수정한 주소로 지시부 자동 재작성
#바. 판단 공사
○ AI가 공사 관리의 처리 범위를 기준으로 선택한 공사를 배지로 표시, 불분명하면 비워 두고 담당자가 확인하여 결정
1) 판단 공사 배지를 클릭하면 공사 목록 표시
2) 담당할 공사를 선택하여 변경
3) 공사 대상이 아니면 목록 맨 아래 "해당 없음" 선택, 민원대장 추가 여부를 한 번 확인
- 공사가 비어 있으면 주황색 "공사 고르기"로 표시
- 지시부에 포함된 민원의 공사를 변경하면 해당 지시부에서 제외되고, 남은 건으로 지시부 자동 재작성
#사. 고려사항
○ 현장 유의사항 등 시공사에 전달할 내용을 입력하는 입력란, 지시부에 "○" 줄로 기입
1) 고려사항 입력란을 더블클릭하면 입력란 아래로 펼쳐져 입력
2) 머릿기호 규칙대로 여러 줄 입력 가능
3) Tab이나 바깥 클릭은 저장 후 접기, Esc는 취소
- 행에는 첫 줄만 표시, 마우스를 올리면 전체 표시
- 지시부에 포함된 민원은 수정 후 지시부 자동 재작성
#아. 진행
○ 민원 처리 단계를 글자가 표시된 막대 하나로 표시, 막대가 찰수록 처리가 진척된 민원
1) 접수 → 지시부 → 보냄 → 답변 → 완료 순서로 막대가 참
2) 보냄 막대를 클릭하면 받는 사람·보낸 시각·첨부가 담긴 보낸 증거 카드 표시
3) 지시부 막대를 클릭하면 지시부 열기, 답변·완료 막대를 클릭하면 민원대장의 해당 행으로 이동
- 답변·완료 단계는 민원대장 상태를 따름(진행·답변·보류·장기는 답변 단계)
- 메일을 보냈으나 보낸메일함에서 확인되지 않으면 주황색 "확인 필요"로 표시
- 민원대장에서 완료·불가가 되면 표 아래 "완료 N건" 표시줄 아래로 이동, [보기]로 펼침
#자. 행 메뉴
○ 행 끝 ⋯ 버튼이나 행 우클릭으로 여는 메뉴, 해당 민원에 필요한 작업을 한곳에 모음
1) 행 끝 ⋯를 클릭하거나 행을 우클릭
2) 맨 위에서 사진·위치도 수 확인, 작은 사진을 클릭하여 지시부에 넣을 사진 변경
3) "보내기" : "메일로 보내기"(현장대리인의 업무연락처 메일 주소로 지시부 첨부) 또는 "이미지 보내기"(휴대폰 Claude 앱으로 전송) 선택
4) "완료로 이동" : 민원대장의 해당 행을 완료로 변경, 대장에 없으면 등록 여부 확인
5) 그 밖에 "이 건만 지시부 만들기"·"지시부 열기"·"다시 만들기"·"저장 폴더 열기"·"민원대장에 추가"·"지우기"
- 완료된 민원은 "완료 풀기"로 민원대장 상태를 이전 상태로 복원
- 메일은 확인 창에서 받는 사람·제목·본문을 확인한 뒤 전송, 민원인 이름·연락처는 미포함
- 메일 제목·본문 틀은 설정 → 민원처리 카드에서 변경
- 삭제한 민원은 다음 불러오기 때 다시 등록됨
