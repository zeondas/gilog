= 기록앱 준비 안내서
~ 설치 파일만으로는 쓸 수 없는 세 기능을 쓰기 전에 해 둘 준비
# 1. 안내서의 목적
가. 기록앱은 설치 파일만 설치하면 대부분 바로 사용 가능, 다만 기록앱 밖의 프로그램·구글 계정과 이어지는 세 기능은 사전 준비 필요
나. 준비 순서와 누를 곳을 단계별로 정리하여 다른 담당자도 혼자 준비할 수 있도록 작성
다. 준비가 덜 되었을 때 기록앱에 표시되는 안내 문구와 조치 방법을 장마다 함께 수록
_
# 2. 준비가 필요한 기능
가. 민원처리 : AI가 국민신문고 민원을 대신 읽어 오는 기능, 컴퓨터에 AI 프로그램과 크롬 도우미를 설치
나. 구글 캘린더 연동 : 기록앱 일정·마감을 휴대폰 구글 캘린더에서 보는 기능, 구글에 사용 허가를 받고 로그인
다. 집행현황 팀 공유 : 팀원과 집행현황을 함께 보고 고치는 기능, 구글 시트 하나를 함께 쓰도록 연결
_
# 3. 용어 풀이
가. Claude(클로드) : Anthropic사가 만든 AI, 기록앱이 민원 읽기·공사 판단·메일 작성에 사용
나. Claude Code : 컴퓨터에 설치하는 Claude 프로그램, [민원 불러오기]를 누르면 기록앱이 이 프로그램에 일을 맡김
다. 크롬 Claude 확장 : 크롬에 추가하는 Claude 도우미, Claude Code가 이 도우미를 거쳐 크롬 화면을 보고 클릭
라. 업무처리포털 : 국민신문고의 공무원용 민원 처리 사이트
마. 구글 클라우드 콘솔 : 외부 프로그램이 구글 계정을 쓰도록 구글이 허가해 주는 관리 사이트
바. 앱 정보 파일 : 콘솔에서 받는 기록앱의 신분증 파일(client_secret으로 시작하는 json 파일)
사. 확인되지 않은 앱 경고 : 구글 심사를 받지 않은 프로그램에 로그인할 때 구글이 띄우는 경고, 기록앱은 심사를 받지 않아 처음 로그인할 때 한 번 표시되며 [고급]을 눌러 넘어가면 됨
아. 구글 시트 : 구글의 온라인 엑셀, 팀 공유 때 집행현황을 주고받는 곳
자. 호스트 : 공유 시트를 처음 만들고 함께 쓰는 사람 명단을 관리하는 사람(팀에 1명)
_
# 4. 사람별 할 일
가. 기록앱을 쓰는 담당자 : 민원처리 준비 전부, 구글 캘린더 연동 준비 나, 집행현황 팀 공유 준비 다
나. 콘솔 관리자(기록앱용 구글 콘솔을 만든 사람) : 구글 캘린더 연동 준비 가 (이미 되어 있음, 다시 할 일 없음)
다. 집행현황 호스트 : 집행현황 팀 공유 준비 나 (팀에 1명)
라. 【확인 필요】 회사 PC에서 claude.ai 로그인·크롬 웹 스토어 확장 설치·구글 로그인·구글 시트 새로고침이 되는지 확인 후 기입

= 민원처리 준비
~ AI가 크롬으로 국민신문고 민원을 대신 읽어 오도록 컴퓨터를 준비
# 1. 준비가 필요한 이유
가. [민원 불러오기]는 기록앱이 신문고를 직접 여는 방식이 아니라, 컴퓨터에 설치한 Claude Code가 크롬을 대신 조작하여 민원을 읽어 오는 방식
나. Claude Code와 크롬 Claude 확장은 기록앱 설치 파일에 들어 있지 않아 컴퓨터마다 따로 설치·로그인 필요
다. 엣지는 회사 정책상 신문고를 IE 모드로 열어 AI가 화면을 읽지 못하므로 반드시 크롬 사용

# 3. 준비 항목
가. Claude 계정 : Claude 유료 요금제에 가입한 계정 (사람마다 1개)
나. Claude Code 넣기 : claude.exe 파일을 정해진 폴더에 넣고 1회 실행·로그인 (컴퓨터마다 1회)
다. 크롬 Claude 확장 : 크롬에 확장을 추가하고 같은 Claude 계정으로 로그인 (컴퓨터마다 1회)
라. 엣지 Claude 확장 끄기 : 엣지에도 Claude 확장이 있을 때만 (1회)
마. 신문고 로그인 : 기록앱 [신문고 열기]로 크롬에서 업무처리포털 로그인 (로그인이 풀릴 때마다)
바. 폴더 확인 : 사진을 받는 폴더 확인, 크롬 여러 파일 다운로드 허용 (1회)
_
# 4. 상세설명
## 가. Claude Code 넣기
○ 회사 망은 인터넷 설치 명령이 막혀 있어, 미리 받아 둔 claude.exe 파일을 정해진 폴더에 직접 복사하는 방식
○ 처음 실행하면 영어로 된 검은 창(명령 창)이 열리지만, 아래 그림의 순서대로 키보드 Enter와 ↓(아래 화살표) 키만 누르면 됨
1) claude.exe 파일 준비 : 기록앱 담당자에게 압축 파일(claude-code_버전_win-x64.zip)로 받아 압축을 풀면 claude.exe 파일 1개
2) 윈도우 탐색기 주소 칸에 %USERPROFILE% 입력 후 Enter, 내 사용자 폴더(C:\Users\내 이름) 표시
3) 그 폴더에 새 폴더 .local을 만들고, .local 안에 새 폴더 bin을 만듦
4) bin 폴더에 claude.exe를 복사 (최종 위치 : C:\Users\내 이름\.local\bin\claude.exe)
- 폴더 이름 .local이 만들어지지 않으면 끝에 점을 하나 더 붙여 .local. 으로 입력
<그림 claude/01_bin폴더.png>
5) bin 폴더의 claude를 더블클릭, 검은 창이 열리고 글자 색 고르기 화면 표시
6) 이미 Dark mode에 √ 표시가 있으므로 그대로 Enter
<그림 claude/02_글자색.png>
7) 로그인 방법 고르기 화면 : 1번 Claude account with subscription(Claude 유료 요금제 계정)에 > 표시가 있으므로 그대로 Enter
<그림 claude/03_로그인방법.png>
8) 잠시 후 브라우저(엣지 또는 크롬)가 저절로 열림, 검은 창에는 아래 화면이 표시되고 기다림
- 브라우저가 열리지 않으면 검은 창에서 c 키를 눌러 주소를 복사하고, 브라우저 주소 칸에 붙여 넣은 뒤 Enter
<그림 claude/04_로그인주소.png>
9) 브라우저의 Claude 로그인 화면에서 Claude 유료 계정으로 로그인 (Google로 계속하기 또는 이메일 입력)
<그림 claude/05_브라우저로그인.png>
10) "Claude Code 앱에서 내 Claude chat account 연결을 요청합니다" 화면에서 [승인]
<그림 claude/06_연결승인.png>
11) "Claude Code 사용 준비가 완료되었습니다" 표시가 나오면 브라우저 창을 닫고 검은 창으로 돌아감 (작업 표시줄의 검은 창 아이콘 클릭)
<그림 claude/07_준비완료.png>
12) 검은 창에 Login successful(로그인 성공) 표시, Enter
<그림 claude/08_로그인성공.png>
13) Security notes(보안 안내) 화면, Enter
<그림 claude/09_보안안내.png>
14) "이 폴더를 믿을까요" 화면 : ↓ 키를 한 번 눌러 Yes, I trust this folder로 옮긴 뒤 Enter
- 처음 > 표시는 No, exit(아니요, 끝내기)에 있으므로, 그대로 Enter를 누르면 창이 닫힘, 5)부터 다시 진행
<그림 claude/10_폴더확인.png>
15) 크롬 확장을 찾았다는 화면이 나오면 ↓ 키를 한 번 눌러 Yes, use my browser로 옮긴 뒤 Enter
- 크롬에 Claude 확장(나.)이 아직 없으면 이 화면은 나오지 않음
<그림 claude/11_크롬확장.png>
16) 맨 위에 Claude Code와 계정 요금제(Claude Max 등)가 표시되고 > 입력 칸이 나오면 준비 완료, 오른쪽 위 × 로 검은 창 닫기
<그림 claude/12_완료.png>
- 기록앱은 이 폴더를 먼저 찾으므로 설정 → 민원처리 카드 → Claude 실행 파일 칸은 처음 값(claude) 그대로 둠
- 다른 폴더에 넣었으면 그 파일의 전체 위치를 Claude 실행 파일 칸에 입력
- 한 번 로그인하면 다시 할 필요 없음, 로그인이 풀리면 기록앱에 "Claude Code 로그인이 필요해요"가 표시되며 그때 5)부터 다시 진행
## 나. 크롬 Claude 확장
<그림 {크롬 웹 스토어의 Claude 확장 화면([Chrome에 추가] 버튼이 보이게)}>
○ Claude Code가 크롬 화면을 보고 클릭할 수 있게 해 주는 크롬 도우미
1) 크롬에서 크롬 웹 스토어(chromewebstore.google.com)를 열고 Claude 검색 (제공 : Anthropic)
2) [Chrome에 추가] → [확장 프로그램 추가]를 클릭
3) 크롬 오른쪽 위 확장 프로그램(퍼즐 모양) 버튼 → Claude 옆 핀을 클릭하여 고정
4) 고정된 Claude 버튼을 클릭하여 가.와 같은 Claude 계정으로 로그인
- [민원 불러오기]를 하는 동안 크롬은 켜 둠
## 다. 엣지 Claude 확장 끄기
○ 엣지에도 Claude 확장이 켜져 있으면 AI가 엣지 쪽에 이어져 신문고를 읽지 못함
1) 엣지 주소 칸에 edge://extensions 입력 후 Enter
2) Claude 확장의 켜기 스위치를 끔
- 엣지에 Claude 확장이 없으면 할 일 없음
## 라. 신문고 로그인
<그림 process_head.png>
○ AI는 크롬에 로그인되어 있는 업무처리포털을 그대로 사용
1) 기록앱 민원처리 화면 상단 [신문고 열기]를 클릭
2) 크롬에 업무처리포털이 열리면 로그인
3) 로그인한 크롬 창은 그대로 두고 [민원 불러오기]를 클릭
- 로그인이 풀려 있으면 기록앱이 멈추고 "신문고 로그인이 풀려 있어요" 안내, 다시 로그인 후 진행
## 마. 폴더 확인
○ AI가 읽은 민원과 첨부 사진이 오가는 폴더 (2. 화면의 폴더 칸)
1) 설정 → 민원처리 카드에서 민원 폴더·가져올 폴더·다운로드 폴더·보낼 폴더 확인
2) 다운로드 폴더는 크롬이 파일을 받는 폴더와 같게 지정 (크롬 설정 → 다운로드 → 위치)
3) 처음 첨부 사진을 받을 때 크롬이 "여러 파일 다운로드"를 물으면 [허용]
## 바. 준비가 덜 되었을 때 뜨는 글
○ 민원처리 화면 하단 줄이나 안내 띠에 표시되는 글과 조치 방법
1) "Claude Code를 찾지 못했어요" : claude.exe가 .local\bin 폴더에 있는지 확인 (가.)
2) "Claude Code 로그인이 필요해요" : claude.exe를 다시 실행하여 로그인 (가.)
3) "크롬을 찾지 못했어요" : 크롬 설치
4) "Claude가 크롬에 붙지 못했어요" 또는 "크롬의 Claude 확장과 이어지지 않았어요" : 크롬을 켜고 확장 로그인 확인, 엣지 확장은 끔 (나.·다.)
5) "Claude가 크롬 화면을 읽지 못했어요" : 크롬 확장 켜짐·엣지 확장 꺼짐 확인 (나.·다.)
6) "신문고 로그인이 풀려 있어요" : [신문고 열기]로 다시 로그인 (라.)
7) "못 찾은 사진 N개" : 다운로드 폴더와 크롬 여러 파일 다운로드 허용 확인 (마.)
8) "인터넷 연결이 막혔어요" : 회사 보안 프로그램이 막은 경우, 정보통신 담당 부서에 문의
9) "Claude 사용 한도에 걸렸어요" : 잠시 후 다시 클릭
- 멈춘 까닭은 하단 [로그 열기]로 확인

= 구글 캘린더 연동 준비
~ 기록앱의 일정·민원 마감·할 일 마감을 내 구글 캘린더로 보내도록 준비
# 1. 준비가 필요한 이유
가. 기록앱이 내 구글 계정에 일정을 쓰려면 구글 로그인으로 사용 허락이 필요
나. 기록앱은 구글 심사를 받지 않은 앱이라 처음 로그인할 때 "Google에서 확인하지 않은 앱" 경고가 표시되며, 아래 순서대로 넘어가면 됨
다. 민원인 이름·연락처는 어떤 경우에도 구글로 보내지 않음

## 가. 구글 콘솔 앱 만들기 (콘솔 관리자, 처음 1회 – 이미 되어 있음)
○ 구글 클라우드 콘솔(console.cloud.google.com)에서 기록앱용 앱을 한 번 만들어 두는 작업, 지금 프로젝트 이름은 giLog이고 모두 되어 있어 기록 보관용
1) console.cloud.google.com 접속 후 구글 계정으로 로그인, 상단 프로젝트 선택 → [새 프로젝트] → 이름 입력 → [만들기]
2) 왼쪽 메뉴 API 및 서비스 → 라이브러리에서 Google Calendar API를 검색하여 [사용] (팀 공유용 Google Sheets API·Google Drive API, 구글 할 일용 Google Tasks API도 같은 방법)
<그림 google/g01_캘린더API.png>
3) 왼쪽 메뉴 Google 인증 플랫폼 → 브랜딩에서 앱 이름(기Log)·사용자 지원 이메일·홈페이지·개인정보처리방침 주소 입력
<그림 google/g02_브랜딩.png>
4) 대상에서 사용자 유형 "외부", 게시 상태 "프로덕션 단계"로 둠 (테스트 단계면 등록한 사람만 로그인되고 약 7일마다 로그인이 풀림)
<그림 google/g03_대상.png>
5) 데이터 액세스에서 캘린더(앱이 만든 캘린더만) 범위 추가
<그림 google/g04_데이터액세스.png>
6) 클라이언트 → [클라이언트 만들기] → 애플리케이션 유형 "데스크톱 앱" → [만들기]
<그림 google/g05_클라이언트만들기.png>
7) 만든 클라이언트(giLog desktop)의 정보를 기록앱 설치 파일에 넣음 (기록앱 제작자 몫, 담당자는 할 일 없음)
<그림 google/g06_클라이언트목록.png>
- 프로덕션 단계의 심사받지 않은 앱은 로그인할 수 있는 사람이 앱 전체 기간 통틀어 100명까지이며 늘리거나 되돌릴 수 없음 (2026-10-29 기준 3명 사용)
- 설정에 앱 정보 파일 줄이 보이면 설치 파일에 앱 정보가 없는 경우이므로, 콘솔 관리자에게 받은 client_secret…json 파일을 [파일 고르기]로 넣음
## 나. 구글 로그인 (담당자, 처음 1회)
○ 내 구글 계정에 "giLog" 캘린더를 새로 만들고 그 캘린더에만 일정을 씀 (내 다른 캘린더는 건드리지 않음)
1) 기록앱 설정 → 캘린더 카드 → 구글 연동 → [구글 로그인]을 클릭
2) 브라우저에 "계정을 선택하세요" 화면이 열리면 내 구글 계정 클릭
<그림 google/l01_계정고르기.png>
3) "Google에서 확인하지 않은 앱" 경고가 뜨면 파란 [안전한 환경으로 돌아가기]가 아니라 왼쪽 아래 작은 글자 [고급]을 클릭
<그림 google/l02_확인안된앱경고.png>
4) 아래에 펼쳐진 "기Log(으)로 이동(안전하지 않음)"을 클릭
<그림 google/l03_고급펼침.png>
5) "기Log에서 Google 계정에 대한 액세스를 요청합니다" 화면에서 "모두 선택" 체크 칸을 클릭
<그림 google/l04_권한.png>
6) 아래 체크 칸이 모두 체크된 것을 확인하고 [계속]을 클릭
<그림 google/l05_권한체크.png>
7) "구글 연결을 마쳤어요" 표시가 나오면 브라우저 창을 닫고 기록앱으로 돌아감
<그림 google/l06_연결마침.png>
8) 기록앱 구글 연동 줄에 "연결됨 · 개인 구글 계정" 표시 확인 (2. 화면), 처음에는 일정 전체를 보내느라 잠시 "내보내는 중…" 표시
9) 보낼 것(내 일정·민원 마감·할 일 마감) 켜기·끄기 선택
- 5분 안에 로그인을 마치지 않으면 멈추므로 [구글 로그인] 다시 클릭
- 체크 칸을 비운 채 [계속]을 누르면 일정을 보내지 못함, [연결 끊기] 후 2)부터 다시 진행
- 구글 할 일로 보내기를 켜면 할 일 권한까지 함께 받음
- 연결을 끊을 때 "일정은 두기"를 고르면 다시 연결할 때 같은 giLog 캘린더를 이어서 씀
## 다. 준비가 덜 되었을 때 뜨는 글
○ 설정 구글 연동 줄이나 캘린더 왼쪽 아래 상태 상자에 표시되는 글과 조치 방법
1) "구글에서 받은 JSON 파일이 아니에요" 또는 "클라이언트 정보가 없는 파일이에요" : client_secret으로 시작하는 파일을 다시 선택 (가. 마지막 줄)
2) "5분 안에 로그인을 마치지 않아 멈췄어요" : [구글 로그인]을 다시 클릭
3) "구글에서 허용하지 않았어요" : 권한 화면에서 체크 칸을 모두 체크하고 [계속]을 눌렀는지 확인 (나. 5~6)
4) "구글 로그인이 풀렸어요. 설정에서 다시 연결해 주세요." : 나.를 다시 진행
5) "구글 할 일 권한이 없어요" : 구글 할 일로 보내기를 껐다 켜서 다시 로그인
6) "인터넷에 연결되지 않았어요" 또는 "구글에 연결하지 못했어요" : 인터넷 연결 확인, 회사 망에서 막힌 경우 정보통신 담당 부서에 문의

= 집행현황 팀 공유 준비
~ 같은 팀이 집행현황을 구글 시트 하나로 함께 쓰도록 준비
# 1. 준비가 필요한 이유
가. 집행현황은 사람마다 각자의 컴퓨터에 저장, 팀 공유는 구글 시트 하나를 거쳐 서로의 집행현황을 맞추는 방식
나. 시트를 만드는 사람(호스트) 1명과 그 시트에 연결하는 팀원으로 구성, 모두 구글 로그인 필요
다. 집행현황만 주고받고 민원인 정보는 나가지 않음
_
# 2. 화면
<그림 google/t01_호스트화면.png>
_
# 3. 준비 항목
가. 모든 사람 : 구글 계정, 같은 설치 파일로 설치한 기록앱
나. 호스트 : 팀 공유 켜기 → 새로 만들기 → 명단에 팀원 추가 → 새로고침 → 주소 복사 (팀에 1회)
다. 팀원 : 팀 공유 켜기 → 받은 주소 붙여 넣기 → 연결 (사람마다 1회)
_
# 4. 상세설명
## 가. 모든 사람이 갖출 것
○ 팀 공유는 구글 캘린더 연동과 같은 구글 로그인 방식을 사용
1) 구글 계정 준비
2) 모두 같은 설치 파일로 설치한 기록앱 사용
- 팀 공유를 켤 때 구글 시트 권한을 받는 로그인이 한 번 더 진행되며, 화면은 구글 캘린더 연동 준비 나.(계정 선택 → 확인하지 않은 앱 경고 → [고급] → 이동 → 모두 선택 → [계속])와 같음
- 구글 캘린더 연동을 쓰지 않는 사람도 이때 구글 로그인을 하며, 캘린더 내보내기는 꺼진 상태로 시작
## 나. 호스트 (팀에 1명)
○ 공유 시트를 만들고 팀원에게 시트 권한을 주는 사람 (2. 화면이 호스트 화면, 명단에 "호스트" 표시)
1) 설정 → 집행현황 카드 → 팀 공유 켜기
2) 공유 시트 [새로 만들기]를 클릭하고 브라우저에서 구글 로그인 완료 (가.의 로그인 화면)
3) 함께 쓰는 사람에 팀원 이름과 구글 메일을 입력하고 [＋ 더하기]
4) 집행현황 화면 [새로고침]을 클릭하여 팀원에게 시트 권한 부여
5) 공유 시트 [주소 복사]로 시트 주소를 복사하여 팀원에게 메일·메신저로 전달
- 팀원을 추가하면 구글이 그 메일로 시트 안내 메일 발송
- 팀원이 연결하면 명단의 그 사람 줄에 "연결됨" 표시
- 명단에서 빼면 다음 새로고침 때 그 사람의 시트 권한 해제
## 다. 팀원
<그림 google/t02_팀원화면.png>
○ 호스트가 보낸 주소로 공유 시트에 연결하는 사람
1) 설정 → 집행현황 카드 → 팀 공유 켜기
2) 공유 시트 칸에 호스트가 보낸 시트 주소를 붙여 넣고 [연결]
3) 브라우저에서 명단에 등록된 구글 계정으로 로그인 (가.의 로그인 화면)
4) "연결했어요" 표시 확인 후 집행현황 화면에 호스트의 집행현황이 들어왔는지 확인
- 연결되면 위 그림처럼 명단에 내 줄이 "연결됨"으로 표시되고, 고친 사람 이름에 내 이름 표시
- 집행현황 화면이 열려 있는 동안 5분마다 자동 새로고침, 바로 보려면 [새로고침]
## 라. 준비가 덜 되었을 때 뜨는 글
○ 팀 공유 줄이나 집행현황 화면에 표시되는 글과 조치 방법
1) "함께 쓰는 사람 명단에 내 구글 메일이 없어요" : 호스트에게 명단 추가 요청
2) "시트를 열 수 없어요" : 호스트가 명단에 추가한 뒤 [새로고침]을 했는지 확인
3) "시트를 찾지 못했어요" 또는 "시트 주소를 읽지 못했어요" : 호스트가 보낸 주소를 그대로 다시 붙여 넣음
4) "구글 로그인이 풀렸어요" : 설정 → 집행현황에서 다시 연결
5) "인터넷에 연결하지 못했어요" : 고친 내용은 내 컴퓨터에 두었다가 다음 새로고침 때 올림
