@화면 캘린더
@부제목 내 일정과 민원·할 일 마감을 한 달력에서 챙기는 도구
@기획의도
가. 회의·출장 같은 내 일정과 민원 답변 기한, 할 일 마감을 한 달력에 모아 한눈에 확인
나. 민원·할 일 마감은 따로 적지 않아도 민원대장·할 일에서 자동으로 표시
다. 구글 캘린더로 보내 휴대폰에서도 같은 일정 확인, 종류 색은 구글 캘린더와 같은 24색
@기능별
가. 종류 목록 : 일정 종류별 보이기·숨기기, 관리 창에서 종류·색 지정
나. 앞으로 7일 : 오늘부터 7일 동안의 일정을 차례로 표시
다. 구글 연동 상태 : 구글 캘린더 내보내기 상태와 실패 이유 표시
라. 빠른 입력 : 날짜·시각·일정을 한 줄로 바로 등록
마. 달 옮기기 : 이전·다음·오늘 단추와 마우스 휠로 달 이동
바. 월·주 보기 : 한 달 보기와 시간 칸이 있는 주 보기 전환
사. 달력 칸 : 날짜 고르기, 두 번 눌러 그 날 일정 입력, 쉬는 날 음영
아. 일정 상세 : 일시·반복·장소·설명·알림까지 자세히 입력
자. 마감 일정 : 민원·할 일 마감을 달력에서 바로 체크
@상세
#가. 종류 목록
○ 일정을 종류로 묶어 색으로 구분하고, 필요한 종류만 골라 보도록 구현
1) 왼쪽 종류 목록의 체크를 끄면 그 종류를 달력에서 숨김
2) "관리"를 눌러 새 종류를 만들고 색은 구글 캘린더 24색 가운데 고르거나 자동
3) 민원 마감·할 일 마감·공휴일은 앱이 만드는 종류라 지울 수 없고, 색과 보이기만 변경
4) 관리 창 "다시 받기"로 공휴일을 바로 새로 받음
5) 관리 창 아래 "알림 확인"에서 앞으로 울릴 알림 수·다음 알림·오류를 보고 시험 알림 띄우기
  - 종류를 지우면 그 종류의 일정도 함께 삭제, 지우기 전에 개수를 알려 주고 확인
  - 내 종류는 하나 이상 늘 남음
  - 일정마다 따로 색을 고르지 않고 종류 색을 따름

#나. 앞으로 7일
○ 달력을 넘기지 않아도 다가오는 일정을 바로 보도록 목록으로 제공
1) 오늘부터 6일 뒤까지(오늘 포함) 일정을 날짜·시각순으로 12건까지 표시, 넘치면 "외 N건"
2) 오늘 전에 시작해 안 끝난 일정은 오늘로 당겨 표시
- 숨긴 종류·공휴일·완료한 마감은 빠짐
#다. 구글 연동 상태
○ 구글 캘린더로 잘 보내지고 있는지 바로 알 수 있도록 왼쪽 맨 아래에 상태 상자 제공
1) 설정 → 캘린더 카드 → 구글 연동에서 구글 로그인으로 연결하면 상자가 나타남
2) 바뀐 일정만 자동으로 구글 캘린더 "giLog" 캘린더로 보냄, 실패하면 10분마다 다시 시도
3) 실패하면 상자에 이유와 마지막 성공 시각 표시
4) "지금 내보내기"로 전체를 다시 맞춤
5) 설정 → 캘린더 카드 → 구글 연동 → 내 일정·민원 마감·할 일 마감을 각각 켜고 끄기, 끄면 구글에서 삭제
  - 한 방향 보내기, 구글에서 고친 내용은 다음 내보내기 때 기록의 내용으로 덮어씀
  - "구글 할 일로 보내기"를 켜면 할 일·민원 마감은 구글 할 일 목록으로 보내고, 체크는 양쪽으로 맞춤
  - 구글 일정 색은 11가지뿐이라 비슷한 색으로 바꿔 보냄
  - 민원인 이름·연락처·민원 내용·조치내용·메모는 어떤 경우에도 보내지 않음
  - 구글에서 직접 만든 일정, 다른 캘린더는 건드리지 않음
#라. 빠른 입력
○ 창을 열지 않고 한 줄로 일정을 바로 등록하도록 달력 위에 입력 줄 제공
1) 날짜 → 시작 → 종료 → 일정 → 종류 순서로 입력, 날짜와 일정은 필수
2) 시작을 비우면 종일 일정으로 등록
3) 시각은 14, 930, 1400, 9:30 모두 입력 가능
4) 아무 칸에서 enter, 또는 종류 칸에서 tab으로 등록, 커서는 날짜 칸으로 돌아감
5) "상세 입력"을 누르면 적던 내용을 상세 창으로 옮겨 이어서 입력
- 종류는 목록에서 고름, 새 종류는 관리 창에서 만듦
#마. 달 옮기기
○ 단추와 마우스 휠로 달력을 빠르게 넘기도록 구현
1) 이전·다음 단추로 달 이동, 오늘 단추로 이번 달로 복귀
2) 달력 위에서 마우스 세로 휠로 달 이동
- 주 보기에서는 날짜 줄·종일 줄 위의 휠이 주 이동, 시간 칸 위의 휠은 시간 스크롤
#바. 월·주 보기
○ 한 달 흐름과 하루 시간표를 모두 보도록 두 가지 보기 제공
1) 월 보기 : 그 달의 주 수(5주·6주)에 맞춰 칸 높이를 자동으로 나눔
2) 주 보기 : 0~24시 시간 칸, 오전 8시부터 보임, 지금 시각에 빨간 줄
3) 주 보기에서 겹치는 일정은 나란히 표시
- 고른 보기를 기억해 다음에도 같은 보기로 열림
- 창 높이를 줄이면 주 칸도 함께 줄어 한 달이 화면 안에 들어감
#사. 달력 칸
○ 날짜를 누르는 것만으로 고르기와 입력이 되도록 구현
1) 칸을 한 번 누르면 그 날이 골라지고 빠른 입력 날짜가 따라감
2) 칸을 두 번 누르면 그 날 상세 입력 창이 열림, 주 보기는 빈 시간 칸을 두 번 누르면 그 시각으로 열림
3) 한 칸에 다 못 그린 일정은 "+N개"로 줄여 표시, 누르면 그 날 일정 전체 창
4) 오늘 칸은 연한 보라 바탕에 위 띠로 표시
5) 토·일요일과 공휴일 칸은 연한 빨강 음영, 오늘이 쉬는 날이면 보라 테두리와 보라 날짜 동그라미
  - 음영은 설정 → 캘린더 카드 → 쉬는 날 음영으로 끄기 가능
  - 공휴일은 대체·임시공휴일까지 인터넷에서 자동으로 받음, 받지 못하면 마지막으로 받은 공휴일 표시
  - 업무일지 기록은 달력에 표시하지 않음
#아. 일정 상세
○ 반복·장소·알림까지 필요한 내용을 한 창에서 자세히 적도록 상세 창 제공
1) "상세 입력"을 누르거나 일정을 두 번 누르면(한 번은 고르기) 상세 창이 열림
2) 제목, 일시와 종일 여부, 반복, 장소, 설명, 종류, 알림 입력
3) 반복 : 매일·평일·매주·격주·매달·매년, 반복을 켜면 종료일 필수
4) 알림 : 없음·정시·10분·30분·1시간·1일·7일·한 달 전, 직접 설정(62일까지), 종일 일정은 알림 시각 지정(비우면 오전 9시)
5) enter 저장, shift+enter는 설명의 새 줄, esc 취소, 바깥을 누르면 저장
  - 반복 일정을 고치거나 지우면 모든 회차가 함께 바뀜
  - 알림은 기록이 켜져 있을 때(트레이 포함) 윈도우 알림으로 울리고, 누르면 그 일정이 열림
  - 완전히 끝내면 알림이 오지 않음
<그림>
#자. 마감 일정
○ 민원·할 일 마감을 따로 적지 않아도 달력에 자동으로 표시하고, 달력에서 바로 체크하도록 구현
1) 민원 마감은 민원대장의 법정 답변기한, 제목은 "접수유형(지역 위치)"
2) 할 일 마감은 할 일 목록의 마감일
3) 마감 앞 동그라미를 누르면 할 일은 완료, 민원은 답변으로 바뀜, 다시 누르면 그 전 상태로 복귀
4) 마감 일정을 누르면 민원대장·할 일의 그 항목으로 이동
- 마감 일정은 달력에서 고칠 수 없고, 원래 화면에서만 수정
- 완료한 마감은 흐리게, 가운데 줄로 남음
