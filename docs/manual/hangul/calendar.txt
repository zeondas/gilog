@화면 캘린더
@부제목 내 일정과 민원·할 일 마감을 한 달력에서 관리하는 도구
@기획의도
가. 회의·출장 등 내 일정과 민원 답변기한, 할 일 마감을 한 달력에 통합 표시
나. 민원·할 일 마감은 별도 입력 없이 민원대장·할 일에서 자동 표시
다. 구글 캘린더로 내보내 휴대폰에서도 같은 일정 확인, 종류 색은 구글 캘린더와 같은 24색
@기능별
가. 종류 목록 : 일정 종류별 표시·숨김, 관리 창에서 종류·색 지정
나. 앞으로 7일 : 오늘부터 7일간의 일정을 순서대로 표시
다. 구글 연동 상태 : 구글 캘린더 내보내기 상태와 실패 사유 표시
라. 빠른 입력 : 날짜·시각·제목을 한 행으로 즉시 등록
마. 달 이동 : 이전·다음·오늘 버튼과 마우스 휠로 달 이동
바. 월·주 보기 : 월 보기와 시간 칸이 있는 주 보기 전환
사. 달력 칸 : 날짜 선택, 더블클릭으로 해당 날짜 일정 입력, 휴일 음영
아. 일정 상세 : 일시·반복·장소·설명·알림까지 상세 입력
자. 마감 일정 : 민원·할 일 마감을 달력에서 바로 완료 처리
@상세
#가. 종류 목록
○ 일정을 종류별로 묶어 색으로 구분하고, 필요한 종류만 선택하여 표시
1) 왼쪽 "캘린더 종류" 목록의 체크 해제 시 해당 종류를 달력에서 숨김
2) [관리] 클릭 → "캘린더 종류 관리" 창에서 새 종류 추가, 색은 구글 캘린더 24색 중 선택 또는 "자동"
3) 민원 마감·할 일 마감·공휴일은 앱이 생성한 종류로 삭제 불가, 색·표시만 변경 가능
4) 관리 창 [다시 받기]로 공휴일 즉시 갱신
5) 관리 창 아래 [알림 확인]에서 7일간 알림 건수·다음 알림·오류 확인, [시험 알림 띄우기] 가능
  - 종류 삭제 시 해당 종류의 일정도 함께 삭제, 삭제 전 건수 안내 후 확인
  - 직접 만든 종류는 최소 1개 유지
  - 일정별 색 지정 없이 종류 색을 따름
<그림>
#나. 앞으로 7일
○ 달력을 넘기지 않고도 다가오는 일정을 바로 확인하도록 목록으로 제공
1) 오늘부터 6일 후까지(오늘 포함) 일정을 날짜·시각순으로 12건까지 표시, 초과 시 "외 N건"
2) 오늘 이전에 시작해 끝나지 않은 일정은 오늘 날짜로 표시
3) 목록의 일정 클릭 시 해당 날짜로 이동하여 일정 열림
- 숨긴 종류·공휴일·완료한 마감은 제외
#다. 구글 연동 상태
○ 구글 캘린더 내보내기 상태를 즉시 확인하도록 왼쪽 맨 아래에 상태 상자 제공
1) 설정 → 캘린더 카드 → 구글 연동에서 [구글 로그인]으로 연결하면 상자 표시
2) 변경된 일정만 구글 "giLog" 캘린더로 자동 내보내기, 실패 시 10분마다 재시도
3) 실패 시 상자에 사유와 마지막 성공 시각 표시
4) [지금 내보내기]로 전체 일정 재동기화
5) 설정 → 캘린더 카드 → 구글 연동에서 항목별 사용·해제 설정, 해제 시 구글에서 삭제
  - "내 일정 내보내기"·"민원 마감 내보내기"·"할 일 마감 내보내기"
  - 단방향 내보내기, 구글에서 수정한 내용은 다음 내보내기 때 기록앱 내용으로 덮어씀
  - "구글 할 일로 보내기" 사용 시 마감은 구글 할 일 목록으로 내보내고 완료 체크 양방향 반영
  - 구글 일정 색은 11가지뿐이라 비슷한 색으로 변환하여 내보냄
  - 민원인 이름·연락처·민원 내용·조치내용·메모는 어떤 경우에도 내보내지 않음
  - 구글에서 직접 만든 일정, 다른 캘린더는 변경하지 않음
#라. 빠른 입력
○ 창을 열지 않고 한 행으로 일정을 즉시 등록하도록 달력 위에 입력 행 제공
1) 날짜 → 시작 → 종료 → 제목 → 종류 순서로 입력, 날짜는 필수
2) 시작을 비우면 종일 일정으로 등록
3) 시각은 14, 930, 1400, 9:30 형식 모두 입력 가능
4) Enter·Tab으로 다음 입력란 이동, 제목 입력란에서 Enter·Tab 또는 [+] 클릭 시 등록
  - 등록 후 커서는 날짜 입력란으로 복귀
5) [상세 입력] 클릭 시 입력 중인 내용을 상세 창으로 옮겨 계속 입력
- 제목 입력란은 연보라 바탕에 안내 문구 표시, 제목을 비우면 "제목 없음"으로 등록
- 종류는 목록에서 선택, 새 종류는 관리 창에서 추가
#마. 달 이동
○ 버튼과 마우스 휠로 달력을 빠르게 이동하도록 구현
1) ‹ › 버튼으로 이전·다음 달(주 보기는 주) 이동, [오늘]로 오늘 날짜 복귀
2) 달력 위에서 마우스 세로 휠로 달 이동
- 주 보기에서는 날짜 행·종일 행 위의 휠은 주 이동, 시간 칸 위의 휠은 시간 스크롤
#바. 월·주 보기
○ 월간 흐름과 일간 시간표를 모두 확인하도록 두 가지 보기 제공
1) 월 보기 : 해당 월의 주 수(5주·6주)에 맞춰 칸 높이 자동 배분
2) 주 보기 : 0~24시 시간 칸, 오전 8시부터 표시, 현재 시각에 빨간 선
3) 주 보기에서 시간이 겹치는 일정은 나란히 표시
- 선택한 보기를 저장, 다음에도 같은 보기로 표시
- 창 높이를 줄이면 주 칸도 함께 줄어 한 달이 화면 안에 표시
- 상단 "일정 검색"란 입력 시 제목·장소·종류·설명에 해당 글자가 있는 일정만 표시
#사. 달력 칸
○ 날짜 클릭만으로 선택과 입력이 가능하도록 구현
1) 칸 클릭 시 해당 날짜 선택, 빠른 입력 날짜도 함께 변경
2) 칸 더블클릭 시 해당 날짜 상세 입력 창 표시, 주 보기는 빈 시간 칸 더블클릭 시 해당 시각으로 표시
3) 한 칸에 모두 표시하지 못한 일정은 "+N개"로 표시, 클릭 시 해당 날짜 일정 전체 창 표시
4) 오늘 칸은 연보라 바탕에 상단 띠로 표시
5) 토·일요일과 공휴일 칸은 연한 빨강 음영, 오늘이 휴일이면 보라 테두리와 보라 날짜 원으로 표시
  - 음영은 설정 → 캘린더 카드 → "쉬는 날 음영"으로 해제 가능
  - 공휴일은 대체·임시공휴일까지 인터넷에서 자동 수신, 수신 실패 시 마지막으로 받은 공휴일 표시
  - 업무일지 기록은 달력에 표시하지 않음
#아. 일정 상세
○ 반복·장소·알림까지 필요한 내용을 한 창에서 상세히 입력하도록 상세 창 제공
1) [상세 입력] 클릭 또는 일정 더블클릭(클릭은 선택) 시 상세 창 표시, 상단에 "새 일정" 또는 "일정" 표시
2) 제목, 일시와 [종일] 여부, 반복, 장소, 설명, 캘린더(종류), 알림 입력
3) 반복 : 매일·주중 매일(월~금)·매주·격주·매월·매년, 반복 선택 시 종료일 필수
4) 알림 : 알림 없음·정시·10분 전·30분 전·1시간 전·1일 전·7일 전·한 달 전·직접 설정(62일까지)
  - 종일 일정은 알림 시각 지정(비우면 오전 9시)
5) 한 줄 입력란은 Enter·Tab으로 다음 입력란 이동, 마지막 입력란에서 저장
  - 설명란은 Enter로 다음 줄, Tab으로 저장 후 닫기
  - Esc는 취소, 바깥 클릭 시 저장
  - 제목을 비우면 "제목 없음"으로 저장, 새 일정도 바깥 클릭 시 저장(입력 내용이 없으면 닫기)
  - 반복 일정 수정·삭제 시 모든 회차에 함께 적용
  - 알림은 기록앱 실행 중(트레이 포함) 윈도우 알림으로 표시, 클릭 시 해당 일정 열림
  - 프로그램을 종료하면 알림 미표시
<그림>
#자. 마감 일정
○ 민원·할 일 마감을 별도 입력 없이 달력에 자동 표시하고, 달력에서 바로 완료 처리하도록 구현
1) 민원 마감은 민원대장의 법정 답변기한, 제목은 "접수유형(지역 위치)"
2) 할 일 마감은 할 일 목록의 마감일
3) 마감 앞 원 클릭 시 할 일은 완료, 민원은 답변으로 변경, 다시 클릭 시 이전 상태로 복귀
4) 마감 일정 더블클릭 시 민원대장·할 일의 해당 항목으로 이동(클릭은 선택)
- 마감 일정은 달력에서 수정 불가, 원래 화면에서만 수정
- 완료한 마감은 흐린 글자·취소선으로 표시
