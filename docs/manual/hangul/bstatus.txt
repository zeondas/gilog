@화면 예산현황
@부제목 사업 예산의 재원·이월 구성과 재원별 지출을 한 장부로 정리하는 도구
@기획의도
가. 집행현황의 공사비를 그대로 불러와 세부사업별 국비·도비·시비 등 재원과 이월 구성을 연도별로 정리
나. 예산현액·집행액은 집행현황에서 자동 연계, 불용액·추경·이월 등 집행현황에 없는 값만 직접 입력
다. 공사별 재원 배분 입력 시 재원별 지출 자동 계산, 재원별 예산·집행 현황 일괄 확인
라. 과거(2024~2025) 자료는 엑셀 양식으로 일괄 등록, 다년도 사업 장부를 처음부터 완성
@기능별
가. 조회 연도 : ‹ ›로 장부 조회 연도 선택
나. 보기·단위 : 요약·자세히 보기 전환, 원·천원 단위 전환
다. 열 폭 조정 : 열 경계 드래그·더블클릭, 열 제목 행 우클릭으로 열 폭 조정
라. 검색 : 장부 내 세부사업을 사업명으로 검색
마. 엑셀 : 조회 연도 장부 내보내기, 직접 입력값 가져오기, 과거 자료 가져오기
바. 사업기간·설정 : 단년도·다년도 기간 표시, 기간·재원·이월 사업 연결·재원 배분 설정
사. 장부 표 : 세부사업 › 연도 › 재원 순으로 예산현액·집행액·집행률 표시
아. 직접 입력 칸 : 테두리 칸에 불용액·추경·이월 등 입력
자. 행 메뉴·메모 : 우클릭으로 설정 열기·순서 이동, 사업별 메모
@상세
#가. 조회 연도
○ 다년도 사업도 연도별로 구분하여 조회하도록 제목 옆에 연도 이동 버튼 제공
1) 제목 옆 ‹ › 클릭으로 이전·다음 연도로 이동
2) 단년도 사업은 해당 연도 사업만, 다년도 사업은 사업기간에 조회 연도가 포함될 때 표시
- 마지막으로 조회한 연도를 저장, 다음 실행 시 같은 연도로 표시
#나. 보기·단위
○ 평소에는 간략히, 필요 시 엑셀 "집행·이월 현황"과 같은 열로 상세 조회하도록 두 가지 보기 제공
1) 요약 : 당해예산 ①, 전년도 이월 ②, 예산현액 ①+②, 집행액, 집행률, 다음연도 이월, 불용액
2) 자세히 : 엑셀과 같은 19열, 상단 2행
  - 당해예산(소계·본예산·1추~4추), 전년도 이월(소계·명시이월·사고이월), 예산현액
  - 집행액(소계·당해·명시·사고), 집행률, 다음연도 이월(소계·명시이월·사고이월), 불용액
3) [원]·[천원] 버튼으로 금액 단위 전환
- 자세히 보기는 표 안에서 가로 스크롤
- 숫자 0은 "-"로 표시
#다. 열 폭 조정
○ 열 제목 경계로 열 폭을 조정하는 기능, 집행현황과 같은 방식
1) 열 제목 오른쪽 경계를 드래그하면 해당 열 폭만 변경, 표가 넓어지면 표 안에서 가로 스크롤
2) 경계를 더블클릭하면 해당 열을 내용에 맞춤
3) 열 제목 행 우클릭 → "내용에 맞춤(모든 열)" 또는 "처음 폭으로" 선택
- 집행률·메모 열은 고정 폭
- 요약·자세히 보기의 열 폭은 각각 저장
#라. 검색
○ 사업이 많아도 원하는 사업을 즉시 찾도록 장부 내 검색 제공
1) 상단 "세부사업 검색"란에 사업명 입력, 입력과 동시에 해당 사업만 필터 표시
- 검색란 끝 × 또는 Esc로 입력 내용 일괄 삭제
#마. 엑셀
○ 장부를 엑셀로 주고받고, 과거 연도 자료를 양식으로 일괄 등록하도록 지원
1) [엑셀 ▾] → "내보내기 · 원(천원)" : 조회 연도 전체 행(접힌 행 포함)을 "YYYY 예산현황" 시트로 저장
2) [엑셀 ▾] → "가져오기" : 같은 양식 시트에서 직접 입력 칸만 가져옴, 건수 확인 후 입력
  - 집행현황에서 연계되는 칸은 가져오지 않음
  - 기록앱에 없는 세부사업·재원은 제외하고 건수 안내
3) [엑셀 ▾] → "가져오기 · 계약현황 양식" : 계약현황 양식으로 과거 자료 일괄 등록
  - 양식은 계약별 예산연도·재원별 원인행위와 연도별 지급액을 기재
  - 연도별 집행현황에 본사업·명시이월·사고이월 사업과 공사 행 자동 생성
  - 예산현황 설정(재원별 예산·이월·불용·공사별 재원)까지 자동 입력
  - 지급액은 해당 계약의 오래된 예산(이월분)부터 집행한 것으로 계산
  - 집행현황에 이미 자료가 있는 연도는 제외
#바. 사업기간·설정
○ 사업별 기간과 재원 종류를 정하는 설정 창, 재원이 둘 이상이면 재원별 예산과 공사별 재원 배분 표 제공
1) 사업기간 칸 끝 ⚙ 버튼 또는 사업 행 우클릭 "예산현황 설정"으로 창 표시
2) 왼쪽 사업 설정 : 기간(단년도·다년도, 시작~끝 연도), 재원, 이월 사업 잇기
  - 재원은 국비·도비·시비 선택, 기타는 "기타 재원 이름" 입력 후 Enter 또는 [추가]
  - 재원은 최소 1개 유지
  - 명시이월 사업 연결 시 짝이 되는 사고이월 사업도 함께 연결
3) 오른쪽 재원 나누기(재원이 둘 이상일 때만) : 연도 선택 후 재원별 예산 표에 재원별 예산 입력
4) 공사별 재원 표 : 공사별 계약금액을 재원 칸에 나눠 입력, 집행액은 그 비율대로 자동 배분
  - 빈 칸을 더블클릭하면 남은 금액 자동 입력
  - 배분하지 않은 공사는 첫 재원으로 계산
  - 표 아래 [+ 공사 추가]로 공사를 바로 등록하면 집행현황에도 등록
5) 재원별 예산 합계가 집행현황 예산과 일치하면 ✓, 불일치하면 붉게 표시
  - 불일치 시 상단에 "맞지 않는 곳 N" 배지 표시
  - 불일치 상태로도 저장 가능, 장부 표에 붉게 표시
  - 표 아래에 원인·지출 재원 확인 방법 안내
6) [예산현황에서 빼기] : 보낸 사업을 예산현황에서 제외
- 창 가장자리 드래그로 창 크기 조정, 표 열 경계 드래그로 열 폭 조정

#사. 장부 표
○ 집행현황에서 보낸 세부사업의 예산·집행을 엑셀 "집행·이월 현황"과 같은 계산으로 정리한 장부
1) 집행현황 세부사업 행 우클릭 "예산현황으로 보내기"로 보낸 사업만 표시
  - 이월 세부사업은 보낼 때 [기존 사업에 잇기]·[새 사업으로] 중 선택
2) 단년도 사업은 조회 연도 1행, 다년도 사업은 세부사업 › 연도 › 재원 3단계로 펼침
  - 재원이 하나면 재원 행 없이 연도 행에서 바로 수정
3) 계산 : 당해예산 = 본예산 + 1추~4추, 전년도 이월 = 명시 + 사고
  - 예산현액 = 당해예산 + 전년도 이월, 집행률 = 집행액 ÷ 예산현액
4) 재원이 둘 이상이면 재원 행 집행액은 공사별 재원 배분 비율로 나눈 금액으로 표시
5) 다년도 사업은 잔액이 다음 연도 전년도 이월로 연계
  - 재원별 예산 합계가 집행현황 예산과 다르면 당해예산을 붉게 표시, 마우스를 올리면 사유 표시
  - 연결한 이월 사업의 전년도 이월이 전년도 다음연도 이월과 다르면 붉게 표시
#아. 직접 입력 칸
○ 집행현황에 없는 값만 입력하도록 테두리 칸으로 구분, 집행현황에서 연계되는 당해예산·집행액은 잠금
1) 행 더블클릭 시 수정 행이 표시되고 직접 입력 칸만 입력 가능
2) 다음연도 이월(명시·사고), 불용액, 추경 등 입력
3) Enter 또는 바깥 클릭 시 저장, Esc는 취소
  - 다음연도 이월·불용액은 자동 계산하지 않음, 잔액(현액 − 집행 − 이월 − 불용)은 마우스 오버 시 표시
  - 재원이 둘 이상이면 재원 행 본예산도 직접 입력(설정 창 재원별 예산과 같은 값)
  - 집행현황에 해당 연도 자료가 없으면 본예산·집행액도 직접 입력
#자. 행 메뉴·메모
○ 사업 행에서 설정·순서·메모를 바로 관리하도록 우클릭 메뉴와 메모 제공
1) 사업 행 우클릭 : "예산현황 설정", "위로 옮기기", "아래로 옮기기"
2) 사업 행 연필 버튼으로 사업별 메모 1건 작성
- 변경한 순서는 그대로 저장
