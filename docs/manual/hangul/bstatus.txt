@화면 예산현황
@부제목 사업 예산의 재원·이월 구성과 재원별 지출을 한 장부로 정리하는 도구
@기획의도
가. 집행현황의 공사비를 그대로 불러와 세부사업마다 국비·도비·시비 등 재원과 이월 구성을 연도별로 정리
나. 예산현액·집행액은 집행현황에서 자동으로 가져오고, 여기서는 불용액·추경·이월 등 집행현황에 없는 값만 입력
다. 공사별로 재원을 나눠 적으면 재원별 지출이 자동 계산되어 재원별 예산과 집행을 한눈에 확인
라. 과거(2024~2025) 자료는 엑셀 양식으로 한 번에 가져와 다년도 사업 장부를 처음부터 완성
@기능별
가. 보는 해 : ‹ ›로 장부를 볼 연도 선택
나. 보기·단위 : 요약·자세히 보기 전환, 원·천원 단위 전환
다. 배치최적화 : 열 폭을 내용에 맞게 자동 조정, 열 끌기로 직접 조정
라. 검색 : 장부 안의 사업을 글자로 검색
마. 엑셀 : 보는 해 장부 내보내기, 직접 적는 값 가져오기, 과거 자료 가져오기
바. 사업기간·설정 : 단년도·다년도 기간 표시, 기간·재원·이월 사업 잇기·재원 나누기 설정
사. 장부 표 : 세부사업 › 연도 › 재원 순으로 예산현액·집행액·집행률 표시
아. 직접 적는 칸 : 테두리 칸에 불용액·추경·이월 등 입력
자. 줄 메뉴·메모 : 우클릭으로 설정 열기·순서 옮기기, 사업마다 메모
@상세
#가. 보는 해
○ 다년도 사업도 한 해씩 끊어 보도록 제목 옆에 연도 이동 단추 제공
1) 제목 옆 ‹ ›를 눌러 앞뒤 연도로 이동
2) 단년도 사업은 그 해 사업만, 다년도 사업은 기간 안에 보는 해가 들어 있을 때 표시
- 마지막으로 본 해를 기억해 다음에도 그 해로 열림
#나. 보기·단위
○ 평소에는 간단히 보고, 필요할 때 엑셀 "집행·이월 현황"과 같은 열로 자세히 보도록 두 가지 보기 제공
1) 요약 : 당해예산 ①, 전년도 이월 ②, 예산현액(①+②), 집행액, 집행률, 다음연도 이월, 불용액
2) 자세히 : 엑셀과 같은 19열(당해예산 소계·본예산·1추~4추, 전년도 이월 소계·명시·사고, 예산현액, 집행 소계·당해·명시·사고, 집행률, 다음연도 이월 소계·명시·사고, 불용액), 머리 두 줄
3) 원·천원 단추로 금액 단위 전환
- 자세히 보기는 표 안에서 가로 스크롤
- 숫자 0은 "-"로 표시
#다. 배치최적화
○ 금액 자리 수에 맞춰 열 폭을 한 번에 정리하는 기능, 집행현황과 같은 방식으로 작동
1) 머리 줄 배치최적화를 누르면 열 폭을 내용에 맞게 자동 조정
2) 열 경계를 끌어 폭을 직접 조정, 경계를 두 번 누르면 그 열만 내용에 맞춤
3) 열 제목 우클릭으로 처음 폭으로 되돌리기
- 요약·자세히 보기의 열 폭은 따로 기억
#라. 검색
○ 사업이 많아져도 원하는 사업을 바로 찾도록 장부 안 검색 제공
1) 머리 줄 검색 칸에 사업명 입력, 치는 대로 바로 걸러 표시
2) 맞는 글자는 형광 표시
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
#마. 엑셀
○ 장부를 엑셀로 주고받고, 과거 해 자료를 양식으로 한 번에 넣도록 지원
1) 엑셀 ▾ → 내보내기 : 보는 해의 줄 전부를(접힌 줄도 펼쳐서) "YYYY 예산현황" 한 시트로, 고른 단위대로 저장
2) 엑셀 ▾ → 가져오기 : 같은 모양 시트에서 직접 적는 칸만 가져옴, "N줄의 직접 적는 값을 가져올까요?" 확인 뒤 입력
  - 집행현황에서 오는 칸은 가져오지 않음
  - 앱에 없는 세부사업·재원은 건너뛰고 몇 줄인지 안내
3) 엑셀 ▾ → 계약현황 양식 : 계약 한 줄마다 예산연도·재원별 원인행위와 연도별 지급액을 적은 양식으로 과거 해 자료를 한 번에 입력
  - 해마다 집행현황에 본사업·명시이월·사고이월 사업과 공사 줄을 만들고, 예산현황 설정(재원별 예산·이월·불용·공사별 재원)까지 자동으로 채움
  - 지급액은 그 계약의 오래된 예산(이월분)부터 쓴 것으로 계산
  - 집행현황에 이미 자료가 있는 해는 건너뜀
#바. 사업기간·설정
○ 사업마다 기간과 재원 종류를 정하는 설정 창, 재원이 둘 이상이면 재원별 예산과 공사별 재원을 나누는 표 제공
1) 사업기간 칸 끝 작은 ⚙ 또는 사업 줄 우클릭 "예산현황 설정"으로 창 열기
2) 왼쪽 사업 설정 : 기간(단년도·다년도, 시작~끝 해), 재원(국비·도비·시비 칩, 기타는 이름을 적고 enter), 이월 사업 잇기
  - 재원은 하나 이상 늘 남음
  - 명시이월 사업을 이으면 짝이 되는 사고이월 사업도 함께 이어짐
3) 오른쪽 재원 나누기(재원이 둘 이상일 때만) : 해를 고르고 재원별 예산 표에 재원마다 예산 입력
4) 공사별 재원 표 : 공사마다 계약금액을 재원 칸에 나눠 입력, 집행액은 그 비율대로 자동 배분
  - 빈 칸을 두 번 누르면 남은 금액이 자동으로 채워짐
  - 나누지 않은 공사는 첫 재원으로 계산
  - 표 아래 [+ 공사 추가]로 공사를 바로 넣으면 집행현황에도 등록
5) 재원별 예산 합계가 집행현황 예산과 맞으면 ✓, 다르면 붉게 표시되고 머리 줄에 "맞지 않는 곳 N" 배지
  - 맞지 않아도 저장되고, 장부 표에 붉게 남음
  - 표 아래에 원인·지출재원 확인 방법 안내
6) 예산현황에서 빼기 : 보낸 사업을 예산현황에서 다시 빼기

#사. 장부 표
○ 집행현황에서 보낸 세부사업의 예산·집행을 엑셀 "집행·이월 현황"과 같은 계산으로 정리한 장부
1) 집행현황 세부사업 줄 우클릭 "예산현황으로 보내기"로 보낸 사업만 표시
  - 이월 세부사업은 보낼 때 "기존 사업에 잇기 / 새 사업으로" 선택
2) 단년도 사업은 보는 해 한 줄, 다년도 사업은 세부사업 › 연도 › 재원 세 겹으로 펼침
  - 재원이 하나면 재원 줄 없이 연도 줄에서 바로 수정
3) 계산 : 당해예산 = 본예산 + 1추~4추, 전년도 이월 = 명시 + 사고, 예산현액 = 당해예산 + 전년도 이월, 집행률 = 집행액 ÷ 예산현액
4) 재원이 둘 이상이면 재원 줄 집행액은 공사별 재원대로 나눈 몫으로 표시
5) 다년도 사업은 남은 돈이 다음 해 전년도 이월로 이어짐
  - 재원별 예산 합이 집행현황 예산과 다르면 당해예산이 붉게, 마우스를 올리면 이유 표시
  - 이은 이월 사업의 전년도 이월이 앞 해 다음연도 이월과 다르면 붉게 표시
#아. 직접 적는 칸
○ 집행현황에 없는 값만 적도록 테두리 칸으로 구분, 집행현황에서 오는 당해예산·집행액은 잠김
1) 줄을 두 번 누르면 고치는 줄이 열리고 직접 적는 칸만 입력 가능
2) 다음연도 이월(명시·사고), 불용액, 추경 등 입력
3) enter나 바깥을 누르면 저장, esc는 취소
  - 다음연도 이월과 불용액은 자동 계산하지 않음, 남은 돈(현액 – 집행 – 이월 – 불용)은 마우스를 올리면 참고로 표시
  - 재원이 둘 이상이면 재원 줄 본예산도 직접 입력(설정 창 재원별 예산과 같은 값)
  - 집행현황에 그 해 자료가 없으면 본예산·집행액도 직접 입력
#자. 줄 메뉴·메모
○ 사업 줄에서 설정과 순서, 메모를 바로 다루도록 우클릭 메뉴와 메모 제공
1) 사업 줄 우클릭 : 예산현황 설정, 위로 옮기기, 아래로 옮기기
2) 사업 줄 연필 단추로 사업마다 메모 하나 작성
- 옮긴 순서는 그대로 기억
