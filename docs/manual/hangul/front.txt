@개요제목 프로그램 개요
@개요부제 흩어진 업무 자료를 한 프로그램에서 관리하는 개인 업무 도구
@개요
가. 도로 유지관리 업무에 쓰는 파일·민원·예산·일정·업무일지·연락처를 하나의 프로그램으로 통합
나. 모든 자료는 내 컴퓨터의 암호화 파일 한 개에 저장, 인터넷 연결 없이도 사용
다. 화면 크기·단축키·사용 모듈을 사용자에 맞게 설정
@제원
가. 프로그램 이름 : 기록앱(giLog), 버전 0.52.0(2026. 10. 29. 기준)
나. 설치 파일 : giLog_0.52.0_x64-setup.exe 1개(약 9.4MB)
다. 사용 환경 : Windows 10·11(64비트), Microsoft Edge WebView2(윈도우 기본 포함)
라. 기준 화면 : 1600×900 창(24인치 FHD·배율 100%), 최소 창 1024×700
마. 자료 저장 : 문서\giLog\gilog.db 한 파일, 비밀번호 기반 암호화(SQLCipher·Argon2)
바. 외부 연동(선택) : 구글 캘린더·할 일, 구글 시트(집행현황 팀 공유), 주소정보누리집, Claude Code(민원처리)
@기술
가. 화면 : React 18 + TypeScript 5(빌드 도구 Vite)
나. 앱 틀 : Tauri 2(Rust) – 창·트레이·윈도우 알림·파일 처리
다. 저장·암호화 : Rust 저장 모듈(SQLite + SQLCipher, Argon2)
라. 글꼴 : Pretendard
@분량
가. 화면(TypeScript·TSX) : 62개 파일, 25,389줄
나. 규칙 함수(TypeScript) : 54개 파일, 10,928줄(자동 시험 1,493줄 포함)
다. 화면 모양(CSS) : 15개 파일, 11,166줄
라. 앱 틀(Rust) : 17개 파일, 6,948줄
마. 저장·암호화(Rust) : 14개 파일, 8,065줄
바. 합계 : 162개 파일, 약 62,500줄(빈 줄 제외)
사. 개발 기간 : 2026. 10. 14. ~ 10. 29.(약 2주), 변경 기록 1,609회, 설치 파일 빌드 72회
@처음화면
○ 기록앱을 실행하면 잠금 화면이 표시되고, 비밀번호(또는 윈도우 PIN) 입력 후 시작 화면으로 이동
<잠금>
○ 시작 화면은 왼쪽 사이드바와 오른쪽 본문으로 구성
<화면>
가. 모듈 메뉴 : 모듈 화면 이동(아래쪽 업무연락처 포함), 설정에서 해제한 모듈은 숨김
나. 설정 : 기록앱 전체 및 모듈별 설정
다. 잠그기 : 자리를 비울 때 즉시 잠금(Ctrl+L), 설정한 시간 동안 입력이 없으면 자동 잠금
라. 접기 : 사이드바를 아이콘만 남기고 접어 본문을 넓게 사용(Ctrl+B)
마. 본문 : 선택한 모듈 화면 표시, 시작 화면은 설정에서 지정(초기값 업무일지)
