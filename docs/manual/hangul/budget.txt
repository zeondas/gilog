나. 세부사업 → 부기사업 → 공사(용역·물품) 위계 구조로 정리하여 합계를 자동 집계
다. 팀원끼리 구글 시트로 공유하여, 고친 값이 [새로고침]으로 서로의 앱에 반영

자. 집행률·가용액 : 예산 대비 집행 비율과 남은 쓸 수 있는 돈을 자동 계산
차. 숫자 칸 합계 : 숫자 칸 여러 개를 골라 개수·합계·차액 확인
@상세
#가. 해 고르기
○ 해마다 따로 관리하는 집행 표를 해 단위로 바꿔 보는 기능
1) 제목 옆 ‹ ›를 눌러 보는 해를 변경
2) 자료가 없는 해는 세부사업 추가·예산서 엑셀 가져오기·전년도에서 세부사업 복사 중 골라 시작
- 전년도에서 복사하면 이월·공사를 뺀 세부사업 이름·예산만 복사
#나. 새로고침
○ 같은 팀 담당자들이 구글 시트 하나로 집행현황을 함께 쓰는 기능, 평소엔 각자 앱에서 고치고 새로고침으로 서로의 값을 맞춤
1) 설정 → 집행현황 카드 → 팀 공유를 켬
2) 처음 켠 사람은 [새로 만들기]로 공유 시트를 만들고, 함께 쓰는 사람에 팀원 이름·구글 메일을 추가
3) 팀원은 받은 시트 주소를 같은 카드의 주소 칸에 붙여 넣고 [연결]
4) 해 고르기 옆 [새로고침]을 누르면 내 값을 올리고 팀원 값을 받음, 옆에 올린·받은 시각 표시
5) 같은 칸을 두 사람이 다르게 고쳤으면 주황 테두리 칸을 눌러 둘 중 하나를 선택
- 집행현황을 열 때와 열려 있는 동안 5분마다 자동으로 새로고침
- 받은 줄은 첫 칸 왼쪽 초록 선으로 표시, 띠의 [바뀐 것 보기]로 누가 어느 칸을 고쳤는지 확인
- 팀 공유를 켜면 "담당" 열이 생기고, 세부사업마다 담당자 한 명 지정 가능
- 인터넷이 끊겨도 내 컴퓨터에서 보고 고칠 수 있고, 다음 새로고침 때 올라감
- 공유 범위는 집행현황만, 예산현황·민원대장 등은 내 컴퓨터에만 저장

#다. 집행액·시공량
○ 담당자마다 견해가 다른 잔액·집행률 기준을 고르는 단추, 고른 기준은 기억
1) 머리 줄 "집행액 | 시공량" 중 하나를 누름
2) 잔액 = 원인행위 − 고른 기준, 집행률 = 고른 기준 합계 ÷ 예산으로 다시 계산
- 원인행위·고른 기준 열·잔액 세 열이 옅은 보라로 표시
- 가용액은 기준과 상관없이 같은 값
#라. 원·천원
○ 금액을 원 또는 천원 단위로 바꿔 보는 단추
1) 머리 줄 "원 | 천원" 중 하나를 누름
2) 천원을 고르면 반올림한 정수로 표시, 입력도 천원 단위
- 손대지 않은 칸은 원래 원 단위 값 그대로 보존
#마. 배치최적화
○ 보이는 내용 중 가장 긴 글에 맞춰 열 폭을 한 번에 정리하는 기능
1) 머리 줄 [배치최적화]를 누름
2) 고정 폭 열을 뺀 모든 열이 글 길이에 맞춰지고, 남는 폭이 있으면 표를 왼쪽으로 모음
3) 열 제목 끝선을 끌면 그 열 폭만 변경, 끝선을 두 번 누르면 내용에 맞춤
- 열 제목 우클릭으로 처음 폭으로 복귀
#바. 사업 추가
○ 표에 세부사업 한 줄을 더하는 단추
1) 머리 줄 [사업 추가]를 누름
2) 그 자리에 빈 입력 줄이 열리면 세부사업 이름·예산을 입력
3) enter나 바깥 누르기는 저장, esc는 취소
- 부기사업·공사는 줄 우클릭 메뉴에서 추가
#사. 엑셀
○ 예전 엑셀 집행현황을 옮겨 오고, 보고용 엑셀로 내보내는 기능
1) 머리 줄 [엑셀 ▾]를 누름
2) 가져오기 : 앱에서 내보낸 파일과 예전 집행현황 시트 모두 가져오기 가능
3) 내보내기 : 고른 해·단위로 시트 한 장 저장, 합계 줄은 수식으로 기입
- 같은 해에 다시 가져오면 같은 이름은 파일 값으로 덮어쓰고 없는 것만 추가, 덮어쓰기·새로 더하기 건수를 먼저 확인
- 한 칸에 부기사업이 여럿이면 하나로 넣고 "확인 필요"로 안내
#아. 집행 표
○ 세부사업 → 부기사업(산출항목) → 공사(용역·물품)를 한 표에 위계 구조로 정리, 위 줄에는 아래 줄 합계가 자동 표시
1) 줄을 한 번 누르면 선택, 두 번 누르면 그 자리에서 수정
2) 바깥을 누르면 저장, esc는 취소
3) 줄 우클릭 메뉴 : 세부사업·부기사업·공사 추가, 수정·메모·단계·다른 곳으로 옮기기·위/아래로·지우기
4) 공사 줄 공사명 칸에 이름이나 초성을 입력하면 업무연락처 사업이 후보로 표시, 고르면 업체도 자동 입력
5) 단계 배지(준비·추진·완료·중지·타절)를 눌러 공사 진행 단계 변경
- 금액을 입력하는 동안 잔액·집행률·합계가 바로 다시 계산
- 끝난 공사는 회색 글자로 아래에, 이월 사업은 표 아래 "이월 사업" 묶음으로 표시
- 지우기는 딸린 줄 수를 알려 주고 확인, 고른 공사는 del 키로도 삭제
- 메모는 굵게·밑줄·머릿기호 등을 쓰는 메모 창에서 입력

#자. 집행률·가용액
○ 예산 대비 얼마나 집행했는지와 앞으로 쓸 수 있는 돈을 자동으로 계산하여, 엑셀 수식 없이 한눈에 확인
1) 집행률 = 고른 기준(집행액 또는 시공량) 합계 ÷ 예산
2) 가용액 = 예산 − 원인행위 합계(완료·타절 공사는 원인행위와 집행액 중 큰 값)
3) 공사 줄의 회색 막대는 원인행위 대비 집행 정도 표시
- 가용액이 0 아래로 내려가 예산을 넘으면 붉게 표시
- 가용액은 세부사업·부기사업 줄에만 표시
#차. 숫자 칸 합계
○ 엑셀처럼 숫자 칸을 여러 개 골라 합계·차액을 바로 확인하는 기능
1) 숫자 칸 하나를 누름
2) ctrl+누르기는 한 칸씩 추가·제외, shift+누르기는 처음 칸부터 거기까지 네모로 선택
3) 두 칸 이상 고르면 표 오른쪽 아래에 개수·합계 표시
4) 딱 두 칸이면 차액(먼저 누른 칸 − 나중 칸)도 표시
- 예산·원인행위·집행액·시공량·잔액·가용액 열에서 사용 가능
- esc를 누르거나 해를 바꾸면 선택 해제
