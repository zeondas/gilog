@상세
#가. 연도 선택
○ 연도별로 관리하는 집행 표를 연도 단위로 전환하여 조회하는 기능
1) 제목 옆 ‹ › 클릭으로 조회 연도 변경
2) 자료가 없는 연도는 [세부사업 추가]·[예산서 엑셀 가져오기]·[(전년도)년에서 세부사업 복사] 중 선택
- 전년도 복사 시 이월 사업·공사를 제외한 세부사업·부기사업 이름과 예산만 복사
#나. 새로고침
○ 같은 팀 담당자가 구글 시트 하나로 집행현황을 공동 관리하는 기능, 각자 수정 후 새로고침으로 상호 반영
1) 설정 → 집행현황 카드 → "팀 공유" 사용 설정
2) 최초 사용자는 [새로 만들기]로 공유 시트 생성, "함께 쓰는 사람"에 팀원 이름·구글 메일 입력
3) 팀원은 받은 시트 주소를 같은 카드의 주소 입력란에 붙여 넣고 [연결] 클릭
4) 연도 옆 [새로고침] 클릭 시 내 수정값 업로드·팀원 수정값 수신, 옆에 "올림·받음" 시각 표시
5) 같은 칸을 두 사람이 다르게 수정한 경우 주황 테두리 칸을 클릭하여 둘 중 하나 선택
- 집행현황을 열 때와 열려 있는 동안 5분마다 자동 새로고침
- 받은 행은 첫 칸 왼쪽 초록 선으로 표시, [바뀐 것 보기] 또는 "받음" 시각 클릭으로 수정 내역 확인
- 팀 공유 사용 시 "담당" 열 표시, 세부사업별 담당자 1명 지정 가능
- 인터넷 연결이 끊겨도 조회·수정 가능, 다음 새로고침 때 업로드
- 공유 범위는 집행현황만 해당, 예산현황·민원대장 등은 내 컴퓨터에만 저장

#다. 집행률·시공량 보기
○ 잔액·비율 계산 기준을 집행액 또는 시공량으로 전환하는 기능, 선택한 보기는 저장
1) 상단 [집행률]·[시공량] 중 하나를 클릭
2) 집행률 보기 : 시공량 열 숨김, 잔액·막대·합계 비율을 집행액 기준으로 계산
3) 시공량 보기 : 집행액 열 숨김, 잔액·막대를 시공량 기준으로 계산
  - 합계 비율은 "사용률"(시공량 합계 ÷ 예산)로 표시
- 가용액은 보기와 관계없이 같은 값
- 엑셀 내보내기도 선택한 보기 기준으로 열 숨김 처리
#라. 원·천원
○ 금액을 원 또는 천원 단위로 전환하여 표시하는 기능
1) 상단 [원]·[천원] 중 하나를 클릭
2) 천원 선택 시 반올림한 정수로 표시, 입력도 천원 단위
- 수정하지 않은 칸은 원 단위 값 그대로 보존
#마. 열 폭 조정
○ 열 제목 경계로 열 폭을 조정하는 기능, 조정한 폭은 열별로 저장
1) 열 제목 오른쪽 경계를 드래그하면 해당 열 폭만 변경, 표가 넓어지면 표 안에서 가로 스크롤
2) 경계를 더블클릭하면 해당 열을 내용에 맞춤
3) 열 제목 행 우클릭 → "내용에 맞춤(모든 열)" 또는 "처음 폭으로" 선택
- 구분·집행률·단계·담당·메모 열은 고정 폭
- 열 제목 클릭 시 해당 열 음영 표시, 다시 클릭하면 해제
#바. 사업 추가
○ 집행 표에 세부사업 1행을 추가하는 버튼
1) 상단 [사업 추가] 클릭
2) 해당 위치에 빈 입력 행이 표시되면 세부사업명·예산 입력
3) Enter 또는 바깥 클릭 시 저장, Esc는 취소
- 세부사업을 선택한 상태면 그 아래에 추가
- 부기사업·공사는 행 우클릭 메뉴에서 추가
#사. 엑셀
○ 기존 엑셀 집행현황을 불러오고, 보고용 엑셀로 내보내는 기능
1) 상단 [엑셀 ▾] 클릭
2) "가져오기" : 기록앱에서 내보낸 파일과 기존 집행현황 시트 모두 가져오기 가능
3) "내보내기" : 선택한 연도·단위·보기로 시트 1매 저장, 합계 행은 수식으로 기재
- 같은 연도에 다시 가져오면 같은 이름은 덮어쓰고 없는 것만 추가, 건수 사전 확인
- 한 칸에 부기사업이 여럿이면 하나로 입력하고 메모에 "확인 필요" 표시
#아. 집행 표
○ 세부사업 → 부기사업(산출항목) → 공사(용역·물품)를 한 표에 정리, 상위 행에 하위 합계 자동 표시
1) 행 클릭 시 선택, 더블클릭 시 표에서 바로 수정
2) 바깥 클릭 시 저장, Esc는 취소
3) 행 우클릭 메뉴 : 세부사업·부기사업·공사 추가, "수정"·"메모"·"단계", 이동·삭제
4) 공사 행 공사명 입력란에 이름이나 초성 입력 시 업무연락처 사업이 후보로 표시, 선택하면 업체도 자동 입력
5) 단계 배지(준비·추진·완료·중지·타절) 클릭으로 공사 진행 단계 변경
- 금액 입력 중 잔액·집행률·합계 즉시 재계산
- 완료·타절 공사는 회색 글자로 아래에, 이월 사업은 표 아래 "이월 사업" 묶음으로 표시
- 삭제 시 하위 행 수를 안내하고 확인, 선택한 공사는 Delete로도 삭제
- 메모는 굵게·밑줄·머릿기호 등을 지원하는 메모 창에서 입력
- 상단 검색란에 공사명·업체 입력 시 해당 공사만 필터 표시

#자. 집행률·가용액
○ 예산 대비 집행 비율과 가용액을 자동 계산, 엑셀 수식 없이 바로 확인
1) 집행률 = 집행액 합계 ÷ 예산(시공량 보기는 사용률 = 시공량 합계 ÷ 예산)
2) 가용액 = 예산 − Σ(완료·타절 공사는 집행액, 그 외 공사는 원인행위)
3) 공사 행 잔액 = 원인행위 − 집행액(시공량 보기는 시공량), 회색 막대로 진행 정도 표시
- 가용액이 0 미만(예산 초과)이면 붉게 표시
- 가용액은 세부사업·부기사업 행에만 표시
#차. 숫자 칸 합계
○ 엑셀처럼 숫자 칸을 여러 개 선택하여 합계·차액을 즉시 확인하는 기능
1) 숫자 칸 하나를 클릭
2) Ctrl+클릭은 한 칸씩 추가·제외, Shift+클릭은 기준 칸부터 해당 칸까지 사각 범위 선택
3) 2칸 이상 선택 시 표 오른쪽 아래에 개수·합계 표시
4) 2칸 선택 시 차액(먼저 선택한 칸 − 나중 칸)도 표시
- 예산·원인행위·집행액·시공량·잔액·가용액 열에서 사용 가능
- Esc를 누르거나 연도를 변경하면 선택 해제
