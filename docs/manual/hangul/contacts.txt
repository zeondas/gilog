@화면 업무연락처
@부제목 업무로 만나는 사람을 사업별로 묶어 두고 바로 꺼내 쓰는 도구
@기획의도
가. 업무로 만나는 사람을 한 사람에 카드 한 장으로 모아 관리
나. 사람마다 사업을 지정하여 사업별로 묶어서 열람
다. 업무일지의 상대, 민원처리의 현장대리인, 집행현황의 담당이 여기서 사람을 불러옴, 한 번 입력해 두면 다시 찾을 일이 없도록 구현
@기능별
가. 신규 줄 : 이름만 입력해도 연락처 등록, 사업도 함께 지정
나. 사업 관리 : 사업 추가, 이름·그룹·색 수정과 삭제
다. 검색 : 이름·소속·번호로 연락처 검색
라. 엑셀 : 엑셀 업무연락처 가져오기·내보내기
마. 사업 목록 : 사업을 누르면 그 사업 사람만 표시
바. 카드 : 이름·직위·소속과 연락처를 한 장에 표시, 두 번 눌러 수정
사. 사업 배지 : 한 사람에 여러 사업 지정, 색은 자동 지정
아. 번호·메일 : 누르면 바로 복사
자. 메모 : 카드 안에서 바로 메모 작성
@상세
#가. 신규 줄
○ 화면 맨 위에 늘 열려 있는 입력 줄, 이름만 있으면 바로 등록되도록 구현
1) 이름, 소속, 직위, 무선, 유선, 이메일, 사업 순서로 입력
2) tab이나 enter로 다음 칸 이동, 마지막 칸에서 enter를 누르면 등록
3) 사업 칸에 이름을 입력하면 후보 목록이 뜨고, enter·tab으로 배지 지정(↑↓로 후보 변경)
4) 목록에 없는 이름은 "새 사업으로 추가"로 등록할 때 새 사업 생성
- 이름은 꼭 입력해야 하는 칸
- 전화번호는 숫자만 입력하면 하이픈 자동 입력(010-1234-5678), 네 자리까지는 내선번호로 그대로
- 사업 칸이 비었을 때 backspace는 마지막 배지 빼기
#나. 사업 관리
○ 사업을 그룹별로 묶어 한 창에서 추가·수정·삭제
1) 머리 줄 "사업 관리" 단추를 누르면 사업 관리 창 표시
2) 위 입력 줄에 그룹·사업명·축약 공사명을 입력하여 사업 추가, 둘 중 하나만 입력해도 가능
3) 줄을 두 번 누르거나 연필을 누르면 그 자리에서 그룹·사업명·축약 수정
4) 머리 줄 "사업명"·"연락처"를 누르면 가나다·많은 순으로 정렬
5) 그룹 머리 우클릭 : 이름 바꾸기, 위로/아래로 옮기기, 그룹 지우기(사업은 "그룹 없음"으로 이동)
- 사업을 지우면 사람은 남고 배지만 빠짐, 지우기 전에 붙은 사람 수를 알려 주고 한 번 더 확인
- 정식 이름(문서용)과 줄인 이름(관리용)을 따로 둘 수 있음, 화면은 줄인 이름, 문서·엑셀은 정식 이름 사용
- 창 양옆 가장자리를 끌어 폭 조절, 두 번 누르면 처음 폭
<그림>
#다. 검색
○ 많은 연락처 가운데 필요한 사람을 바로 찾도록 검색 칸 제공
1) 오른쪽 위 검색 칸에 이름·소속·번호를 입력
2) 입력하는 대로 맞는 카드만 남고, 맞는 글자는 형광 표시
- 초성 검색 가능(ㅂㅈㅎ, 박ㅈ)
- 칸 끝의 x나 esc 키로 입력한 글자를 한 번에 삭제
#라. 엑셀
○ 쓰던 엑셀 업무연락처를 그대로 가져오고, 필요할 때 엑셀로 내보내기
1) "엑셀 ▾" 단추에서 가져오기·내보내기 선택
2) 가져오기는 파일을 고른 뒤 덮어쓰기 또는 대체하기 선택
- 덮어쓰기 : 같은 사람은 파일 내용으로 덮고 새 사람은 추가
- 대체하기 : 지금 연락처를 모두 지우고 파일 내용만 남김
3) 내보내기는 한 사람이 한 줄, 사업이 여러 개면 한 칸 안에 한 줄씩
- 이미 있는 사람(이름·소속·무선 번호가 같음)은 새로 만들지 않음
#마. 사업 목록
○ 화면 왼쪽에 사업을 그룹별로 모아, 사업 단위로 사람을 바로 확인
1) 사업을 누르면 그 사업 사람만 표시, 맨 위 "전체"는 모든 사람
2) 목록 위 찾기 칸에서 사업 이름 검색, 초성 가능
3) 가나다·많은 순 정렬 선택
4) 그룹 머리를 누르면 그룹 접기·펼치기
- 연락처가 없는 사업은 맨 아래 "연락처 없음", 그룹 없는 사업은 "그룹 없음"에 표시
#바. 카드
○ 한 사람에 카드 한 장, 머리띠에 이름·직위·소속, 그 아래 사업 배지와 연락처 표시
1) 카드를 두 번 누르거나 마우스를 올렸을 때 나오는 연필을 누르면 카드 전체 수정
2) tab은 다음 칸, enter는 저장, esc는 취소
3) 지우기 : 수정 중인 카드 아래 붉은 지우기 단추, "이 연락처를 지울까요?" 확인 후 삭제
- 카드 바깥을 누르면 고친 내용 저장
#사. 사업 배지
○ 한 사람이 여러 사업에 관여하는 경우가 많아, 사업 여러 개를 배지로 지정
1) 수정 중인 카드의 "＋ 사업 찾아 붙이기" 칸에 이름을 입력하여 추가
2) 배지의 x를 눌러 빼기
- 색은 8색 가운데 자동 지정, 사업 관리 창에서 직접 변경 가능
- 배지가 길면 "…"로 줄이고, 마우스를 올리면 정식 이름 표시
#아. 번호·메일
○ 전화·메일을 보낼 때 번호를 옮겨 적지 않도록 누르면 바로 복사
1) 카드의 무선·유선·메일을 누르면 그 값을 복사
2) "복사했어요"가 잠깐 표시
#자. 메모
○ 사람에 대해 알아 둘 내용을 카드 안에 바로 기록
1) 카드의 메모 글을 눌러 그 자리에서 작성, 메모가 없으면 마우스를 올렸을 때 "메모 추가" 표시
2) enter는 같은 위계 다음 줄, shift+enter는 한 위계 아래 줄, tab은 저장하고 닫기, esc는 취소
- 머릿기호 규칙(□ → ● → -) 적용
