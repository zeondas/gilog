@화면 업무연락처
@부제목 업무 관계자를 사업별로 묶어 관리하고 즉시 활용하는 연락처 도구
@기획의도
가. 업무 관계자를 1인 1카드로 모아 관리
나. 사람마다 사업을 지정하여 사업별로 묶어 열람
다. 업무일지 상대, 민원처리 현장대리인, 집행현황 담당이 여기서 사람을 불러옴, 한 번 입력으로 재검색 불필요
@기능별
가. 신규 행 : 이름만 입력해도 연락처 등록, 사업 동시 지정
나. 사업 관리 : 사업 추가, 사업명·그룹·색 수정 및 삭제
다. 검색 : 이름·소속·번호로 연락처 검색
라. 엑셀 : 엑셀 업무연락처 가져오기·내보내기
마. 사업 목록 : 사업 클릭 시 해당 사업 관계자만 표시
바. 카드 : 이름·직위·소속과 연락처를 한 장에 표시, 더블클릭으로 수정
사. 사업 배지 : 1인에 여러 사업 지정, 색은 자동 지정
아. 번호·메일 : 클릭 시 즉시 복사
자. 메모 : 카드 안에서 바로 메모 작성
@상세
#가. 신규 행
○ 화면 맨 위에 상시 표시되는 입력 행, 이름만 있으면 즉시 등록되도록 구현
1) 이름, 소속, 직위, 무선, 유선, 이메일, 사업 순서로 입력
2) Tab 또는 Enter로 다음 입력란 이동, 마지막 입력란에서 Enter를 누르면 등록
3) 사업 입력란에 이름 입력 시 후보 목록 표시, Enter·Tab으로 배지 지정(↑·↓로 후보 변경)
4) 목록에 없는 이름은 "＋ 새 사업으로 추가" 선택 시 등록과 함께 새 사업 생성
- 이름은 필수 입력 항목
- 전화번호는 숫자·하이픈만 입력 시 규칙에 맞게 하이픈 자동 배치(010-72805715 → 010-7280-5715)
- 4자리 이하는 내선번호로 그대로 유지, 자릿수가 모자라면 숫자만 남김, 괄호·공백·문자 포함 시 입력 그대로
- 사업 입력란이 비었을 때 Backspace는 마지막 배지 제거
#나. 사업 관리
○ 사업을 그룹별로 묶어 한 창에서 추가·수정·삭제
1) 상단 [사업 관리] 클릭 시 사업 관리 창 표시
2) 위 입력 행에 그룹·사업명·축약 공사명을 입력하여 [추가], 둘 중 하나만 입력해도 가능
3) 행 더블클릭 또는 우클릭 "수정"으로 그 자리에서 그룹·사업명·축약 공사명 수정
4) 행 우클릭 : "수정", "그룹 변경", "지우기"(재확인 후 삭제)
5) 그룹 우클릭 : "이름 바꾸기", "위로 옮기기"·"아래로 옮기기", "그룹 지우기"(사업은 "그룹 없음"으로 이동)
6) 열 제목 "사업명"·"연락처" 클릭 시 가나다·많은 순 정렬
- 사업 삭제 시 사람은 유지되고 배지만 제거, 삭제 전 연결된 인원수를 표시하고 재확인
- 정식 이름(문서용)과 축약 이름(관리용) 별도 지정, 화면은 축약 이름, 문서·엑셀은 정식 이름 사용
- 창 기본 폭 680, 양옆 가장자리 드래그로 폭 조절(크기 기억), 긴 사업명은 "…" 표시
- 열 오른쪽 경계 드래그로 그 열만 폭 조절, 경계 더블클릭 시 내용에 맞춤
- 열 제목 우클릭 : "내용에 맞춤(모든 열)", "처음 폭으로"
<그림>
#다. 검색
○ 다수 연락처 중 필요한 사람을 즉시 찾도록 검색란 제공
1) 오른쪽 위 검색란에 이름·소속·번호 입력
2) 입력과 동시에 일치하는 카드만 표시, 일치 글자는 형광 표시
- 이름은 초성 검색 가능(ㅂㅈㅎ, 박ㅈ)
- 검색란 끝의 × 또는 Esc로 입력 내용 일괄 삭제
#라. 엑셀
○ 기존 엑셀 업무연락처를 그대로 가져오고, 필요 시 엑셀로 내보내기
1) [엑셀 ▾]에서 가져오기·내보내기 선택
2) 가져오기는 파일 선택 후 덮어쓰기 또는 대체하기 선택
- 덮어쓰기 : 같은 사람은 파일 내용으로 갱신, 새 사람은 추가
- 대체하기 : 현재 연락처를 모두 삭제하고 파일 내용만 유지
3) 내보내기는 1인 1행, 사업이 여러 개면 한 칸 안에 한 줄씩 기재
- 이름·소속·무선 번호가 같으면 같은 사람으로 처리(중복 생성 안 함)
#마. 사업 목록
○ 화면 왼쪽에 사업을 그룹별로 모아 사업 단위로 관계자를 즉시 확인
1) 사업 클릭 시 해당 사업 관계자만 표시, 맨 위 "전체"는 모든 사람
2) 목록 위 "사업 찾기" 입력란에서 사업 이름 검색, 초성 가능
3) 가나다·많은 순 정렬 선택
4) 그룹 이름 클릭 시 그룹 접기·펼치기
- 연락처가 없는 사업은 각 묶음 아래쪽, 그룹 없는 사업은 "그룹 없음"에 표시
#바. 카드
○ 1인 1카드, 상단에 이름·직위·소속, 그 아래 사업 배지와 연락처 표시
1) 카드 더블클릭 또는 마우스를 올리면 나오는 연필 클릭 시 카드 전체 수정
2) Tab·Enter는 다음 입력란(마지막 입력란이면 저장), Esc는 취소
3) 삭제 : 수정 중인 카드 아래 붉은 삭제 버튼, "이 연락처를 지울까요?" 확인 후 삭제
- 카드 바깥 클릭 시 수정 내용 저장
#사. 사업 배지
○ 1인이 여러 사업에 관여하는 경우가 많아 사업 여러 개를 배지로 지정
1) 수정 중인 카드의 "＋ 사업 찾아 붙이기" 입력란에 이름을 입력하여 추가
2) 배지의 × 클릭 시 제거
- 색은 8색 중 자동 지정, 사업 관리 창에서 직접 변경 가능
- 배지가 길면 "…"로 줄이고, 마우스를 올리면 정식 이름 표시
#아. 번호·메일
○ 전화·메일 발송 시 번호를 옮겨 적지 않도록 클릭 즉시 복사
1) 카드의 무선·유선·메일 클릭 시 해당 값 복사
2) "복사했어요"가 일시적으로 표시
#자. 메모
○ 관계자에 대한 참고 사항을 카드 안에 바로 기록
1) 메모 더블클릭 시 그 자리에서 수정, 메모가 없으면 마우스를 올렸을 때 [메모 추가] 표시
2) Enter는 같은 위계 다음 줄, Shift+Enter는 한 위계 아래 줄, Tab은 저장 후 닫기, Esc는 취소
- 머릿기호 규칙(□ → ● → -) 적용
