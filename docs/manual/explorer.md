# 탐색기
정의: 두 창으로 파일을 옮기고 고치는 앱 안의 파일 관리자
장면: screen_00

## 기획 의도
- 프리커맨더처럼 두 창을 나란히 두고, 윈도우 탐색기의 키·끌어 놓기·우클릭을 그대로 써요.
- 회사 문서보안 해제도 앱 안 우클릭에서 바로 시작해요.
- 민원처리가 만든 지시부·사진이 쌓이는 폴더를 같은 화면에서 다뤄요.

## 번호
1. 파일 찾기 | label.search.fx-search | 모든 드라이브에서 이름으로 바로 찾아요. "자세히 ▾"로 조건을 더해요. | 위
2. 머리 줄 단추 | div.fx-tools | 창 나누기(트리·두칸·세칸·네칸)와 미리보기·이름변경 등이에요. 켜진 단추는 채운 색이에요. | 위
3. 폴더 트리 | aside.fx-tree | 폴더를 누르면 지금 창에 열려요. 맨 위는 즐겨찾기예요. | 아래
4. 탭 | button.fx-tab | 창마다 여러 폴더를 탭으로 열어 둬요. 우클릭은 탭 메뉴예요. | 위
5. 드라이브·빠른 필터 | div.fx-row1 | 드라이브로 바로 가고, 빠른 필터로 지금 목록을 걸러요. | 위
6. 경로 단추 | button.fx-ib | 경로 복사 · 윈도우 탐색기로 열기 · ★ 즐겨찾기 더하기/빼기예요. | 위
7. 목록 | .fx-frow >> nth=2 | 두 번 누르면 열려요. 우클릭은 윈도우 메뉴 그대로예요. | 아래 왼끝
8. 단축키 줄 | div.fx-keys | `F5` 복사·`F6` 옮기기는 반대 창으로 가요. | 아래 왼끝

## 열린 모습
- files_tabmenu | div.fx-tabmenu | 탭 우클릭 메뉴 | 고정·복제·반대 창에 열기·다른 탭 모두 닫기가 나와요.
- files_delete | div.dialog | 지우기 확인 | `F8`을 누르면 "지울까요?"를 묻고 휴지통으로 보내요.

## 알아 두면 좋은 것
- 윈도우 탐색기 키가 그대로 돼요: `Ctrl+C`·`X`·`V`(윈도우 탐색기·바탕 화면과 오감) · `Alt+↑` 위 폴더 · `Ctrl+Z` 되돌리기 · `Ctrl+F` 상세 찾기.
- 보안 해제: 파일 우클릭 맨 아래 "윈도우 탐색기에서 열기 · 보안 해제"를 누르면 윈도우 탐색기가 그 파일을 골라 둔 채 메뉴를 띄워요.
- 민원처리의 지시부·사진은 민원 폴더(처음 D:\민원처리)에 "접수일_위치_보수내용" 이름으로 쌓여요.
- 같은 이름이 있으면 파일마다 건너뛰기·덮어쓰기·둘 다 두기를 물어요. `Shift+F8`은 휴지통을 거치지 않고 완전히 지워요.

## 확인
- 정의·기획 의도 초안 – 확인
- 사양서 탐색기 절 첫머리에 "아직 시안 단계라 이 절 전체가 앱에 없어요"가 남아 있어요 – 지운 줄인지 확인
- 사양서는 탭 우클릭에 "닫기(Ctrl+W)"가 있다는데 열린 모습(탭 하나)에는 없어요 – 탭이 하나일 때 빼는 것인지 확인
- 사양서 "민원처리 줄의 '파일' 단추 = 탐색기 열고 빠른 필터에 이름"인데 민원처리 화면에 그 단추가 없어요(⋯ 메뉴 "저장 폴더 열기"만) – 어느 쪽이 맞는지 확인
