# 탐색기
정의: 컴퓨터 내 업무 파일을 체계적으로 관리하는 도구
장면: screen_00

## 기획 의도
- 회사 업무 환경에 맞는 무료 파일 탐색기 프로그램을 제공해요. 지원이 끝난 구형 탐색기 사용은 이제 그만.
- Everything과 같은 고속 검색 기능을 프로그램에 내장해, 탐색기와 같이 쓸 수 있도록 했어요.
- 바쁜 업무 중 너저분하게 열려 있는 폴더 창을 줄일 수 있도록 탐색기 다중 분할 기능을 제공해요.

## 상세 설명
### 파일 찾기
컴퓨터의 모든 드라이브에서 파일·폴더 이름을 바로 찾아요. Everything처럼 파일 목록을 미리 만들어 두고 찾아서, 치는 대로 결과가 나와요.
1. 머리 줄 왼쪽 찾기 칸에 이름 일부를 쳐요.
2. 잠깐 멈추면 지금 창에 "찾기" 탭이 열리고, 치는 대로 결과가 바뀌어요. 위 띠에 "모든 드라이브 · N개 · 걸린 시간"이 보여요.
3. `Enter`를 누르면 커서가 결과 목록으로 가요.
4. 결과를 두 번 누르면 파일이 열리고, 찾기 탭은 그대로 남아요. `Ctrl+Enter`는 그 파일이 있는 폴더를 새 탭으로 열어요.
- 결과에서도 복사·옮기기·이름 바꾸기·보안 해제가 그대로 돼요.
- 칸 끝의 ×나 `Esc`로 친 글자를 한 번에 지워요.
- 빠른 찾기는 설치할 때 관리자 허용을 한 번 받아 둬요. 네트워크·USB 드라이브와 윈도우·프로그램 폴더는 목록에 없어서, 그곳은 예전처럼 폴더를 차례로 뒤져 찾아요. 켜고 끄기는 설정 → 탐색기 "빠른 찾기"예요.

### 상세 찾기
이름 말고도 파일 안의 글자, 날짜, 크기로 좁혀 찾아요.
그림: files_findmore | .fx-findpanel | 찾기 칸 오른쪽 "자세히 ▾"를 누르면 열리는 상세 찾기
1. 찾기 칸 오른쪽 "자세히 ▾"를 눌러요(`Ctrl+F`도 같아요).
2. **이름**에 찾을 이름을 적어요. `*`는 아무 글자, `?`는 한 글자, 여러 개는 `;`로 나눠요. 예: `*.hwp;*.pdf`
3. **안의 글자**에 파일 속 글을 적으면 한글·워드·엑셀·파워포인트·PDF·텍스트 파일 안에서 찾아요.
4. **어디서**는 비우면 모든 드라이브, 폴더를 적으면 그 폴더 아래만 찾아요. "하위 폴더"를 끄면 그 폴더만 봐요.
5. 필요하면 **수정한 날**·**크기**를 범위로 적고, "잠긴 파일만"·"민원과 이어진 것만"을 골라요.
6. [찾기]를 누르면 지금 창에 "찾기: …" 탭으로 결과가 나와요. 위 띠의 "조건 고치기"·"다시 찾기"로 이어서 찾아요.
- 자주 쓰는 조건은 [조건 저장]으로 남겨 두면 다음에 그대로 불러와요.

### 머리 줄 단추
창 나누기와 자주 쓰는 일을 한 줄에 모았어요. 켜져 있는 단추는 채운 색이에요. 창을 여럿으로 나눠 쓰면 윈도우 탐색기 창을 여러 개 띄우지 않아도 돼요.
- **새로고침**(`Ctrl+R`) – 지금 폴더를 다시 읽어요. 다른 프로그램에서 돌아오면 저절로 다시 읽어요.
- **배치복구** – 폴더 트리 폭과 창 사이 크기를 처음대로 되돌려요.
- **트리보기** – 왼쪽 폴더 트리를 켜고 꺼요.
- **두칸보기** – 두 창으로 나눠요. 한 번 더 누르면 좌우 ↔ 상하로 바뀌어요.
- **세칸보기** – 세 창으로 나눠요. 한 번 더 누르면 긴 칸이 왼쪽 ↔ 오른쪽으로 바뀌어요.
- **네칸보기** – 2×2 네 창으로 나눠요.
- **펼쳐보기** – 하위 폴더의 파일까지 한 목록 탭으로 모아 봐요.
- **미리보기** – 대상 창 자리에 고른 파일을 미리 봐요(`Alt+P`).
- **숨긴파일** – 숨김 파일을 흐리게 보여 줘요.
- **같은폴더** – 대상 창을 지금 창과 같은 폴더로 열어요.
- **창바꾸기** – 지금 창과 대상 창을 서로 바꿔요.
- **이름변경** – 고른 파일들의 일괄 이름 바꾸기 창을 열어요.
지금 창은 마지막으로 누른 창, 대상 창은 그 바로 전에 있던 창이에요. 세칸·네칸에서는 두 창에 테두리가 생겨요. `F5` 복사·`F6` 옮기기는 늘 대상 창으로 가고, `Tab`은 다음 창, `Ctrl+1`~`4`는 창을 바로 골라요. 창 사이 경계를 끌면 크기가 바뀌어요.

### 일괄 이름 바꾸기
여러 파일 이름을 규칙 하나로 한 번에 바꿔요.
1. 목록에서 바꿀 파일들을 골라요.
2. 머리 줄 **이름변경**을 눌러요.
3. 패턴 칸에 새 이름 규칙을 적어요. `[n]` 기존 이름 · `[c]` 번호 · `[ymd]` 수정한 날 · `[p]` 상위 폴더 이름 · `[e]` 확장자. 예: `[ymd]_[n]`
4. 필요하면 찾기·바꾸기(대소문자·모든 발생·확장자 제외), 번호(시작·증가·자릿수)를 정해요.
5. 위 목록의 "새 이름"에서 결과를 미리 봐요. 겹치는 이름이나 쓸 수 없는 글자는 빨간 줄이 되고 바꾸기가 막혀요.
6. [이름 바꾸기] 또는 맨 아래 [확인](바꾸고 닫기)을 눌러요. 잘못 바꿨으면 [되돌리기].

### 폴더 트리
폴더를 누르면 지금 창에 열리고, 트리는 지금 창의 폴더를 따라 펼쳐져요. 맨 위 "즐겨찾기" 묶음에는 ★로 지정한 폴더가 모여요.
1. 자주 쓰는 폴더를 열어요.
2. 경로 줄 오른쪽 ★를 눌러요. 별이 채워지면 즐겨찾기에 들어간 거예요.
3. 트리 맨 위 "즐겨찾기" 묶음과 드라이브 줄 끝 [★ 즐겨찾기]에 그 폴더가 보여요. 빼려면 그 폴더에서 ★를 다시 눌러요.
- 트리에 보일 드라이브와 즐겨찾기 묶음은 설정 → 탐색기 → **폴더 트리**에서 켜고 꺼요(아래 "설정 → 탐색기").
- 트리와 창 사이 경계를 끌면 폭이 바뀌고, 두 번 누르면 처음 폭으로 돌아가요.
- 트리의 폴더를 우클릭하면 이름 바꾸기·새 폴더·보안 해제를 할 수 있어요.

### 탭
창마다 여러 폴더를 탭으로 열어 두고 오가요.
그림: files_tabmenu | div.fx-tabmenu | 탭을 우클릭하면 나오는 탭 메뉴
- 새 탭은 탭 줄 끝 ＋로 열어요. 새 탭이 여는 폴더는 설정 → 탐색기 "새 탭이 여는 폴더"예요.
1. 늘 열어 둘 폴더의 탭을 우클릭해요.
2. **고정**을 눌러요. 탭에 핀이 표시되고 닫기 단추가 사라져요.
3. 고정 탭에서 다른 폴더로 가면 새 탭에 열려서, 고정한 폴더는 그대로 남아요. 풀려면 우클릭 → **고정 풀기**.
- 탭 메뉴의 **복제**는 같은 폴더 탭을 하나 더, **반대 창에 열기**는 대상 창에 열어요. 닫기는 `Ctrl+W`.
- `Ctrl+Tab`·`Ctrl+Shift+Tab`으로 탭을 옮겨 가고, 폴더를 마우스 가운데 단추로 누르면 뒤에 새 탭으로 열려요.
- 설정 "끌 때 열린 탭 비우기"를 켜면 다시 켤 때 고정 탭만 남아요.

### 드라이브·빠른 필터
그림: files_viewmenu | div.fx-menu.fx-menu-r | 보기 ▾를 누르면 나오는 보기 방식
- **드라이브 단추**(C: D: …)를 누르면 그 드라이브 맨 위로 가요. USB를 꽂거나 빼면 3초 안에 단추에 반영돼요. 우클릭하면 윈도우 드라이브 메뉴(꺼내기·속성 등)예요. 보일 드라이브는 설정 → 탐색기 **드라이브 단추**에서 골라요.
- **빠른 필터**는 지금 폴더 목록을 글자로 바로 걸러요. 목록에서 글자 키를 쳐도 이 칸에 들어가요.
- **보기 ▾**로 자세히·간단히·큰 아이콘·썸네일을 골라요(`Ctrl+Shift+1`~`4`, `Ctrl+휠`). 창마다 따로 기억해요.

### 경로 줄
- 경로의 폴더 조각을 누르면 그 폴더로 가요. 빈 곳을 누르면 경로를 고쳐 적을 수 있어요(`Ctrl+L`·`Alt+D`·`F4`). 적는 동안 아래 폴더가 후보로 떠서 `↑`·`↓`로 고르고 `Tab`으로 채워요.
- 조각 사이의 ›를 누르면 그 폴더의 아래 폴더 목록이 떠요.
- 오른쪽 단추: **경로 복사**(파일을 골랐으면 파일 경로) · **윈도우 탐색기로 열기**(`Ctrl+E`) · **★ 즐겨찾기**.

### 목록
- 두 번 누르거나 `Enter`로 열어요. 파일은 윈도우 기본 프로그램으로 열려요. 위 폴더는 맨 위 ".." 줄, `Backspace`, `Alt+↑`, 빈 곳 두 번 누르기.
- 여러 개 고르기: `Ctrl`·`Shift`를 누른 채 누르기, `Space`, 빈 곳에서 끌어 고무줄로 고르기.
- 열 제목을 누르면 정렬, 경계를 끌면 폭(두 번 누르면 자동 폭), 열 제목 우클릭으로 보일 열을 골라요.
- 우클릭은 윈도우 전체 메뉴가 바로 떠요. 맨 아래 "윈도우 탐색기에서 열기 · 보안 해제"는 기록이 더한 줄이에요.
- 복사·옮기기: `F5`·`F6`은 대상 창으로("복사할까요?" 한 번 확인), `Ctrl+C`·`X`·`V`는 윈도우 탐색기·바탕 화면·메일 첨부와도 오가요. 끌어 놓기는 같은 드라이브면 옮기기, 다른 드라이브면 복사(`Ctrl` 복사·`Shift` 옮기기, 오른쪽 단추로 끌면 고르는 메뉴).
- 같은 이름이 있으면 두 파일을 나란히 보여 주고 건너뛰기·덮어쓰기·둘 다 두기(새 파일에 " (2)")를 물어요. "나머지도 같게"로 한 번에 정해요.
그림: files_delete | div.dialog | F8을 누르면 묻는 지우기 확인
- `F8`·`Delete`는 묻고 휴지통으로, `Shift+F8`은 완전히 지워요. 묻지 않게 하려면 설정 → 탐색기 "지울 때 묻기"를 꺼요.
- `Ctrl+Z` 되돌리기·`Ctrl+Y` 다시 하기는 이 앱에서 한 옮기기·복사·이름 바꾸기·휴지통 지우기·새 폴더만 돼요(앱을 끄면 기록이 사라져요).
- zip 파일은 두 번 누르면 폴더처럼 들어가 안을 보고 꺼낼 수 있어요(읽기만).

### 문서보안 해제
회사 문서보안 메뉴는 윈도우 탐색기에서만 보여서, 기록이 윈도우 탐색기로 넘겨 줘요.
1. 목록에서 보안을 풀 파일을 골라요(같은 폴더라면 여러 개도 돼요).
2. 우클릭 → 맨 아래 **윈도우 탐색기에서 열기 · 보안 해제**를 눌러요.
3. 윈도우 탐색기가 열리면서 그 파일들이 골라지고, 우클릭 메뉴까지 저절로 떠요.
4. 메뉴에서 보안 해제를 골라요.
5. 윈도우 탐색기 창은 직접 닫아요. 기록 목록은 저절로 새로 고쳐져요.

### 단축키 줄
창 아래 줄에 자주 쓰는 키를 늘 보여 줘요: `F2` 이름 바꾸기 · `F3` 열기 · `F5` 복사 · `F6` 옮기기 · `F7` 새 폴더 · `F8` 지우기 · `Ctrl+C`·`X`·`V` · `Space` 고르기 · `Tab` 다음 창 · `Ctrl+E` 윈도우 탐색기로.

### 설정 → 탐색기
그림: settings_files | section.mod-card:has(.mod-head:text-is("탐색기")) | 설정 화면의 "탐색기" 카드
- **날짜 형식** – 목록 "수정한 날" 열의 모양이에요.
- **드라이브 단추**·**폴더 트리** – 위쪽 단추 줄과 왼쪽 트리에 각각 보일 내 PC·드라이브·즐겨찾기를 골라요.
- **빠른 찾기** – 모든 드라이브 빠른 찾기를 켜고 꺼요.
- **보이는 열** – 자세히 보기에 보일 열(크기·수정한 날·파일 형식)이에요.
- **숨김 파일 보이기** · **새 탭이 여는 폴더** · **지울 때 묻기** · **끌 때 열린 탭 비우기**

## 확인
- 사양서 탐색기 절 첫머리에 "아직 시안 단계라 이 절 전체가 앱에 없어요"가 남아 있어요 – 지운 줄인지 확인
- 사양서는 탭 우클릭에 "닫기(Ctrl+W)"가 있다는데 열린 모습(탭 하나)에는 없어요 – 탭이 하나일 때 빼는 것인지 확인
- 사양서 "민원처리 줄의 '파일' 단추 = 탐색기 열고 빠른 필터에 이름"인데 민원처리 화면에 그 단추가 없어요(⋯ 메뉴 "저장 폴더 열기"만) – 어느 쪽이 맞는지 확인
