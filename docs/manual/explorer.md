# 탐색기
정의: 컴퓨터 내 업무 파일을 체계적으로 관리하는 도구
장면: screen_00

## 기획 의도
- 회사 업무 환경에 맞는 무료 파일 탐색기 프로그램을 제공해요. 지원이 끝난 구형 탐색기 사용은 이제 그만.
- Everything과 같은 고속 검색 기능을 프로그램에 내장해, 탐색기와 같이 쓸 수 있도록 했어요.
- 바쁜 업무 중 너저분하게 열려 있는 폴더 창을 줄일 수 있도록 탐색기 다중 분할 기능을 제공해요.

## 열린 모습
- files_tabmenu | div.fx-tabmenu | 탭 우클릭 메뉴 | 고정·복제·반대 창에 열기·다른 탭 모두 닫기가 나와요.
- files_delete | div.dialog | 지우기 확인 | `F8`을 누르면 "지울까요?"를 묻고 휴지통으로 보내요.

## 알아 두면 좋은 것
- 파일 열기는 윈도우 기본 프로그램으로 열려요(앱 안 뷰어는 없어요).
- 날짜 모양·보이는 드라이브·숨김 파일·새 탭이 여는 폴더·지울 때 묻기는 설정 → "탐색기" 카드에서 바꿔요.

## 자세히
### 회사 업무 환경에 맞는 무료 탐색기
- 두 창으로 옮기고 복사 | 왼쪽·오른쪽 창을 나란히 두고, `F5` 복사·`F6` 옮기기는 반대 창(대상 창)으로 가요. 누르면 "복사할까요?"로 한 번 확인해요.
- 윈도우 탐색기와 같은 손버릇 | 파일 우클릭은 윈도우 전체 메뉴("더 많은 옵션 표시")가 바로 떠요. `Ctrl+C`·`X`·`V`로 윈도우 탐색기·바탕 화면·메일 첨부와 파일을 주고받고, 끌어다 놓기도 양쪽으로 돼요.
- 손에 익은 키 | `F2` 이름 바꾸기 · `F7` 새 폴더 · `F8` 휴지통 · `Alt+↑` 위 폴더 · `Ctrl+L` 주소 칸 · `Alt+Enter` 속성 · `Ctrl+Z` 되돌리기(이 앱에서 한 옮기기·복사·이름 바꾸기·지우기·새 폴더).
- 문서보안 해제 | 파일 우클릭 맨 아래 "윈도우 탐색기에서 열기 · 보안 해제"를 누르면, 윈도우 탐색기가 그 파일을 골라 둔 채 보안 메뉴가 있는 우클릭 메뉴까지 띄워 줘요.
- 같은 이름 파일 | 파일마다 이미 있는 것과 나란히 보여 주고 건너뛰기·덮어쓰기·둘 다 두기를 물어요. "나머지도 같게"로 한 번에 정해요.
- 일괄 이름 바꾸기 | 여러 파일 이름을 규칙(기존 이름·번호·수정한 날·상위 폴더 이름 등)으로 한 번에 바꿔요. 바꾸기 전 미리 보기, 겹치는 이름은 빨간 줄로 막고, 되돌리기도 돼요.
- 민원처리 파일 | 민원처리의 지시부·사진은 한 폴더(처음 D:\민원처리)에 "접수일_위치_보수내용" 이름으로 쌓여 찾기 쉬워요.
- zip 파일 | 두 번 누르면 폴더처럼 들어가 안을 보고 꺼낼 수 있어요(읽기만).

### Everything 같은 고속 검색 내장
- 모든 드라이브에서 바로 찾기 | 위 찾기 칸에 이름을 치는 대로 결과 탭이 바로 바뀌어요. 파일 목록을 미리 만들어 두는 방식이라, 설치할 때 관리자 허용을 한 번 받아요.
- 자세히 ▾ | 여러 이름(`*`·`?`·`;`), 안의 글자(한글·오피스·PDF), 어디서·하위 폴더, 수정한 날, 크기, 잠긴 파일만, 민원과 이어진 것만으로 좁혀요. 조건은 저장해 다시 써요.
- 결과에서 바로 일하기 | 결과는 지금 창의 새 탭이에요. 두 번 누르면 파일이 열리고 탭은 남아요. `Ctrl+Enter`는 그 파일의 폴더를 새 탭으로, 복사·옮기기·이름 바꾸기·보안 해제도 결과에서 바로 돼요.
- 빠른 필터 | 목록에서 글자 키를 치면 지금 폴더 안을 바로 걸러요.
- 빠른 찾기 켜고 끄기 | 설정 → 탐색기 "빠른 찾기"에서 켜고 꺼요. 윈도우·프로그램 폴더는 목록에서 빼 두어, 그 아래는 "어디서"로 고르면 예전처럼 차례로 뒤져 찾아요.

### 다중 분할로 창 정리
- 두칸·세칸·네칸 | 머리 줄 단추로 창을 나눠요. 두칸을 한 번 더 누르면 좌우 ↔ 상하, 세칸을 한 번 더 누르면 긴 칸이 왼쪽 ↔ 오른쪽으로 바뀌어요. 창 사이를 끌어 크기를 맞추고, "배치복구"로 처음대로.
- 지금 창·대상 창 | 테두리로 지금 창과 대상 창을 보여 줘요. `F5`·`F6`은 대상 창으로, `Tab`은 다음 창, `Ctrl+1`~`4`는 창 고르기예요.
- 탭 | 창마다 여러 폴더를 탭으로 열어 둬요. 고정 탭은 다른 폴더로 가면 새 탭이 열려요. 탭 우클릭으로 복제·반대 창에 열기, 가운데 단추로 누른 폴더는 뒤 새 탭.
- 같은폴더·창바꾸기 | 대상 창을 지금 창과 같은 폴더로 열거나, 두 창의 폴더를 서로 바꿔요.
- 펼쳐보기·미리보기 | 하위 폴더 파일까지 한 목록으로 보고, 대상 창 자리에 고른 파일을 미리 봐요.
- 다시 켜도 그대로 | 칸 모양·나눈 비율·창마다 탭·열 폭·정렬을 기억해요. 설정 "끌 때 열린 탭 비우기"를 켜면 고정 탭만 남아요.

## 확인
- 사양서 탐색기 절 첫머리에 "아직 시안 단계라 이 절 전체가 앱에 없어요"가 남아 있어요 – 지운 줄인지 확인
- 사양서는 탭 우클릭에 "닫기(Ctrl+W)"가 있다는데 열린 모습(탭 하나)에는 없어요 – 탭이 하나일 때 빼는 것인지 확인
- 사양서 "민원처리 줄의 '파일' 단추 = 탐색기 열고 빠른 필터에 이름"인데 민원처리 화면에 그 단추가 없어요(⋯ 메뉴 "저장 폴더 열기"만) – 어느 쪽이 맞는지 확인
