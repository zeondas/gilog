# 설정
정의: 앱 전체와 모듈별 설정을 한 곳에서 바꾸는 화면
장면: screen_09

## 기획 의도
- 비밀번호·잠금·테마·화면 크기·목록·키 설정·모듈별 설정을 한 화면에 모았어요.
- 자동 잠금은 끌 수 있고, 잠기기까지 시간도 정해요.
- 바꾸는 즉시 저장되고, 언제든 "기본값으로 되돌리기"로 처음 값으로 돌아가요.

## 번호
1. 설정 찾기 | label.set-find | 이름·설명에 맞는 설정만 남기고 맞은 글자를 칠해요("암호" → 비밀번호처럼 비슷한 말도 찾아요). | 위
2. 기본값으로 되돌리기 | button:has-text("기본값으로 되돌리기") | 한 번 더 묻고 처음 값으로 돌려요. 암호·저장 위치·구글 연결·자료는 그대로예요. | 위
3. 닫기 | button.set-close | 마지막으로 보던 화면으로 돌아가요. | 위
4. 모듈 | section.card >> nth=0 >> .card-head | 공통 설정 맨 위 카드예요. 사이드바 순서대로 모듈이 있어요. | 아래
5. 켜고 끄기 | span.switch >> nth=0 | 끄면 사이드바에서 숨겨요. 자료는 그대로이고 다시 켜면 돌아와요. | 아래
6. 일반 | section.card >> nth=1 >> .card-head | 내 이름·테마·시작 화면·화면 크기·닫기 단추 동작 등을 정해요. | 아래 왼끝

## 열린 모습
- settings_calendar | section.mod-card:has-text("구글 로그인") | 캘린더·구글 연동 | 쉬는 날 음영, 구글 로그인, 일정·민원 마감·할 일 마감 내보내기를 켜고 꺼요.

## 알아 두면 좋은 것
- 아래로 내리면 보안·저장(비밀번호·자동 잠금·백업), 키 설정, 모듈별 설정(탐색기·민원대장·민원처리·캘린더·업무일지)이 이어져요.
- `Ctrl+F`로 찾기 칸에 가고, `Esc`로 찾는 글을 지워요.
- 내리면 오른쪽 아래 "맨 위로" 단추가 나와요.
- 모듈은 적어도 하나는 켜 둬야 해요.

## 확인
- 정의·기획 의도 초안 – 확인
- 사양서는 "구글 캘린더 연동"을 공통 설정 카드로 적었는데, 화면은 모듈별 "캘린더" 카드 안에 "구글 연동"으로 있어요 – 확인
- 사양서는 집행현황에 설정 카드를 두지 않는다고 했는데, 화면에는 집행현황 카드(팀 공유)가 있어요 – 확인
- 모듈 카드의 업무연락처 설명이 아직 "사람·프로젝트 연락처"예요("사업"으로 바꿀지) – 확인
