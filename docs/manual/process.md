# 민원처리
정의: 국민신문고 민원을 불러와 시공사 공사 지시부를 만들어 보내는 도구
장면: screen_02

## 기획 의도
- 신문고 민원을 하나씩 내려받던 일을 [민원 불러오기] 한 번으로, AI가 보수 내용과 맡을 공사를 골라 둬요.
- 위치·보수 내용·위치도·현장사진이 든 공사 지시부를 만들어 메일이나 폰으로 시공사에 보내요.
- 지시부를 만들면 민원대장 조치내용에 지시 내용이 저절로 적혀요.

## 번호
1. 신문고 열기 | .ct-head button:has-text("신문고 열기") | 크롬으로 업무처리포털을 열어 로그인해요. | 위
2. 민원 불러오기 | button.pr-fetch | Claude가 처리중 민원을 읽어 표에 넣어요. 이미 있는 번호는 건너뛰어요. | 위
3. 공사 관리 | .ct-head button:has-text("공사 관리") | 공사·시공사·처리 범위를 적어요. AI는 처리 범위로 판단해요. | 위
4. 고르기 칸 | .pr-row >> nth=1 >> .pr-check | 같은 공사 민원을 골라 한 지시부로 묶어요. | 아래
5. 위치 | div.pr-place.one | 리·동 + 지번이에요. 두 번 누르면 고쳐요. | 아래
6. 판단 공사 | button.pr-work | AI가 고른 공사예요. 눌러서 바꿔요. | 아래
7. 고려사항 | div.pr-nc | 두 번 눌러 적어요. 지시부 ○ 줄이 돼요. | 아래
8. 진행 | span.pr-gauge | 접수 → 지시부 → 보냄 → 답변 → 완료로 차요. | 아래
9. ⋯ 메뉴 | button.pr-more | 줄 우클릭과 같은 메뉴예요. | 아래

## 열린 모습
- process_rowmenu | div.dmenu.pr-rowmenu | 줄 메뉴 | 맨 위에 사진·위치도 수가 보이고, 지시부 만들기부터 지우기까지 이 민원 일을 골라요.
- process_works | .dialog.pr-works | 공사 관리 창 | 공사명을 치면 업무연락처 사업에서 찾아 축약 공사명·현장대리인·시공사를 채워요.

## 알아 두면 좋은 것
- 지시부는 표준 양식 한글 파일과 쪽마다 그림으로 민원 폴더에 저장돼요. [보내기 ▾]로 메일(현장대리인 업무연락처 주소) 또는 폰을 골라요.
- 민원 요약에 마우스를 올리면 AI가 그 공사를 고른 이유가 보여요. 번호를 누르면 전체 접수번호가 복사돼요.
- 민원대장에서 완료·불가로 바꾸면 이 표에서 숨어요. 아래 "완료 N건"으로 펼쳐 봐요.
- 준비(한 번): Claude Code 설치·로그인, 크롬에 Claude 확장, 크롬으로 신문고 로그인.
