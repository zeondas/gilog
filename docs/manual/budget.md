# 집행현황
정의: 예산 집행률과 가용액을 한눈에 보는 집행 관리표
장면: screen_03

## 기획 의도
- 엑셀로 하던 집행 관리를 표 하나로 옮겨, 집행률과 가용액을 바로 계산해 보여요.
- 팀원끼리 구글 시트로 함께 써서, 한 사람이 고친 값이 [새로고침]으로 다른 사람 앱에도 떠요.

## 열린 모습
- budget_menu | div.bd-pop | 줄 우클릭 메뉴 | 세부사업·부기사업·공사 추가, 수정·메모, 옮기기, 지우기(딸린 줄 수를 알려 줘요)가 나와요.

## 알아 두면 좋은 것
- 숫자 칸을 `Ctrl`·`Shift`+누르기로 여러 개 고르면 오른쪽 아래에 개수·합계가 떠요. 딱 두 칸이면 차액도요.
- 팀 공유: 설정 › 집행현황 카드에서 켜고 시트 주소를 붙여요. 켜면 해 옆에 [새로고침]과 "올림·받음" 시각이 생기고, 열 때와 5분마다 저절로도 맞춰요.
- 같은 칸을 두 사람이 다르게 고치면 주황 테두리 칸을 눌러 어느 값을 둘지 골라요.
- 줄을 두 번 누르면 고치고, 바깥 누르기는 저장, `Esc`는 취소예요.

## 확인
- 정의·기획 의도 초안 – 확인
- 세부사업 줄 우클릭에 "부기사업 모두 펼치기/접기"·"예산현황 설정"이 있는데 사양서 메뉴 목록에 없어요 – 사양서에 더할지 확인
- 팀 공유를 켠 장면이 없어 [새로고침]·담당 열에 번호를 못 붙였어요 – 장면을 더할지 확인
