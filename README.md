# giLog

도로관리과 담당자 한 사람이 쓰는 업무 기록 앱이에요. 업무일지, 민원대장, 업무연락처, 캘린더, 할 일 목록, 설정으로 이루어져요.

- 설치 파일은 이 보관소의 Releases에 자동으로 올라와요.
- 화면은 React + TypeScript, 앱 틀은 Tauri 2예요.
- 색·간격 값은 `src/tokens.css`에 모여 있어요. 화면 코드에 색 값을 직접 적지 않아요.

지금은 4단계(업무연락처)까지 만들었어요.

- 규칙 함수 시험: `npm test`(vitest, `src/*.test.ts` – 날짜·전화·머릿기호·민원·할 일·캘린더·예산현황·탐색기·키). 지금 동작을 고정하는 시험이라, 일부러 규칙을 바꿀 때만 시험 값도 함께 고쳐요.
- 모양(CSS)은 `src/styles/`(불러오는 순서는 `index.css`)에 화면별로 있어요. 옮기거나 나눈 뒤에는 `tools/guard`(사진·계산된 모양 값) 0점을 확인해요.
