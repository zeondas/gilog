# data/paju_roadaddr.txt — 파주시 도로명주소 ↔ 지번 표

- 출처: 행정안전부 주소정보누리집(business.juso.go.kr) "도로명주소 한글" 전체자료 경기도(`rnaddrkor_gyunggi.txt`, 2026-10-18 받음)에서 시군구명이 "파주시"인 줄만 뽑았어요. 55,119줄, 2.8MB.
- 한 줄 = `도로명|지하여부|건물본번|건물부번|읍면동|법정리|산여부|지번본번|지번부번|건물명` (UTF-8, `|` 구분, 머리 줄 없음).
- 원본 칸 순서(참고): 관리번호|법정동코드|시도|시군구|읍면동|법정리|산|지번본|지번부|도로명코드|도로명|지하|건물본번|건물부번|행정동코드|행정동명|우편번호|이전도로명주소|효력발생일|공동주택|이동사유|건축물대장건물명|시군구건물명|비고 (cp949).
- 끝에 11번째 칸 `행정동`이 붙을 수 있어요(2026-10-18 사용자 1안 — 다음 갱신부터). 있으면 앱이 금촌동·아동동처럼 행정동 여럿에 걸친 법정동도 지역을 묻지 않고 채워요. 지금 파일은 10칸이라 그런 곳은 지역 고르기 목록이 떠요.
- 앱은 빌드 때 이 파일을 압축해 넣어요(`src-tauri/core/build.rs` → 약 400KB, 읽기 `core/src/address.rs`). 파일만 바꾸면 다음 빌드에 들어가요.

## 갱신(분기마다)
1. 사용자가 주소정보누리집 → 주소자료 → "도로명주소 한글" 전체자료에서 경기도 파일(`rnaddrkor_gyunggi.txt`, cp949)을 받아 대화에 올려요(작업 공간은 그 사이트에 못 들어가요).
2. 세션이 `python3 tools/address/extract.py rnaddrkor_gyunggi.txt > data/paju_roadaddr.txt`를 돌려요(파주시 줄 수를 알려 주고, 4만 줄보다 적으면 멈춰요).
3. `cargo test --manifest-path src-tauri/core/Cargo.toml address` — 보기 값 6개(시청로 50, 통일로 136, 문향로 61, 필승로 500, 경의로 1246, 금정로 20-3)가 그대로인지 봐요. 건물이 헐리거나 번호가 바뀌어 틀리면 시험 값을 새 자료에 맞춰 고쳐요.
