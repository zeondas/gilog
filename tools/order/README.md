# 지시부 시험 도구 (10단계 민원처리)

기Log가 지시부를 만드는 방식을 미리 시험한 스크립트예요(앱 코드 아님).

- `make_tpl.py 원본양식.pptx 자리표시양식.pptx` — 사용자의 「작업지시서 양식2」에서 첫 장만 남기고, 표 둘째 줄에 `{연번} {지시자} {주소} {보수내용} {고려사항}`, 사진 자리에 이름이 "위치도"·"현장사진"인 네모를 넣어요.
- `fill.py 자리표시양식.pptx 결과.pptx '{"text":{...},"images":{"위치도":"..","현장사진":".."}}'` — 자리 글자를 바꾸고(줄바꿈은 같은 서식 문단), 이름 붙은 네모 자리에 그림을 비율대로 맞춰 넣어요. 빠진 자리를 알려 줘요.
- JPG: `soffice --headless --convert-to pdf 결과.pptx` → `pdftoppm -r 110 -jpeg`. 윈도우 앱에서는 파워포인트(hwpx는 한글)로 바꿔야 해요.
